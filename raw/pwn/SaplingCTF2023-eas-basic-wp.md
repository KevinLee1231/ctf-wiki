# EAS: basic

## 题目简述

服务循环执行 printf(user_input)，并在堆上保存整数 owo。只有当该值加 0x1337 后等于目标 ovo，才调用打印 flag 的函数。格式串的 %n 能把已输出字符数写入指定地址，因此可以直接改写 owo。

## 解题过程

先用 %p 或位置参数确定 owo 指针位于第 11 个 printf 参数。根据源码中的比较式计算需要写入的 16 位值 target，构造：

~~~python
payload = f"%{target}c%11$hn".encode()
~~~

若目标值小于已经输出的字符数，应按 $2^{16}$ 取模补差；%hn 只写低 2 字节，避免 %n 覆盖邻接数据。写入后再次进入菜单触发检查，服务调用 h3re 并输出：

~~~text
maple{prprprpr1n7f}
~~~

## 方法总结

格式串写利用有三个要素：目标指针的参数序号、需要写入的值、当前累计输出字符数。优先选择 %hhn 或 %hn 控制写宽度，并把所有计数按相应模数计算；不能只照抄一个固定 padding 而忽略前缀输出。
