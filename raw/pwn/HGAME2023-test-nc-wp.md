# test_nc

## 题目简述

这是一道 Pwn 方向的环境签到题，用于确认选手能够通过 Netcat 与远程 Linux 服务交互。服务本身直接提供命令执行环境，不需要构造内存破坏利用。

## 解题过程

使用题目给出的主机和端口建立 TCP 连接；下面的保留域名和端口仅用于展示命令格式：

```bash
nc challenge.example 31337
```

连接成功后执行读取 flag 文件的命令：

```bash
cat flag
```

服务将文件内容直接回显，即可提交其中的 `hgame{...}`。

## 方法总结

- 核心技巧：使用 Netcat 连接题目提供的交互式 TCP 服务。
- 基本排查：若没有提示符，可直接发送命令并回车；连接失败时先核对主机、端口和网络环境。
- 复用要点：正式分析 Pwn 题前，先确认能够稳定连接、收发数据并区分本地附件与远程服务的文件路径。
