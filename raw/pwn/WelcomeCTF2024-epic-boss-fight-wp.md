# Epic Boss Fight

## 题目简述

Boss 初始生命为 10000，普通攻击每次只造成 1 点伤害且玩家会损失 10 点生命；防御则让 Boss 回复 1000。Boss 生命使用 16 位有符号 `short`，目标是让回血触发整数溢出，从而满足胜利条件。

## 解题过程

关键逻辑为：

```c
short int boss_hp = 10000;

case 2:
    boss_hp += 1000;
    break;

if (boss_hp <= 0) {
    win();
}
```

`short` 的范围是 $[-32768,32767]$。连续选择防御时，Boss 生命依次增加；到 32000 后再加 1000，底层 16 位值为 33000，即十六进制 `0x80e8`，按有符号数解释为：

$$33000-65536=-32536$$

因此只需连续防御 23 次，生命从 10000 增加到溢出后的负数。循环末尾 `boss_hp <= 0` 成立，调用 `win` 并输出：

```text
grey{i_wonder_how_negative_integers_are_shown_in_memory?}
```

## 方法总结

有符号 16 位整数超过 32767 后会按二进制补码解释为负数。游戏数值、计数器和长度字段若使用过窄类型，增益操作也可能成为攻击输入；安全判断必须在防溢出的类型和范围检查之后进行。
