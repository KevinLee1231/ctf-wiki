# bi0sCTF 2024 - BFS

## 题目简述

服务实现了一个 Brainfuck 解释器，把 flag 分成三段并设计了三种受限泄漏关卡。每次只允许提交短 Brainfuck 程序，flag 字节被放在随机 tape 位置，数据指针也随机。三关分别要求：把远处字节搬回初始指针、按给定顺序标记所有隐藏字节、通过最终可见的 tape 窗口编码字节的商和余数。

虽然题目位于 Misc，决定性技术障碍是利用受限解释器的执行与观测边界，因此归入 Pwn。

## 解题过程

### 通用移动原语

tape 初始绝大多数单元为 0，只有目标字节和少数锚点非零。Brainfuck 循环可以在不知道绝对距离时搜索下一个非零单元。例如官方 exploit 使用的短片段会交替跨过零单元，直到命中非零锚点；随后用

```brainfuck
[<+>-]
```

一类循环把当前单元搬到左侧相邻位置并清零源单元。将“搜索锚点”和“逐步搬运”组合起来，就能跨越随机距离而无需提交成千上万个 `<` 或 `>`。

### 第一关：把字节运回入口

每轮服务告诉目标 flag 字节所在位置和初始数据指针 `entry`，但执行后只显示 `entry` 处的一个字节。根据目标在指针左侧还是右侧，选择镜像的 Brainfuck payload：

```text
目标在右：向右搜索非零值 -> 逐格向左搬运 -> 回到 entry
目标在左：向左搜索非零值 -> 逐格向右搬运 -> 回到 entry
```

官方右侧版本为：

```brainfuck
<->-[+[<+<]>-]>[<[<<]>[<+>-]<]
```

左侧使用交换 `<`、`>` 与对应增减方向的镜像。执行后服务打印 `tape[entry]`，逐轮拼接得到第一段。

### 第二关：按顺序标记隐藏位置

第二段的所有字节同时放在随机位置，服务公开这些位置的目标顺序，但不直接给出字符。解释器把 `.` 改造成“记录当前数据指针位置”，而不是输出字节；只有 `markstack` 与隐藏位置序列完全一致才返回第二段 flag。

将公开位置排序，并把当前 dp 插入有序表。对目标顺序中的每个位置：

1. 根据它在当前有序表的左侧或右侧选择搜索方向；
2. 借助尚未清零的非零单元作为锚点移动到目标；
3. 执行 `.` 记录位置；
4. 用 `[-]` 清零该单元，避免后续搜索再次命中；
5. 从有序表删除旧锚点并更新当前位置。

由此构造一条不依赖实际随机距离的 payload。全部标记正确后服务直接显示第二段。

### 第三关：用指针位置泄漏十进制值

最后一关不显示 flag 单元，只显示初始 dp 周围固定宽度的 tape 窗口。思路是把字节值 $v$ 转换为指针位移，使可见窗口中分隔符的数量编码结果。

第一次连接对每个字节执行 Brainfuck 长除法，计算

$$
q=\left\lfloor\frac{v}{10}\right\rfloor,
$$

再把 dp 移动与 $q$ 成比例的距离。官方解析窗口中 `|` 的数量，并还原十位部分 $10q$。第二次连接对相同位置计算

$$
r=v\bmod10,
$$

以同样方式编码位移；解析出 $r$ 后得到 $v=10q+r$。flag 在不同连接间固定，所以两次观测可以合并。

实现时应先在本地解释器用所有 $0\le v<256$ 验证除法、取模和窗口计数公式，再用于远程；第三关的 Brainfuck 字符串很长，任何一个括号方向或初始偏移错误都会使 dp 越界或计数整体偏移。

## 方法总结

三关逐步限制观测能力，但都可以把秘密转换到仍可观察的通道：第一关把值搬到可读入口，第二关把位置序列编码到 `.` 的标记副作用，第三关把数值的商和余数编码到最终指针位置。零单元与非零锚点提供了不依赖随机绝对距离的导航方式；第三关用两次独立会话组合 $v=10q+r$ 完成字节恢复。
