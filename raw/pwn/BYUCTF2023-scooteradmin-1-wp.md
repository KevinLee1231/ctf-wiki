# BYUCTF 2023 - ScooterAdmin 1

## 题目简述

认证结构体中，用户输入缓冲区后紧邻密码文件描述符。程序误把十六进制长度 `0x32` 当作十进制 32，向 32 字节字段读取 50 字节，允许覆盖后续文件描述符。

## 解题过程

发送 51 至 60 个 NUL 字节即可覆盖密码输入和文件描述符：

```python
p.send(b'\x00' * 60)
```

文件描述符被清零为标准输入。程序随后本应从密码文件读取“正确密码”，实际却再次从同一输入流取数据；攻击者提供的密码和所谓正确密码都以 NUL 开头，`strcmp` 看到两个空字符串，因而返回相等。

认证通过后得到：

```text
byuctf{agree_with_yourself_on_the_password!}
```

## 方法总结

结构体字段相邻使一个普通栈溢出直接改变了数据来源。利用目标不是返回地址，而是文件描述符；把它改成 `stdin` 后，攻击者同时控制比较两侧，形成“自己与自己比较”的逻辑绕过。
