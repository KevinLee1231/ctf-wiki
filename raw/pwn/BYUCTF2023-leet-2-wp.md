# BYUCTF 2023 - Leet 2

## 题目简述

服务仍要求 `eval` 结果为 `1337`，这次禁止字符 `1` 至 `9` 和左括号 `(`，但没有禁止十六进制前缀、加减号或数字 `0`。

## 解题过程

十六进制常量 `0xf` 的值为 `15`，不含被禁的十进制数字。构造 90 个 `0xf` 再减去 `0xd`：

```text
0xf+0xf+...+0xf-0xd
```

其中 `0xf` 重复 90 次，因此表达式满足 $90 \times 15-13=1337$。

提交展开后的表达式即可得到：

```text
byuctf{aaaaaaand_more_simple_bypasses_:)}
```

## 方法总结

数值过滤必须覆盖 Python 接受的全部字面量表示。题目只封锁了十进制字符，却保留了十六进制常量和算术运算，因此可以换表示层绕过，而无需攻击解释器本身。
