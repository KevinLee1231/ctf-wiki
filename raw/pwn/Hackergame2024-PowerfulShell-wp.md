# PowerfulShell

## 题目简述

服务是一个由 Bash 脚本实现的黑名单 jail，并没有启用 Bash 自带的 restricted mode。每轮读取一行，若出现大小写字母、数字 `0`、引号、斜杠、通配符及多种标点就退出，否则把输入交给 `eval`：

```bash
FORBIDDEN_CHARS="'\";,.%^*?!@#%^&()><\/abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0"

if [[ $input =~ [$FORBIDDEN_CHARS] ]]; then
    exit
else
    eval $input
fi
```

容器把低权限用户的家目录和工作目录都设置成 `/players`，flag 位于根目录。决定性障碍是从允许字符与 Bash 内建展开中拼出可执行命令、突破语言沙箱，因此归入 `pwn`，而不是因为附件是 shell 脚本就归为普通编程题。

## 解题过程

### 从无需字母的展开获得字符

Bash 在变量赋值右侧会进行波浪号展开，因此下面的赋值不需要输入任何字母，却能把 `/players` 保存进变量：

```bash
_1=~
```

变量名可以只使用下划线和数字。`${parameter:offset:length}` 又允许从变量内容切片；当偏移写成负数时，冒号后必须留空格，避免被解析成 `:-` 默认值操作符。`/players` 的下标 7 是字符 `s`：

```bash
${_1:7:1}
```

仅靠家目录还缺少 `h`。Bash 特殊参数 `$-` 保存当前 shell 的选项标志，在题目环境中为 `hB`。把它存入第二个变量后，从倒数第二位取得 `h`：

```bash
_2=$-
${_2: -2:1}
```

### 组合并逃逸

依次提交三行：

```bash
_1=~
_2=$-
${_1:7:1}${_2: -2:1}
```

第三行完成参数展开后成为 `sh`。外层 `eval` 执行它，子 shell 直接从同一输入流继续读取命令，而这些命令不再经过 `FORBIDDEN_CHARS` 检查。此时即可使用正常命令查看根目录并读取 flag，例如：

```bash
ls /
cat /flag
```

### 验证

官方 Dockerfile 固定了 `WORKDIR /players`、用户家目录 `/players` 和 Bash 入口，恰好保证 `~` 展开结果及 `$-` 中的 `h` 可预测。解法不依赖 `$0`、路径通配符或 BashFuck；这些常见路线所需的 `0`、`?`、`*`、引号都已被过滤。

## 方法总结

- 核心技巧：利用波浪号展开、特殊参数和字符串切片，在无字母输入条件下拼出 `sh` 并进入未过滤的子 shell。
- 识别信号：Bash jail 使用黑名单后仍调用 `eval`，且允许 `$`、`{}`、冒号、空格和变量赋值时，应系统枚举参数展开与特殊变量。
- 复用要点：先盘点环境提供的稳定字符串（`$HOME`、`$-`、`$PWD` 等），再用切片抽取字符；负偏移的空格和目标 Bash 的实际选项值都必须在对应环境核对。
