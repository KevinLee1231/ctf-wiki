# Flag Shop

## 题目简述

余额使用 `unsigned int`，购买假 flag 时只检查当前余额是否大于单价，却不检查购买数量对应的总价。购买过量商品会令余额无符号下溢。

## 解题过程

初始余额为 100，假 flag 单价为 50。选择购买 3 个后执行：

$$100-3\times50=-50\equiv4294967246\pmod{2^{32}}.$$

界面用 `%i` 打印时可能显示为负数，但内存中的 `money` 仍是很大的无符号整数。再次选择购买价格 1337 的真实 flag，条件 `money >= cost_flag` 成立，程序会读取：

```text
n00bz{5h0p_g0t_h3ck3d_4nd_fl4g_g0t_570l3n!}
```

## 方法总结

数量、单价和总价必须在同一整数域中做上界与溢出检查。显示为负数只是格式化错配的表象，真正利用的是无符号减法回绕。
