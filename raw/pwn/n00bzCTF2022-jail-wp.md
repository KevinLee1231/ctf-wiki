# jail

## 题目简述

远程 shell 对输入做字符白名单，只允许数字和少量 shell 元字符，看似无法输入命令名。遗漏点是 shell 自带的特殊参数 `$0`，它展开为当前 shell 的名称或路径。

## 解题过程

直接提交：

```bash
$0
```

shell 先展开 `$0`，再把展开结果作为命令执行，相当于从受限命令环境中再次启动一个未受同一输入过滤限制的 shell。获得交互后读取 flag：

```text
n00bz{$0_g1ve5_sh3ll??!!!!}
```

## 方法总结

字符白名单不等于语义白名单。shell 的参数展开、变量、重定向和特殊参数都可能在过滤之后生成新的命令文本。设计 jail 时应避免把不可信字符串交给完整 shell 解释器，并使用真正的进程隔离与系统调用约束。
