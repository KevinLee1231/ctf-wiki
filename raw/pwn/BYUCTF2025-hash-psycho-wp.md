# Hash Psycho

## 题目简述

服务让用户自选十进制整数 ID，唯独禁止 `1337`。管理员对象的 ID 为 `1337`，进入管理员办公室时却不比较对象或 ID，而只判断 `hash(YOURUSER) == hash(ADMIN)`。

在题目使用的 64 位 CPython 中，大整数哈希按模数 $M=2^{61}-1$ 归约，因此不同整数可以拥有相同哈希值。

## 解题过程

选择

$$
id=1337+(2^{61}-1)=2305843009213695288.
$$

它不等于被显式拦截的 `1337`，但在 CPython 中满足：

```python
M = 2**61 - 1
candidate = 1337 + M
assert candidate != 1337
assert hash(candidate) == hash(1337)
```

提交任意用户名和该 ID，然后选择管理员办公室。错误的哈希鉴权把碰撞当成身份相等，服务返回：

```text
byuctf{wh0_kn3w_h4sh_w4snt_h4sh}
```

## 方法总结

- 核心技巧：构造 CPython 整数哈希碰撞，绕过仅比较哈希值的身份校验。
- 识别信号：程序把 `hash(x)` 当作唯一标识、权限凭证或防碰撞摘要时，应立即检查运行时哈希的截断、取模和随机化规则。
- 复用要点：哈希相等只适合加速后续的真实相等比较，不能替代它；该构造依赖 64 位 CPython 的整数哈希参数，应先在目标环境验证。
