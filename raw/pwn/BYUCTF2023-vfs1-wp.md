# BYUCTF 2023 - VFS1

## 题目简述

程序把十个虚拟文件连续存入一个结构体：`contents[2880]` 后紧邻 `flag[64]`。每个文件槽为 32 字节文件名和 256 字节内容，读取时却直接用 `%s` 输出，没有显式长度。

## 解题过程

关键布局是：

```c
struct filesystem {
    char contents[2880];
    char flag[64];
    int current_file;
};
```

创建文件时程序用 `%32s` 和 `%256s` 接收，再分别 `memcpy` 固定的 32、256 字节。让字段完全由非零字节填满，就不会在槽内留下字符串终止符。创建到第十个文件时，其内容恰好占据 `contents[2624:2880]`，下一字节就是 `flag[0]`。

因此连续创建十个文件，第十个文件名填满 32 字节、内容填满 256 字节，再读取编号 9。下列语句会越过数组边界继续打印相邻 flag：

```c
printf("[+] Contents: %s", fs.contents + 9 * 288 + 32);
```

输出尾部为：

```text
byuctf{more_like_VULNERABLE_file_system!}
```

## 方法总结

这里不是传统控制流劫持，而是相邻字段越界读取。固定宽度复制不保证目标字段以 NUL 结尾；之后若把它当 C 字符串处理，读取边界就由内存中偶然出现的零字节决定。
