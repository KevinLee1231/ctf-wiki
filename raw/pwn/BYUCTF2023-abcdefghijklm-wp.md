# BYUCTF 2023 - ABCDEFGHIJKLM

## 题目简述

服务只保留输入前四个字符中的 `a` 至 `m`，随后删除其余位置的这些字母，并把输入截断到 80 字符。目标是读取 `flag.txt`。

## 解题过程

前四个字符正好可以放置 `exec`。其后的禁用字母不直接出现，而写成字符串转义；Python 解析字符串时再把 `\xNN` 还原为真实字符。官方 payload 为：

```python
exec("pr\x69nt(op\x65n('\x66'+\x63\x68r(108)+'\x61\x67.txt').r\x65\x61\x64())")
```

外层过滤发生在语法求值前，因此看到的是 `\x69` 等安全文本；内层 `exec` 实际执行的内容等价于读取并打印 `flag.txt`，得到：

```text
byuctf{enc0dings_4r3_us3d_f0r_jailz}
```

## 方法总结

这是“过滤阶段”和“解释阶段”不一致导致的旁路。检查原始字符串时，必须考虑字符串转义、二次求值与编码规范化会在之后重新生成被禁字符。长度限制也应在规范化后的最终代码上重新验证。
