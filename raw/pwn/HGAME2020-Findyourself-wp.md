# Findyourself

## 题目简述

题目提供一个受限的 proc-shell，常规命令的输出不可见，但当前进程仍保留了可利用的文件描述符。目标是辨认 `/proc/self` 的含义，启动新的 shell，并把标准输出重新接到仍可交互的描述符上。

## 解题过程

首先查看当前进程工作目录对应的链接：

```sh
ls -l /proc/self/cwd
```

`/proc/self` 始终指向执行命令的当前进程，`cwd` 则是它的工作目录。接着执行 shell 的位置参数 `$0`：

```sh
$0
```

在 shell 中，`$0` 通常保存当前 shell 的程序名，执行它会再启动一层 shell。此时标准输出仍不可见，但文件描述符 0 对应的交互通道可用。把 fd 0 复制到 fd 1：

```sh
exec 1>&0
```

`exec` 在这里不启动新进程，而是永久修改当前 shell 的重定向关系。恢复输出后直接读取：

```sh
cat /flag
```

终端即可显示 flag。

## 方法总结

- 核心技巧：利用 `$0` 派生新 shell，并用 `exec 1>&0` 修复被关闭或重定向的标准输出。
- 识别信号：命令能够执行却看不到结果时，应检查 fd 0、1、2 的连接关系，而不是立即判断命令被过滤。
- 复用要点：`/proc/self` 是动态指向当前进程的入口；shell 重定向语法中的 `1>&0` 表示让 fd 1 指向 fd 0 当前指向的对象。
