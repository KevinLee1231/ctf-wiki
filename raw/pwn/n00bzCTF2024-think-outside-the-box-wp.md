# Think outside the box

## 题目简述

井字棋程序只检查 `row < size && column < size`，没有验证坐标非负。负下标先越界改写栈上的 `size`，随后利用二维数组的线性寻址，把超出 0–2 的坐标映射回棋盘，同时避开机器人的分支判断。

## 解题过程

第一步提交：

```text
-1,-4
```

在题目给定二进制的栈布局中，`board[-1][-4] = 'O'` 会覆盖 `size` 的低字节，使其从 3 变成更大的值。输入因此可以使用列号 3，而不再被 `column < size` 拒绝。

接下来依次提交：

```text
-1,3
0,3
1,3
```

C 的二维数组按连续内存寻址，这三个位置分别别名到 `board[0][0]`、`board[1][0]`、`board[2][0]`，形成第一列三个 `O`。但机器人的逻辑比较的是原始 `row,column`，这些越界表示不匹配它预设的 0–2 分支，所以无法正常落子阻挡。`checkWin` 检测到胜利后返回：

```text
n00bz{l173r4lly_0u7s1d3_7h3_b0x_L0L}
```

## 方法总结

上界检查不能替代完整边界检查，带符号下标必须同时满足 $0\le index<size$。利用依赖实际栈布局和数组线性化，因此应通过 GDB 验证越界写命中的变量。
