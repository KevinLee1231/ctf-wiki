# no-flag-4-u

## 题目简述

程序提供按页索引写入的接口，并通过预加载库拦截常见危险函数，试图阻止直接覆盖返回地址。实际索引是有符号整数，检查只限制上界，没有拒绝负数；`pages[index]` 因而可指向页表之前的栈数据。二进制无 PIE、无 canary，并带有 `win` 函数。

## 解题过程

选择索引 `-2` 时，程序取得的“页面指针”实际覆盖当前栈帧中保存的 `rbp`。把它改成一个已知堆页地址，并在该页偏移 8 处放入 `win` 地址：

```python
io.sendlineafter(b"index: ", b"-2")
io.sendlineafter(b"size: ", b"8")
io.sendlineafter(b"content: ", flat({8: exe.sym["win"]}))
```

选择退出后，函数执行 `leave; ret`。被篡改的保存 `rbp` 使 `leave` 把栈迁移到攻击者控制的页，随后 `ret` 从偏移 8 取出 `win` 地址。该路径利用的是合法页面写接口和栈迁移，没有调用预加载库重点拦截的传统复制函数，因此防护不起作用。

```text
maple{OwO_flag_for_you?}
```

## 方法总结

只检查 `index < count` 对有符号索引不够，必须同时验证 $0\le index<count$，并在乘法和地址计算前转换为安全的无符号类型。函数拦截只能覆盖少数 API，无法弥补任意地址写或栈迁移原语；安全边界应建立在索引验证和内存权限上。
