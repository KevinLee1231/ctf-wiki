# BYUCTF 2023 - 2038

## 题目简述

程序要求输入的 Unix 时间戳不早于 2024-01-01，即无符号比较至少为 `1704067200`；随后又把同一个值按有符号 32 位整数转换为时间，并在时间早于当前时输出 flag。漏洞来自同一位模式在有符号与无符号语境中的含义不同。

## 解题过程

选择区间 $2^{31} \leq x < 2^{32}$。

在题目部署环境里，`atoi`/32 位 `int` 产生环绕后的负数；把该负数转成 `unsigned int` 时又是一个很大的正数，因此通过“至少为 2024”的门槛。随后按有符号值交给时间逻辑时，它对应 1970 年以前，满足打印条件。最简单的输入是：

```text
2147483648
```

程序由此输出：

```text
byuctf{year_2038_problem_ftw}
```

## 方法总结

审计整数逻辑时要追踪位宽、符号和每次隐式转换。单独看两个比较都像合理检查，但“无符号准入、有符号使用”组合后产生了矛盾区间。严格解析还应检查转换错误和溢出，而不能依赖 `atoi`。
