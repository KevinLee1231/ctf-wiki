# my clock system

## 题目简述

服务用固定方式播种伪随机数生成时钟记录 ID，并把 64 字节名字读入 64 字节缓冲区。字符串终止符会额外写一个 NUL，恰好把相邻 ID 的最低字节清零。只要先让 ID 的高 24 位等于管理员常量，就能用这一字节溢出变成管理员 ID。

## 解题过程

源码把 PRNG 种子重置为 51966。复刻 libc rand 序列或直接与本地二进制同步，连续执行 16 次 reset，使目标记录的 ID 高 24 位成为 0x55baa5。此时其完整值形如：

~~~text
0x55baa5XX
~~~

提交恰好 64 个非零字符作为名字。程序写入末尾 NUL 时越界一字节，将相邻 ID 的 XX 改成 00：

~~~text
0x55baa500
~~~

该值满足管理员检查。进入隐藏菜单项 0x1337 后返回：

~~~text
maple{1_by73_0v3rfl0w_ovo}
~~~

## 方法总结

一字节 NUL 溢出也能形成精确利用，尤其当相邻字段是小端整数。攻击前要控制其余字节，而固定种子的 PRNG 正好提供可预测状态。记录操作次数时应以程序实际调用 rand 的次数为准，菜单中的额外随机调用会造成序列错位。
