# ORD

## 题目简述

程序要求输入未来的入伍日期，随后用 32 位 `int` 保存 Unix 时间，并计算两年后的 ORD 日期。正常情况下程序会按天等待到 ORD；目标是利用 2038 年附近的有符号整数溢出，让循环条件立即结束。

## 解题过程

源码把 `time_t` 结果写入由 `malloc(4)` 分配的 `int`：

```c
*enlistment = mktime(time_struct);
*ord = *enlistment + 2 * YEAR;

while (*now < *ord) {
    time(now);
    sleep(DAY);
}
```

32 位有符号整数最大值为 $2^{31}-1$，对应 2038-01-19 03:14:07 UTC 左右。选择仍能通过“未来日期”检查、但加上两年会越界的日期，例如：

```text
2038-01-01T02:12:27
```

`*enlistment + 2*YEAR` 在 32 位有符号范围内回绕为负数。于是当前正时间 `*now` 不再小于负的 `*ord`，循环一次也不会执行，程序直接运行 `system("cat flag.txt")`：

```text
grey{1n7363r5_c4n_0v3rfl0w_700}
```

## 方法总结

时间处理同样受整数宽度约束。若把 `time_t` 截断进 32 位有符号整数，日期运算会在 2038 年边界附近回绕，并破坏大小比较。审计时应同时检查时间类型、加法溢出和比较条件。
