# flip-out

## 题目简述

程序把 flag 读入栈上数组 `str[128:]`，随后读取一个十进制字符串。它先用有符号 `int` 检查 `val > 128`，再把同一个值转换成 `unsigned char` 作为数组偏移：

```c
int val = atoi(str);
if (val > 128)
    return 0;
unsigned char c = (unsigned char)val;
printf("%s", &str[c]);
```

有符号检查与 8 位无符号索引之间存在截断差异。

## 解题过程

需要让有符号值不大于 128，同时使其模 256 后等于 128。官方输入为：

```text
-2147483520
```

该值等于 $-2^{31}+128$，在 32 位 `int` 范围内，因此 `atoi` 得到负数并通过上界检查；转换到 `unsigned char` 时按模 $2^8$ 截断：

$$
(-2^{31}+128)\bmod256=128.
$$

于是 `printf` 从 `str[128]` 开始输出，正好泄露预先读入的 flag：

```text
tjctf{chop-c4st-7bndbji}
```

## 方法总结

- 同一输入经过有符号比较、窄类型转换和数组索引时，要逐步计算每个类型的值域与模截断结果。
- 只检查上界却不检查负数，随后再转换成无符号类型，是常见的索引绕过模式。
- 修复应在最终索引类型上验证 `0 <= val && val < sizeof(str)`，并使用能检测溢出和非法尾随字符的解析函数。
