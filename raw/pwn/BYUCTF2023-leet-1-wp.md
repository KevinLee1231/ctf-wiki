# BYUCTF 2023 - Leet 1

## 题目简述

服务对输入执行 `eval`，但拒绝包含 Unicode 数字类别 `\d` 的字符串，并要求表达式结果等于 `1337`。决定性问题是过滤器检查字符长相，而 Python 表达式可以从非数字字符的码点构造整数。

## 解题过程

亚美尼亚字母 `Թ` 的 Unicode 码点正好是 `1337`，所以无需出现任何数字：

```python
ord('Թ')
```

`ord` 返回 `1337`，通过结果判断并得到：

```text
byuctf{simple_bypasses!}
```

源码还暴露了另一类旁路：`eval(print(FLAG))` 会先执行 `print`，即使返回值 `None` 随后不等于 `1337`，flag 也已经作为副作用输出。可直接提交：

```python
print(FLAG)
```

## 方法总结

字符黑名单只约束输入表示，不能约束求值语义。遇到 Python jail，应同时检查 Unicode 分类、码点运算、对象属性和带输出副作用的调用；不要只尝试把目标整数拆成十进制算式。
