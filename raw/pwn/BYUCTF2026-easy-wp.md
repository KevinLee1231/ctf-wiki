# Easy

## 题目简述

题目提供一个 Python 包装器，将用户输入交给 `bash -c` 执行。过滤器会删除普通空格，并拒绝包含小写字符串 `sh` 的输入，目标是在这种限制下读取当前目录中的 `flag.txt`。

决定性障碍不是 Web 参数注入，而是受限 shell 中的参数分隔：需要让 Bash 在解析阶段生成一个空白字符，同时避免直接写出被拦截的字符串。

## 解题过程

Bash 展开 `${IFS}` 时会产生内部字段分隔符，默认值包含空格、制表符和换行。因此可以把命令名和文件名写成：

    /usr/bin/cat${IFS}flag.txt

输入本身没有普通空格，也没有出现 `sh`。`bash -c` 完成参数展开和字段分割后，实际执行效果等价于：

    /usr/bin/cat flag.txt

程序于是输出 flag：

    byuctf{g0_t0_j41l_a60941}

## 方法总结

这类字符黑名单 jail 应先区分“输入字符串中出现的字符”和“shell 展开后生成的字符”。`${IFS}`、变量展开、路径名展开等机制都可能在过滤之后补出分隔符。修复时不能依赖删除若干危险字符，而应避免调用通用 shell，或使用固定命令与结构化参数执行。
