# CPSC233 Final

## 题目简述

最终题同时包含栈地址泄漏、短 name 写入、可控格式串、PIE 与 NX。程序还给出一页 RWX 内存供“函数 shellcode”使用。官方利用先借格式串泄漏 PIE 并反复回到 main，整理栈上的指针关系，再构造任意字节写，把 shellcode写入 RWX 页并跳转执行。

## 解题过程

横幅中的 Exam ID 实际泄漏当前栈地址，减去固定偏移可得到 rsp。name 输入会被当成后续 printf 参数指针，因此先写入 rsp-8。反馈字段存在格式串，可用 %10\$s 泄漏保存的返回地址，并用 %10\$hhn 把低字节改到 main 内合适位置：

~~~python
fmt = f"%{ret_low}c%10$hhn||%10$s||"
~~~

由泄漏值减去 main+245 得到 PIE 基址。随后用 %10\$hn 把返回地址改为 main+1，反复进入 main，每次让栈下降 0x30；直到旧、新目标指针只差最低字节，便能通过一次半字写建立新的可控参数。

完成栈整理后，每轮把目标地址放入 name，用反馈格式串同时维持回到 main+120，并通过 %10\$hhn 写一个目标字节。先从 rsp+9 泄漏 RWX 地址并左移还原页基址，再逐字节写入 shellcraft.sh()。最后把返回地址改到 main 前的 pop rbp; ret 序列，使栈上的 RWX 指针成为控制流目标。

获得 shell 后读取：

~~~text
maple{r34d_5h3llc0d3_u51n6_5h3llc0d3}
~~~

该值与 Assignment 3 重复，但 challenge.yml 与部署 flag 文件一致，应视为官方接受值。

## 方法总结

复杂格式串利用应拆为四个可验证原语：地址泄漏、控制流循环、任意地址写和最终跳转。本题源码与二进制略有差异，偏移必须以发布二进制为准。重复 flag 是仓库事实，不应擅自“修正”为猜测值。
