# BLAST

## 题目简述

BLAST 是一个以 Fortran 编写的 16 维矩阵交互程序：菜单可以打印变换矩阵 `B`、接收向量 `A` 做前向乘法、再做反向乘法并打印结果。程序关闭了栈保护（构建脚本使用 `-fno-stack-protector`），并把 flag 读入静态变量。

漏洞来自 Fortran 数组默认以 1 为起始下标，而 `READ_MATRIX`、`PRINT_MATRIX` 和 `MATVECMUL` 的循环却均从 0 开始。对声明为 `A(M, N)` 的数组访问 `A(0, 0)` 已经越界。题目提示中的“one-indexed language”正是这一点。

## 解题过程

### 把越界访问变成可逆的泄漏

数组元素是 8 位无符号数，矩阵运算等价于模 $256$ 的线性代数。先选择菜单 1 得到完整的 $16\times16$ 矩阵 $B$；官方 solver 验证它在 $\mathbb{Z}/256\mathbb{Z}$ 上可逆。随后直接执行“反向”路径，此时程序会以错误的下标把栈附近的 16 字节作为结果 `A` 打印出来。

由于反向运算计算的是 $A=B\cdot C$，求解端可计算：

$$C=B^{-1}A\pmod {256}$$

这恢复了被矩阵变换掩盖的原始越界内容。官方脚本将前 8 字节作为栈地址泄漏、后 8 字节作为 PIE 代码地址泄漏，并据此计算可重入输入循环的位置。

```python
B = print_transform(conn)
assert B.is_invertible()

leaked_a = vector(backward_pass(conn))
raw = B.inverse() * leaked_a
stack_leak = u64(bytes(raw[:8])) >> 8
pie_leak = u64(bytes(raw[8:])) >> 8
```

### 受限写入与栈迁移

前向路径接收攻击者给出的向量，并计算 $C=B\cdot A$，同样由于 0 下标可向栈外写入。写入空间只有一个向量，不能容纳完整 ROP 链；官方利用因此只伪造保存的帧指针与返回地址，让函数返回后栈迁移到静态 flag 缓冲区附近。

构造方式是先选择目标 16 字节 `want`：其中包含新 `rbp` 与返回到主循环输入点的地址，再将

$$A=B^{-1}\cdot want\pmod {256}$$

作为前向输入。越界写入的结果恰好是 `want`。此时新的栈帧覆盖/贴近保存 flag 的静态区域，下一次菜单 1 打印 `B` 时会将该内存解释为矩阵元素输出，从而得到 flag。

### 验证

官方 `solve.py` 的最后一步再次调用 `print_transform()`，将返回的矩阵按字节拼接后输出；这正是静态 flag 区与伪造栈帧重叠的验证。本文依据官方 solver、Fortran 源码和提示推导，未运行二进制或 solver。

## 方法总结

- 核心技巧：利用 Fortran 默认 1 下标与手写 0 起始循环的错配，建立模 $256$ 的越界读写变换。
- 识别信号：Fortran/C 等不同数组下标约定混用，且代码把数组边界作为参数传递时，应逐一核对声明范围与循环端点。
- 复用要点：线性变换型越界 primitive 先求可逆矩阵把泄漏还原；写入空间不足时，优先考虑用最小覆盖做 stack pivot，再借正常功能完成后续泄漏。
