# V for Vieta

## 题目简述

每轮服务给出一个完全平方数 $k=r^2$，要求提交足够大的正整数 $a,b$，满足：

$$
\frac{a^2+ab+b^2}{2ab+1}=k.
$$

初始 `level` 为 2048，随后每轮减少五分之一；但 `target` 始终为 2048，因此必须在每轮把解增长到超过 2048 位。题目名称提示把二元二次方程视为关于一个未知量的二次式并做韦达跳跃。

## 解题过程

将等式整理为：

$$
a^2+(1-2k)ab+b^2-k=0.
$$

固定 $a$ 并把它看作 $b$ 的二次方程。若 $b$ 是一根，另一根的和为 $(2k-1)a$，故另一根为：

$$
b'=(2k-1)a-b.
$$

题目保证 $k$ 是平方数，所以起点 $(a,b)=(\sqrt{k},0)$ 已满足方程，只是不符合 $b>0$ 和位长约束。反复应用韦达跳跃并交换两个变量，正整数解快速增长：

```python
a, b = isqrt(k), 0
while a.bit_length() <= 2048 or b.bit_length() <= 2048:
    b = (2 * k - 1) * a - b
    assert (a*a + a*b + b*b) // (2*a*b + 1) == k
    a, b = b, a
```

官方 `solve/solve.py` 每轮取得新 $k$ 后重复这一步，提交 JSON `{"a": a, "b": b}`。服务在 `level <= 8` 时返回：

```text
DUCTF{jump1n6_4nd_fl1pp1n6_up_7h3_hyp3r8011c_14dd3r}
```

过程不需要分解 $k$，只使用整数平方根和精确整数运算。

## 方法总结

对称二次丢番图方程常可从一个平凡根出发，通过“另一根 = 根和减已知根”生成新解。必须保留整数精度并在每次跳跃后验证原式；浮点平方根或先做有损除法会破坏等式。这里服务只检查方程和位长，未限制解的增长，因此韦达跳跃正好绕过固定目标位长。
