# MiniLCTF2023 - curvesignin

## 题目简述

题目只给出若干点和一套非标准点加法。整理运算公式后可知这些点位于未知素域上的广义曲线

$$
cy^2=dx^3+ax+b.
$$

模数 $p$ 以及 $a,b,c,d$ 都未直接给出。需要先从多个点恢复曲线参数和模数，再把曲线变换成 Sage 支持的短 Weierstrass 形式，最后求离散对数并判断其对基点阶的提升。

## 解题过程

方程对 $a,b,c,d$ 齐次，可固定 $d=1$ 消除尺度自由度。对生成元和五个给定点分别建立

$$
x_i^3+ax_i+b-cy_i^2\equiv0\pmod p.
$$

在整数多项式环中求这些式子的 Gröbner 基，会得到一个纯整数；分解它并结合点坐标范围可确定

```text
p = 878502880971205563250537
a = 373244437522236692557633
b = 776663746981095848389651
c = 359706841382695634146800
```

将原方程乘以 $c^3$，令 $X=cx$、$Y=c^2y$，得到

$$
Y^2=X^3+(c^2a)X+c^3b.
$$

于是可以在标准椭圆曲线上求 $P=dG$。核心 Sage 代码如下：

```python
from Crypto.Util.number import long_to_bytes
from sage.all import EllipticCurve, GF, Integer

p = 878502880971205563250537
a = 373244437522236692557633
b = 776663746981095848389651
c = 359706841382695634146800

G_raw = (543964449142803087188784, 288605946000947449279542)
P_raw = (793604064853039619406880, 93386361837996865025986)

E = EllipticCurve(GF(p), [c**2 * a % p, c**3 * b % p])
G = E(c * G_raw[0] % p, c**2 * G_raw[1] % p)
P = E(c * P_raw[0] % p, c**2 * P_raw[1] % p)

order = Integer(G.order())
d = Integer(P.log(G))
for k in range(4):
    candidate = long_to_bytes(G_raw[0]) + long_to_bytes(d + k * order)
    print(candidate)
```

实际计算得到

```text
order = 439251440486032596897638
d = 77561004929098652492298
```

其中 $d+order$ 对应可读结果：

```text
miniLCTF{s0_3@5y_c0mput3__d1p}
```

## 方法总结

未知曲线参数可以通过“所有已知点必须同时满足曲线方程”转成消元问题；Gröbner 基中的整数往往是模数的倍数，仍需分解和代回验证。广义曲线不能直接交给标准椭圆曲线 API 时，应先找变量缩放。离散对数只确定模子群阶的标量，因此还要枚举 $d+k\,\mathrm{ord}(G)$，再用编码格式筛选真正消息。
