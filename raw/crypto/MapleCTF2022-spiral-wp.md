# spiral

## 题目简述

完整版 `spiral` 使用与 `spiral-baby` 相同的 16 字节 SPN，但增加到四轮，并在前三轮加入可逆线性混合。状态运算都在模 255 环上完成，末轮没有 Mix 层。单字节相关性不再直接可见，但 255 个取值组成的饱和集合在前三轮后仍保留积分性质。

## 解题过程

对每个字节位置构造一组 255 个明文：该位置遍历 $0..254$，其余字节固定。四轮加密后，猜测相同位置的末轮密钥字节 $k$，撤销末轮加密和 S 盒：

$$
x_i=S^{-1}((C_i[pos]-k)\bmod255).
$$

正确猜测下，这 255 个 $x_i$ 是前三轮输出的一条积分平衡分量，满足

$$
\sum_{i=0}^{254}x_i\equiv0\pmod{255}.
$$

错误猜测也可能偶然通过，因此对同一位置使用多组不同的固定字节，持续取候选集合交集，直到只剩一个值：

```python
possible = set(range(255))
while len(possible) > 1:
    pts = make_balanced_set(pos)
    cts = encrypt_many(pts)
    keep = set()
    for k in range(255):
        total = sum(INV_SBOX[(ct[pos] - k) % 255] for ct in cts)
        if total % 255 == 0:
            keep.add(k)
    possible &= keep
```

恢复的是第 4 轮密钥。密钥计划每轮只做一次 `spiralLeft`；连续四次螺旋旋转会回到原布局，因此这 16 个字节正好也可作为构造器需要的初始密钥。解密密文得到：

```text
maple{sp1r4l!ng_squ4r3s_2f220b}
```

## 方法总结

积分攻击关注一整组选择明文经过若干轮后的求和平衡，而不是单对明文的差分。末轮缺少线性混合使攻击者能逐字节撤销最后一层。候选过滤必须使用多组独立结构并取交集，否则模 255 环中的偶然零和会产生假阳性；最后还要核对轮密钥与初始密钥之间的位置变换。
