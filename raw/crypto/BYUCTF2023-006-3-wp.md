# BYUCTF 2023 - 006 III

## 题目简述

附件给出四个 SHA-512 摘要。所有口令都遵循相同的弱策略：固定前缀 `goldeneye` 后接三位十进制数字。

## 解题过程

候选总数只有 1000，可直接生成：

```python
with open('goldeneye.txt', 'w') as f:
    for i in range(1000):
        f.write(f'goldeneye{i:03d}\n')
```

使用 Hashcat 的原始 SHA-512 模式 1700：

```bash
hashcat -m 1700 006_3.txt goldeneye.txt
hashcat -m 1700 006_3.txt --show
```

按附件中的摘要顺序恢复四个口令：

```text
goldeneye007
goldeneye641
goldeneye069
goldeneye159
```

拼接为：

```text
byuctf{goldeneye007_goldeneye641_goldeneye069_goldeneye159}
```

## 方法总结

慢一点的哈希不能弥补只有 1000 个候选的口令策略。发现多个账户共享模式后，应抽象规则并穷举规则空间，而不是为每个摘要分别跑大字典。
