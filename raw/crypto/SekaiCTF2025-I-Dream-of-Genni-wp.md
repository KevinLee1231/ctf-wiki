# I Dream of Genni

## 题目简述

题目定义了一种“梦中乘法”：取八位数 $x$ 的首位，再把 $x$ 的其余各位依次与七位数 $y$ 的对应位相乘，将十进制结果直接拼接。需要找到一组 $(x,y)$，使这种拼接结果恰好等于正常整数乘积 $x\cdot y$。

题面给出了被禁止的示例解。将首位数字 `3` 与后续七组逐位乘积直接拼接，可写成：

```text
3 || (9×9) || (8×5) || (7×6) || (6×4) || (8×5) || (7×4) || (7×6)
= 3 || 81 || 40 || 42 || 24 || 40 || 28 || 42
= 381404224402842

39876877 × 9564546 = 381404224402842
```

两种计算结果相同，因而 `(39876877, 9564546)` 满足“梦中乘法”等于普通乘法；服务端只是专门排除了这组公开示例。

服务端排除了示例中的已知数对，因此需要寻找第二组解。找到数对后，以 Python 元组字符串的 SHA-256 作为 AES 密钥解密 flag。

## 解题过程

### 1. 把字符串条件转为低位同余

若逐位乘积均为两位数，拼接后的低 $2k$ 位只由最后 $k$ 对数字决定。可以从个位向高位 DFS，每加入一对数字，就检查当前拼接值与普通乘积是否满足：

$$
\operatorname{dream}(x,y)\equiv xy\pmod{10^{2k}}.
$$

官方求解器要求所选数位乘积至少为 10，使每一段固定占两位，避免前导零和一位数造成分段歧义。

伪代码如下：

```python
def dfs(pos, x_digits, y_digits):
    if pos == 7:
        solve_leading_digit()
        return

    for a in range(1, 10):
        for b in range(1, 10):
            if a * b < 10:
                continue
            append_low_digits(a, b)
            if dream_partial == x_partial * y_partial % modulus:
                dfs(pos + 1, ...)
```

每层只保留满足当前模数的分支，搜索空间会迅速缩小。

### 2. 求首位并筛选完整等式

递归确定七组低位后，剩下 $x$ 的最高位。枚举 $1\ldots9$，构成完整八位数并检查：

```python
if dream_multiply(x, y) == x * y:
    solutions.append((x, y))
```

官方脚本得到两组：

```text
(39876877, 9564546)
(49228443, 9773647)
```

第一组正是题面图片中的示例，会被服务端拒绝；提交第二组：

```text
x = 49228443
y = 9773647
```

### 3. 派生密钥并解密

密钥不是两个数的二进制拼接，而是 Python 对元组的字符串表示：

```python
pair = (49228443, 9773647)
key = hashlib.sha256(str(pair).encode()).digest()
plain = AES.new(key, AES.MODE_ECB).decrypt(ciphertext)
```

解密结果为：

```text
SEKAI{iSOgenni_in_mY_D1234M5;_iS_it_T00_s00n}
```

## 方法总结

表面上的巨大整数等式可以按十进制拼接的局部性拆成逐层模约束。由低位向高位搜索时，每扩展一层立即检查模 $10^{2k}$ 的一致性，比完整枚举两个大整数高效得多。

实现派生密钥时要严格复现服务端序列化格式。`str((x, y))` 包含括号、逗号和空格，任何自定义拼接都会得到不同的 SHA-256。
