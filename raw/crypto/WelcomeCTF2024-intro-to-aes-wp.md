# Intro to AES

## 题目简述

服务使用同一随机密钥执行 AES-ECB，并提供加密与解密接口。加密接口拒绝任何包含 `gimme the flag!!` 的明文；解密接口只要解出的任意位置包含该字符串，就返回 flag。目标是在不知道密钥的情况下构造满足检查的密文。

## 解题过程

ECB 独立加密每个 16 字节分组：相同密钥下，某个明文块的密文只由该块自身决定。限制检查发生在完整明文上，但可以分别请求目标字符串的两个片段，让它们各自对齐到块边界，再拼接对应密文块。

目标长 16 字节，拆为两个 8 字节片段。第一次加密 8 个空格加前 8 字节，使前半目标位于一个完整块的后半部分；第二次单独加密后 8 字节，PKCS#7 会把它补成一个完整块。取两次结果的首块拼接：

```python
target = b"gimme the flag!!"

ct1 = encrypt(b" " * 8 + target[:8])
ct2 = encrypt(target[8:])
payload = ct1[:16] + ct2[:16]
```

解密 `payload` 后，第一块末尾是 `gimme th`，第二块开头是 `e flag!!`，跨块连续组成目标字符串。服务端的子串检查成立并返回：

```text
grey{wow_aes_is_so_fun_right}
```

## 方法总结

ECB 不提供分组之间的关联与完整性保护，攻击者可以剪切、重排和拼接独立密文块。遇到“禁止直接加密目标、但解密后检查目标”的接口，应优先检查是否能通过块对齐绕过明文过滤。
