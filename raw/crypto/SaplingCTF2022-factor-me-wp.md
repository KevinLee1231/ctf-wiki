# Factor Me

## 题目简述

题目给出 RSA 公钥参数 $N=640203263008444282715761$、$e=65537$ 和密文 $c=400260416204680499515181$。两个素因子都只有约 40 位，模数远小于正常 RSA，因此可以直接分解后计算私钥。

## 解题过程

分解得到：

$$
p=773368062113,\qquad q=827811871697,
$$

并验证 $pq=N$。随后计算欧拉函数、私钥指数和明文：

~~~python
from Crypto.Util.number import long_to_bytes

N = 640203263008444282715761
e = 65537
c = 400260416204680499515181
p = 773368062113
q = 827811871697

assert p * q == N
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)
m = pow(c, d, N)
print(long_to_bytes(m))
~~~

输出为 f@cTor!ng。题面要求用赛事格式包裹，因此最终 flag 是：

~~~text
maple{f@cTor!ng}
~~~

## 方法总结

RSA 的安全性要求模数足够大且由高质量随机素数生成。本题的数学流程没有异常，弱点完全来自因子过小。拿到 RSA 参数后应先做低成本检查：模数位数、公共因子、近素数、低指数、已知数据库和常见素数生成缺陷，再决定是否需要更复杂的攻击。
