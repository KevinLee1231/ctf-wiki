# BYUCTF 2023 - 006 II

## 题目简述

第二个密码摘要为 SHA-1。口令不在普通小字典中，但题面采用《GoldenEye》背景，并提示围绕角色 Alec 的经历构造定向字典。

## 解题过程

从 Alec Trevelyan 的背景资料提取地点、组织和专有名词，保持原始大小写。候选 `Arkhangelsk` 是剧情中的关键地名。用 SHA-1 直接验证或以 Hashcat 模式 100 跑定向词表：

```bash
hashcat -m 100 006_2.txt alec-words.txt
hashcat -m 100 006_2.txt --show
```

恢复口令后得到：

```text
byuctf{Arkhangelsk}
```

## 方法总结

当通用字典失败时，题目叙事往往就是口令策略线索。定向字典应包含实体名、地点、别名和大小写变体；SHA-1 仍然很快，真正决定成本的是候选空间质量。
