# GreyCTF 2023 Smart

## 题目简述

服务在四个小模数的状态空间上定义映射 $f$，再按输入自身决定的次数迭代：

$h(v)=f^{5555+(v_0v_1v_2v_3\bmod3000000)}(v)$。

服务只给出某个随机秘密的 `h(secret)`，要求提交任意合法状态产生相同结果。无需反演复杂多项式；目标状态所在的函数图最终落在环上，可以沿环寻找满足迭代次数的另一个原像。

## 解题过程

把服务给出的 `target` 作为起点反复计算 $f$，直到再次回到 target。若在 $C$ 步后回到起点，就得到了该目标所在环的长度；如果在 3000000 步内没有回到，则断开并获取新实例。

随后再次从 target 开始枚举

$v_i=f^i(\text{target}),\quad 0\le i<C$。

从 $v_i$ 出发执行 $h$，相对于 target 总共前进

$i+5555+(v_{i,0}v_{i,1}v_{i,2}v_{i,3}\bmod3000000)$

步。只要该值是 $C$ 的倍数，结果便重新落到 target。官方脚本在当前实例中直接寻找等于 $C$ 的情况：

```python
v = target
for i in range(cycle_len):
    k = 5555 + (v[0] * v[1] * v[2] * v[3]) % 3000000
    if k + i == cycle_len:
        answer = v
        break
    v = f(v)
```

将找到的四元组提交即可通过校验，服务返回：

```text
grey{hello_smart_admin_;D_hRkPxgxcMB7Yxk4e}
```

## 方法总结

有限状态上的任意确定性函数都会形成“入树加环”的函数图。题目只比较输出而不要求恢复原秘密，因此应寻找碰撞原像而不是硬解非线性方程。把输入相关的迭代次数与环上位置合并成模环长条件，就能将问题降为一次顺序遍历。
