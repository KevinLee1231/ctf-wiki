# Austen Supremacy

## 题目简述

题面给出一串 `章节.段落.字母` 形式的三元组，并明确暗示 Jane Austen 的《Pride and Prejudice》。这是一道书本密码题：每个三元组依次定位章节、段落以及该段中的字母。

## 解题过程

选用章节和段落划分与题目一致的《傲慢与偏见》全文。计数字母时忽略空格、引号与标点，只统计英文字母。按此规则逐项定位，可得到：

```text
1.1.1   -> i
8.9.8   -> l
10.2.11 -> o
4.14.28 -> v
61.2.4  -> e
47.10.3 -> d
23.7.37 -> a
41.12.4 -> r
17.6.10 -> c
1.1.21  -> y
```

拼接为 `ilovedarcy`。Project Gutenberg 提供了可复现定位所需的[《Pride and Prejudice》公开全文](https://www.gutenberg.org/files/1342/1342-h/1342-h.htm)；若换用其他版本，必须先确认章节、段落划分没有被排版重组。

最终得到：

```text
byuctf{ilovedarcy}
```

## 方法总结

书本密码不仅要识别坐标含义，还要固定文本版本与计数规则。遇到一项偏移时，应优先检查段落划分、标题是否计入以及标点是否被跳过，而不是立即修改坐标。
