# Blind

## 题目简述

附件是一串由盲文字符组成的文本。题名与字符形态共同指向 Braille 编码；决定性步骤是按盲文点位表把每个 Unicode 盲文符号还原成普通字符。

## 解题过程

先保留原始字符边界，不要在复制时把多个盲文单元合并。按六点盲文编号读取每个符号，映射为字母、数字和标点；数字指示符后的单元按数字解释，大写指示符则作用于其后的字母。连续解码并按题目给出的大小写整理后得到：

```text
n00bz{4nd_1f_y0u_4sk_m3_h0w_Im_f33l1ng_D0n'7_t3ll_m3_y0u'r3_7o0_bl1nd_7o_s33}
```

## 方法总结

盲文题的难点通常不在密码强度，而在符号系统和上下文状态。解码时应同时处理数字、大写和标点指示符，并用 flag 格式校验结果，避免只做逐字符静态替换而丢失状态。
