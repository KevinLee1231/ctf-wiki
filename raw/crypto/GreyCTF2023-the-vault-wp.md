# GreyCTF2023 The Vault

## 题目简述

服务令 $n=10^{128}$，接收整数 $a,b$ 后计算 $x=a^b\bmod n$。两把 AES-CTR 密钥分别为 `SHA256(x)` 与 `SHA256(x^10 mod n)`，并用相同 nonce 对随机校验串连续加密。若能令 $x^{10}\equiv x\pmod n$，两次 CTR 使用相同密钥流，异或两遍后明文保持不变。

## 解题过程

$n=2^{128}5^{128}$。这里不能直接套用“模 $n$ 的单位群”思路，因为官方构造的 $a$ 并不与 $n$ 互素；它利用中国剩余定理构造一个非平凡幂等元。取：

```python
n = 10**128
a = pow(2, 10**127, n)
b = 10
```

指数远大于 128，所以 $a\equiv0\pmod{2^{128}}$。另一方面，$10^{127}=2^{127}5^{127}$ 是 $\varphi(5^{128})=4\cdot5^{127}$ 的倍数，因此由 Euler 定理

$a=2^{10^{127}}\equiv1\pmod{5^{128}}$。

于是 $a$ 在两个 CRT 分量上分别为 0 和 1，满足 $a^m\equiv a\pmod n$（任意 $m\ge1$）。服务计算

$x=a^{10}\equiv a$，继而 $x^{10}\equiv x$。

两次 `sha256(long_to_bytes(...))` 得到完全相同的 AES 密钥；CTR nonce 又固定为 `Greyhats`，于是

$(P\oplus S)\oplus S=P$。

校验通过并返回：

```text
grey{th3_4n5w3R_T0_Th3_3x4M_4nD_3v3ry7H1N6_1s_42}
```

## 方法总结

双重加密并不必然更安全。对于流模式，同一密钥与 nonce 产生同一密钥流，连续异或两次会完全抵消。本题通过模环中的非平凡幂等元让两个派生输入相同；分析这类校验时，应先把密码调用化简成代数条件，再分别在素数幂 CRT 分量上构造所需元素。
