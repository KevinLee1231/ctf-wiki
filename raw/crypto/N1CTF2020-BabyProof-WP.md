# N1CTF 2020 BabyProof Writeup

## 题目简述

题目给出一组类似 Schnorr/DSA 证明的交互记录。秘密为整数 $x$，每轮随机数 $v_i$ 只从 $[1,x]$ 取值，而模数 $q_i$ 约为 256 位、$x$ 约为 247 位。响应满足：

$$
r_i \equiv v_i-c_i x \pmod{q_i}.
$$

因为 $v_i$ 显著小于 $q_i$，每条记录都泄露一个“模方程中的小误差”。收集足够多样本后可用格规约恢复 $x$。

## 解题过程

### 收集样本并写成隐藏数问题

每次证明记录包含 $(q_i,c_i,r_i)$。把同余式改写为：

$$
c_i x+r_i=k_iq_i+v_i,qquad 0<v_i<2^{247}.
$$

$k_i$ 未知，但右端误差 $v_i$ 相对 $q_i$ 很小。这正是 Hidden Number Problem 的典型形式。公开求解记录使用约 44 到 60 组样本；样本越多，目标短向量越容易与随机格向量区分。

### 构造格并执行 LLL

对 $m$ 组样本构造 $(m+2)\times(m+2)$ 整数格。前 $m$ 行放对角模数，倒数第二行放挑战系数，最后一行放响应：

```python
M = Matrix(ZZ, m + 2, m + 2)
for i in range(m):
    M[i, i] = q[i]
    M[m, i] = c[i]
    M[m + 1, i] = r[i]

M[m, m] = 1
M[m + 1, m + 1] = 2^246
```

最后一维的 $2^{246}$ 是公开求解脚本按 247 位上界选取的平衡尺度；在 $2^{246}$ 到 $2^{247}$ 附近微调也可能成功。缩放的目的，是让由小误差 $v_i$ 组成的目标向量在欧氏长度上明显偏短。对 `M.LLL()` 的结果检查末两维和符号关系，可以从短向量中读出 $x$；不同实现可能把 $x$ 放在倒数第二维或以负数出现，所以应把候选带回全部同余式验证：

$$
v_i=(r_i+c_ix)\bmod q_i<2^{247}.
$$

### 恢复 flag

源码把 flag 直接编码为秘密 $x$。将验证通过的整数转回大端字节即可：

```python
flag = int(x).to_bytes((x.bit_length() + 7) // 8, 'big')
```

仓库中的真实秘密为：

```text
n1ctf{S0me_kn0wl3dg3_is_leak3d}
```

## 方法总结

零知识协议的代数形式正确，并不意味着实现安全。随机 nonce 的范围、偏差或复用都会把秘密转成隐藏数问题。格攻击后必须做原方程验证：LLL 只给出短向量候选，不会自动证明某一坐标就是秘密。生产实现应使用密码学安全随机源，并在完整模数范围内均匀采样 nonce。
