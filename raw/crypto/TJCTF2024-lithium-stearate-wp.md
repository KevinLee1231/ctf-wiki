# lithium-stearate

## 题目简述

题目实现一个 16 bit 分组、100000 轮的自定义 SPN。附件给出 20 组明密文对和逐 2 字节加密的 flag。表面上轮数极大、主密钥为 64 bit，但密钥调度中的 C++ `switch` 没有任何 `break`，所有分支都会贯穿到最后一个 `case`。结果是掩码不随轮号变化，而后续逻辑仅按 `i % 4` 生成四个轮密钥：整个加密只是同一个 4 轮置换 $F$ 重复 25000 次。

## 解题过程

出题程序在 18 组随机明密文之外，额外构造了一对 slid pair：随机取 $p_0$，令

$$
p_1=F(p_0),
$$

再分别计算 $c_0=E(p_0)$、$c_1=E(p_1)$。由于 $E=F^{25000}$，必有

$$
c_1=F(c_0).
$$

这两组记录被打乱混入 20 组输出，因此枚举所有有序对即可覆盖真正的 slid pair。

进一步检查轮函数可知，32 bit 轮密钥进入 16 bit 数据路径时只使用高、低 16 bit 的异或。四轮超轮可压缩成两个有效未知量：第一轮的 16 bit 异或量 `k0x`，以及上下 32 bit 密钥异或得到的 24 bit 有效量 `lxr`。对每一对候选记录，穷举 `lxr`，再由第一轮前后的关系直接导出 `k0x`，检查下面两条关系：

```text
F(p0, k0x, lxr) == p1
F(c0, k0x, lxr) == c1
```

官方 `solve.h` 的核心搜索等价于：

```cpp
for (uint32_t lxr = 0; lxr < (1u << 24); ++lxr) {
    uint16_t k0x = recover_first_round_xor(p0, p1, lxr);
    if (super_round(p0, k0x, lxr) != p1)
        continue;
    if (super_round(c0, k0x, lxr) != c1)
        continue;
    // 命中后，用逆超轮重复 25000 次解密每个 flag 分组。
}
```

找到参数后，对每个 flag 密文块执行 $F^{-25000}$，按原程序的小端 2 字节顺序拼接，得到：

```text
tjctf{Lft-ft2-stomps/$$1i!de-2-the[left}
```

## 方法总结

- 极高轮数并不自动安全；密钥调度贯穿让轮结构周期缩短为 4，直接满足滑动攻击条件。
- slid pair 的关键关系同时出现在明文端和密文端，能把重复轮置换的密钥恢复问题变成局部匹配问题。
- 本题还主动把一对 slid pair 混入样本。审计生成器时必须关注“随机样本之外”的特殊数据构造，不能只盯着加密函数本身。
