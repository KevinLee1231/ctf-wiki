# RSA?

## 题目简述

题目生成两个 256 位素数 $p,q$ 和一个 512 位素数 $r$，却令 $n=pq+r$，再使用指数 $e=2$ 计算 $c=m^2\bmod n$。虽然代码外观像“结构异常的 RSA”，实际给出的 $n$ 本身是素数，因此问题退化为有限域 $\mathrm{GF}(n)$ 上开平方根。

## 解题过程

题目给出：

```python
c = 2166906408965390116437761185603075699086315246646982132520792868301615462732707695943058783211233589602162482847874299962577512765886861573898075548033678
q = 95476159140358852660572143425801843414366266400633576268276298731539374363607
n = 7236834786093916009325417235344284284391050287273422058348241360770131423240807259717864686885012301293921328397391157761688776563780348734483657156421779
```

已知的 $q$ 并不能直接把 $n$ 分解，因为 $n$ 不是 $pq$。先做素性测试会发现 $n$ 为素数，且：

$$
n \equiv 3 \pmod 4.
$$

对于素数模数 $n\equiv3\pmod4$，二次剩余 $c$ 的平方根可以直接计算为：

$$
m \equiv c^{(n+1)/4}\pmod n.
$$

另一个根是 $n-m$。把两个候选都转成大端字节，选择满足 `hgame{...}` 格式的一个：

```python
c = 2166906408965390116437761185603075699086315246646982132520792868301615462732707695943058783211233589602162482847874299962577512765886861573898075548033678
n = 7236834786093916009325417235344284284391050287273422058348241360770131423240807259717864686885012301293921328397391157761688776563780348734483657156421779

assert n % 4 == 3
root = pow(c, (n + 1) // 4, n)

for value in (root, n - root):
    message = value.to_bytes((value.bit_length() + 7) // 8, "big")
    if message.startswith(b"hgame{"):
        print(message.decode())
```

输出：

```text
hgame{eaa5262c-4631-46ef-a97b-53277ab7e1d8}
```

## 方法总结

- 核心判断：不要被变量名和 `p*q+r` 迷惑，先直接检查最终模数 $n$ 的数学性质。
- 关键公式：当素数 $n\equiv3\pmod4$ 时，可用 $c^{(n+1)/4}$ 快速开平方；一般情形再使用 Tonelli–Shanks。
- 复用要点：模素数平方根通常有 $m$ 与 $n-m$ 两个候选，应结合已知消息格式筛选。
