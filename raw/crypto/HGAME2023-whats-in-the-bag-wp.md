# 包里有什么

## 题目简述

题目给出一组具有特殊结构的背包权重、模数 $m$、公开权重 $b_0$ 和密文 $c$。已知私有权重的首项为 $a_0=2$，公开权重满足

$$
b_0 \equiv a_0w \pmod m,
$$

而密文是所选公开权重之和。目标是恢复乘数 $w$ 的逆向作用，将密文还原为由二进制选择位组成的明文。

题目中的关键参数为：

```text
m  = 1528637222531038332958694965114330415773896571891017629493424
b0 = 69356606533325456520968776034730214585110536932989313137926
c  = 93602062133487361151420753057739397161734651609786598765462162
```

## 解题过程

通常会尝试计算 $w^{-1}\bmod m$，但这里 $a_0=2$ 且 $m$ 为偶数，因此 $\gcd(a_0,m)=2$，直接把 $a_0$ 当作可逆元并不成立。与此同时，题目所用旧版逆元实现会在最大公因数不为 $1$ 时仍返回扩展欧几里得系数，这正是解题时需要复现的行为。

对 $b_0$ 和 $m$ 运行扩展欧几里得算法，求出 $x$ 使

$$
b_0x+my=2.
$$

于是有 $b_0x\equiv 2\pmod m$。将整个密文乘以 $x$ 后，每个背包权重都被还原为原私有权重的两倍，因此再除以 $2$ 即可取得选择位组成的整数：

$$
v=\frac{(cx\bmod m)}{2}.
$$

题目的私有权重按二进制位构造，但位序与直接转字节时相反，所以要先翻转二进制字符串，再按字节解释：

```python
m = 1528637222531038332958694965114330415773896571891017629493424
b0 = 69356606533325456520968776034730214585110536932989313137926
c = 93602062133487361151420753057739397161734651609786598765462162


def xgcd(a: int, b: int) -> tuple[int, int, int]:
    old_r, r = a, b
    old_s, s = 1, 0
    old_t, t = 0, 1
    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
        old_t, t = t, old_t - q * t
    return old_r, old_s, old_t


g, x, _ = xgcd(b0, m)
assert g == 2

selected = (c * x % m) // 2
bits = bin(selected)[2:][::-1]
bits += "0" * (-len(bits) % 8)
plain = int(bits, 2).to_bytes(len(bits) // 8, "big")
print(plain.rstrip(b"\x00").decode())
```

运行后得到：

```text
hgame{1t's_4n_3asy_ba9_isn7_it?}
```

## 方法总结

这道题的易错点不是背包本身，而是“逆元不存在”这一异常条件。遇到旧密码代码时，不能只按现代密码库的接口语义复写；应检查最大公因数，并从扩展欧几里得等式还原原实现实际返回的系数。这里利用 $\gcd(b_0,m)=2$ 得到二倍关系，再整除 $2$，即可恢复选择位。
