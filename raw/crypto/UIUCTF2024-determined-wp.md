# Determined

## 题目简述

服务固定保存 RSA 素数 $p$、$q$ 和另一个秘密整数 $r$。每次连接允许填写一个稀疏 $5\times5$ 矩阵的 9 个公开位置，随后用 Leibniz 公式返回行列式。RSA 公共参数 $N=pq$、$e=65535$ 和密文位于 `gen.txt`。目标是选择矩阵元素，让行列式分别泄漏 $q$、$r$ 和 $pr$，从而恢复两个 RSA 因子。

## 解题过程

把可控位置依次记为 $a,b,c,d,e_0,f,g,h,j$，矩阵为：

$$
M=\begin{pmatrix}
p&0&a&0&b\\
0&c&0&d&0\\
e_0&0&f&0&g\\
0&q&0&r&0\\
h&0&j&0&0
\end{pmatrix}.
$$

用符号运算展开行列式可得：

$$
\det(M)=(-qd+rc)(-pgj+agh+be_0j-bfh).
$$

因此只需发起三次连接，并按服务提示依次输入 `(a,b,c,d,e0,f,g,h,j)`：

```text
(1,0,0,-1,0,0,1,1,0)  -> q
(1,0,1, 0,0,0,1,1,0)  -> r
(0,0,1, 0,0,0,1,0,-1) -> p*r
```

第三次结果除以第二次结果即可得到 $p$。下面代码省略了与远端逐提示交互的重复部分，只保留恢复逻辑：

```python
from Crypto.Util.number import long_to_bytes

# oracle(values) 建立一次新连接，按顺序发送 9 个整数并返回行列式。
q = oracle((1, 0, 0, -1, 0, 0, 1, 1, 0))
r = oracle((1, 0, 1,  0, 0, 0, 1, 1, 0))
pr = oracle((0, 0, 1, 0, 0, 0, 1, 0, -1))
p = pr // r

assert p * q == N
phi = (p - 1) * (q - 1)
d = pow(65535, -1, phi)
print(long_to_bytes(pow(ciphertext, d, N)))
```

仓库本地实例输出的明文前缀仍是旧队名 `sigpwny`，赛事配置中的标准提交前缀为 `uiuctf`。有效答案是：

```text
uiuctf{h4rd_w0rk_&&_d3t3rm1n4t10n}
```

## 方法总结

- 核心技巧：把看似复杂的排列求和识别为行列式，符号展开后通过稀疏赋值隔离秘密因子。
- 识别信号：代码遍历全部排列、按逆序数奇偶添加符号并连乘每列元素，这正是 Leibniz 行列式公式。
- 复用要点：不同连接必须复用同一组服务端秘密；得到候选后应验证 $pq=N$，再计算 RSA 私钥，不能只凭行列式数值猜测。
