# 进制十六——参上

## 题目简述

题面给出一串按空格分组的十六进制字节。它不是密码算法产生的密文，而是 ASCII 文本的十六进制表示；目标是把每两个十六进制字符还原为一个字节，再按文本解码。

## 解题过程

先去掉所有空白，再进行 hex 解码。命令行可以直接使用 `xxd`：

```powershell
'20666C61677B5930555F5348305531445F6B6E30775F4830575F74305F43306E763372745F4845585F746F5F546578547D20466F72206578' |
    xxd -r -p
```

也可以用 Python 明确表示转换过程：

```python
hex_text = """20666C61 677B5930 555F5348 30553144 5F6B6E30
775F4830 575F7430 5F43306E 76337274 5F484558
5F746F5F 54657854 7D20466F 72206578"""

raw = bytes.fromhex(hex_text)
print(raw.decode("ascii"))
```

输出中夹有题面装饰文字，花括号包围的部分即为：

```text
flag{Y0U_SH0U1D_kn0w_H0W_t0_C0nv3rt_HEX_to_TexT}
```

## 方法总结

- 核心技巧：把十六进制视为字节表示，而不是需要分析的加密算法。
- 识别信号：字符只来自 `0-9a-fA-F`，去掉空白后长度为偶数，解码后大量字节落在可打印 ASCII 范围。
- 复用要点：`bytes.fromhex` 会自动忽略空白；若结果不可读，再检查字节序、字符编码或是否还有下一层表示。
