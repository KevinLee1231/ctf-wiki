# merkle-master

## 题目简述

服务端要求提交一棵“有序”的完美 Merkle 树，随后随机要求证明 50 个字符串存在或不存在，并抽查 1000 个随机下标。验证器只检查见过的下标是否按字典序排列，没有验证整棵树，因此可以用大量填充叶子掩盖局部乱序。

## 解题过程

将 50 个字符串排序。对每个字符串 $d$，在树中放入三项：

```text
d[:-1]     # 不存在证明的左邻居
d + "_"   # 不存在证明的右邻居
d          # 存在证明
```

左、右两项相邻且满足 `d[:-1] < d < d + "_"`，所以可为任意 $d$ 提交非存在证明；若服务端要求存在，则对第三项提交普通成员证明。虽然三项的物理顺序 `left, right, d` 并不全局有序，但单次随机选择只会暴露 `d` 或 `left/right`，不会自行形成矛盾。

树深取 17，共 $2^{17}$ 个叶子；在三元组前填充大量相同的 `000000000000`：

```python
TREE_DEPTH = 17
target = 1 << TREE_DEPTH
leaves = [b'000000000000'] * (target - 3 * len(required))
leaves += modified_data
```

每个叶子为 `SHA256(data)`，父结点为 `SHA256(left_hash || right_hash)`。官方脚本按根到叶的方向与兄弟哈希生成 JSON 证明。1000 个随机下标大概率只命中巨大填充区，最终“已见数据有序”检查便无法发现尾部乱序；失败时重连重试即可。通过后得到：

```text
tjctf{R4Lph_w0uld_B3_pr0uD}
```

## 方法总结

- Merkle 根只承诺内容与位置，不自动证明全局排序；排序性质必须用覆盖全部相邻关系的协议证明。
- 随机抽查属于概率保证，攻击者可用大量无害叶子稀释异常位置。
- 非存在证明必须同时验证相邻性、左右边界及树的全局有序性；缺少最后一项就会出现本题漏洞。
