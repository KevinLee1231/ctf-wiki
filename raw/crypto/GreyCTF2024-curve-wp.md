# Curve

## 题目简述

题目随机生成 150 位隐藏向量。每组样本给出一个公开二元向量 `factor`，并按其与隐藏向量的内积奇偶性选择两类椭圆曲线元组：内积为 0 时满足 $z=xy$，否则 $x,y,z$ 独立随机。需要从 900 组跨曲线点中识别这些 DH 元组，解出隐藏向量，再解密 flag。

## 解题过程

第一条曲线为 $E_1:y^2=x^3+6$，定义在 $\operatorname{GF}(p)$ 上；每组样本还给出定义在 $\operatorname{GF}(p^2)$ 上的随机曲线 $E_2:y^2=x^3+b_2$。公开点依次包含

$$
g,\;xg,\;yg,\;zg,\;h,\;xh.
$$

当 $z=xy$ 时，希望检验 $e(yg,xh)=e(zg,h)$。两边点不在同一条曲线上，先令 $t=6/b_2$，在扩域

$$
\operatorname{GF}(p^2)[v]/(v^6-t)
$$

上建立 $E_3:y^2=x^3+6$。映射

$$
(X,Y)\longmapsto(v^2X,v^3Y)
$$

可把 $E_2$ 的点送到 $E_3$。对 $E_2$ 点还需乘以余因子 $\#E_2/n$，投影到 $n$ 阶子群。若 $t$ 是二次或三次剩余，或 $n$ 不整除 $\#E_2$，该样本不满足所需嵌入条件，直接跳过。

对有效样本构造：

```python
P = E1(y_g)
Q = (E2.cardinality() // n) * E2(x_h)
R = E1(z_g)
S = (E2.cardinality() // n) * E2(h)

P = E3(P)
Q = E3(v**2 * Q[0], v**3 * Q[1])
R = E3(R)
S = E3(v**2 * S[0], v**3 * S[1])

bit = int(P.tate_pairing(Q, n, 6) !=
          R.tate_pairing(S, n, 6))
```

配对的双线性保证 $z=xy$ 时两边相等，故相等对应内积位 0，不等对应位 1。把有效的 `factor` 作为矩阵 $A$ 的行、判定位作为向量 $b$，在 $\operatorname{GF}(2)$ 上求解

$$
A\cdot hidden=b.
$$

最后将隐藏位串直接拼成文本输入 SHAKE128，生成与密文等长的密钥流并异或，得到：

```text
grey{tate_ate_weil_VfWZTKzMmgYhpEL7xvRwFu}
```

## 方法总结

题目把一个线性方程的右端隐藏在 DDH 判定问题中。普通离散对数不可行，但合适扩域上的 Tate pairing 可把乘法关系转化为可比较的配对值。完整利用还依赖三点：恢复每组第二条曲线的参数、做余因子清除、过滤不满足扭曲映射条件的样本；缺少任一步都可能产生错误判定位。
