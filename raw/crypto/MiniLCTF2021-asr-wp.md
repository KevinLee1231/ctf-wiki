# MiniLCTF 2021 - asr

## 题目简述

题目使用标准 RSA 生成两个 512 位素数 $p,q$，公开 $n=pq$、密文 $c=m^{65537}\bmod n$，另外泄漏

$$
x=p\oplus \operatorname{rev}_{512}(q),
$$

其中 $\operatorname{rev}_{512}$ 表示把 $q$ 的 512 位二进制表示倒序。直接按位异或不能单独恢复两个素数，但异或关系同时关联了 $p$ 的低位与 $q$ 的高位，而乘积 $n$ 又能约束二者的高、低位。核心是从两端同时做深度优先搜索，并用乘积关系持续剪枝。

## 解题过程

设当前已经恢复了 $i$ 位。$x$ 的第 $i$ 个低位给出

$$
p_i\oplus q_{511-i}=x_i,
$$

而 $x$ 的第 $i$ 个高位给出

$$
q_i\oplus p_{511-i}=x_{511-i}.
$$

每轮枚举 $p_i,q_i,p_{511-i},q_{511-i}$ 四个比特，先检查上述两个异或等式，再做两类剪枝：

1. 已知低位必须满足 $p_{\mathrm{low}}q_{\mathrm{low}}\equiv n\pmod {2^{i+1}}$；
2. 已知高位相乘后的前缀必须能与 $n$ 的高位前缀相容。

下面是整理后的恢复代码。`n`、`c` 和 `x` 直接取题目脚本末尾给出的三行输出。

```python
from Crypto.Util.number import inverse, long_to_bytes

# 状态依次保存 p/q 的低位部分与高位部分。
states = [(0, 0, 0, 0)]
for i in range(256):
    mod = 1 << (i + 1)
    x_low = (x >> i) & 1
    x_high = (x >> (511 - i)) & 1
    n_low = n & (mod - 1)
    n_prefix = n >> (1022 - 2 * i)
    nxt = []

    for pl, ql, ph, qh in states:
        for p_low_bit in range(2):
            for q_low_bit in range(2):
                for p_high_bit in range(2):
                    for q_high_bit in range(2):
                        if p_low_bit ^ q_high_bit != x_low:
                            continue
                        if q_low_bit ^ p_high_bit != x_high:
                            continue

                        npl = pl | (p_low_bit << i)
                        nql = ql | (q_low_bit << i)
                        nph = ph | (p_high_bit << (511 - i))
                        nqh = qh | (q_high_bit << (511 - i))
                        if npl * nql % mod != n_low:
                            continue

                        high_product = (nph * nqh) >> (1022 - 2 * i)
                        # 尚未确定的中间位只会在一个有限区间内影响前缀。
                        if not (0 <= n_prefix - high_product <= (2 << (i + 1))):
                            continue
                        nxt.append((npl, nql, nph, nqh))
    states = nxt

for pl, ql, ph, qh in states:
    p = pl + ph
    if p > 1 and n % p == 0:
        q = n // p
        break
else:
    raise RuntimeError("factorization failed")

phi = (p - 1) * (q - 1)
d = inverse(e, phi)
print(long_to_bytes(pow(c, d, n)))
```

恢复因子后按普通 RSA 解密即可得到：

```text
miniLCTF{reverse_1s_als0_e1sy}
```

把该明文重新计算 $m^e\bmod n$ 可得到题目给出的同一密文。部分参赛 WP 在结尾多写了 `_for_hs`，但该字符串无法与附件中的这组三个输出相互验证，因此不沿用。

## 方法总结

这类异或泄漏不能只盯着同一端逐位猜。位反转把 $p$ 的低位和 $q$ 的高位绑在一起，因此应同步维护两端候选；低位用模 $2^k$ 的乘积精确剪枝，高位用乘积前缀做区间剪枝。最终得到的候选必须再用 $p\mid n$ 验证，之后才进入常规 RSA 解密流程。
