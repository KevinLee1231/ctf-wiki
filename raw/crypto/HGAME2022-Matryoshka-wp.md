# Matryoshka

## 题目简述

题目把同一段文本依次经过凯撒、栅栏、Base64、Vigenere、Hex、摩斯、字符串反转和盲文编码，形成典型的“套娃”编码链。每一层的名称和关键参数都在附件中给出，按加密顺序的逆序逐层还原即可。

## 解题过程

附件记录的正向变换顺序为：

```text
明文
  -> Caesar（21）
  -> Rail Fence（22 栏）
  -> Base64
  -> Vigenere（密钥 hgame）
  -> Hex
  -> Morse
  -> Reverse
  -> Braille
```

因此解码时必须从最外层开始，顺序完全反过来：

1. 将盲文字符映射回普通文本。
2. 把得到的整串字符反转。
3. 按摩斯码解码，其中 `/` 是字符分隔符。
4. 将逗号分隔的十六进制字节还原为文本。
5. 使用密钥 `hgame` 做 Vigenere 解密。
6. Base64 解码。
7. 使用 22 栏做 Rail Fence 解密。
8. 撤销 Caesar 21 位移；加密时 `h -> c` 等价于向后移动 5 位，解密时向前移动 5 位。

在 CyberChef 中也可以按上述顺序搭建 recipe。每完成一层都应检查输出是否符合下一层的字符集，例如 Hex 层应只剩十六进制数字和分隔逗号，Base64 层应符合四字符分组和补位规则。最终得到：

```text
hgame{Welc0me_t0_the_w0rld_0f_crypt0graphy!}
```

## 方法总结

多层编码题最重要的是记录“当前看到的是哪一层的输出”，并严格逆序操作。不要一次性猜整条链；利用每种编码鲜明的字母表、分隔符和长度特征逐层验收，能迅速发现位移方向、栅栏栏数或摩斯分隔符设置错误。
