# InfantRSA

## 题目简述

题目给出 RSA 的两个素因子 $p,q$、公钥指数 $e$ 和密文 $c$。既然模数的分解已经公开，就可以直接计算欧拉函数与私钥指数，属于标准 RSA 解密流程。

## 解题过程

已知参数为：

```text
p = 681782737450022065655472455411
q = 675274897132088253519831953441
e = 13
c = 275698465082361070145173688411496311542172902608559859019841
```

计算：

$$
n=pq,\qquad \varphi(n)=(p-1)(q-1),\qquad
d\equiv e^{-1}\pmod{\varphi(n)}.
$$

随后用 $m\equiv c^d\pmod n$ 得到明文整数，再按大端字节序转换：

```python
p = 681782737450022065655472455411
q = 675274897132088253519831953441
e = 13
c = 275698465082361070145173688411496311542172902608559859019841

n = p * q
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)
m = pow(c, d, n)
plaintext = m.to_bytes((m.bit_length() + 7) // 8, "big")
print(plaintext.decode())
```

输出为：

```text
hgame{t3Xt6O0k_R5A!!!}
```

## 方法总结

- 核心技巧：已知 $p$、$q$ 后直接恢复 $\varphi(n)$ 与私钥指数 $d$。
- 识别信号：题目同时给出完整素因子和 RSA 密文，通常考查最基础的私钥恢复与整数转字节。
- 复用要点：`pow(e, -1, phi)` 要求 $\gcd(e,\varphi(n))=1$；明文整数转换时应使用网络协议常见的大端顺序。
