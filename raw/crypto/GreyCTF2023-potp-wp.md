# GreyCTF 2023 POTP

## 题目简述

题目把字节串编码为 $\mathbb{Z}/2^{13}\mathbb{Z}$ 上的多项式，并发布三组卷积：flag 乘以两份 OTP 之和、随机可打印串乘以第一份 OTP、另一随机可打印串乘以第二份 OTP。虽然未知量很多，但多项式乘法的第 $d$ 个系数只依赖下标不超过 $d$ 的字节，可从常数项开始递归恢复。

## 解题过程

记 flag、多余明文和两份 OTP 的系数分别为 $f_i,u_i,v_i,a_i,b_i$，则：

$C_1=f(x)(a(x)+b(x)),\qquad C_2=u(x)a(x),\qquad C_3=v(x)b(x)$。

所有系数都模 $8192$。常数项给出：

$(C_1)_0=f_0(a_0+b_0)$，

$(C_2)_0=u_0a_0$，

$(C_3)_0=v_0b_0$。

OTP 字节在 0 到 255，随机明文字节在 20 到 127，flag 也可按可打印字符筛选。预先枚举这些范围内的模乘积及其因子对，就能列出常数项候选。

假设已经恢复到次数 $d-1$。从每个公开系数中减去所有已知的交叉项后，次数 $d$ 的方程只剩边界未知量，例如：

```text
r2 = (C2[d] - sum(u[i] * a[d-i] for 1 <= i < d)) mod 8192
r3 = (C3[d] - sum(v[i] * b[d-i] for 1 <= i < d)) mod 8192
r1 = (C1[d] - sum(f[i] * (a[d-i] + b[d-i]) for 1 <= i < d)) mod 8192
```

枚举新的 $a_d,b_d$，再用预计算的模除法表恢复可打印的 $u_d,v_d,f_d$；任何不同时满足三式的分支立即剪掉。递归直到 flag 分支以 `}` 结束，得到：

```text
grey{hFSeQZr6PP3L9Cwx_more_vulnerable_than_xor_f9xZ3tDhTMVT73bu}
```

## 方法总结

多项式 OTP 并没有消除一次性密钥复用，只是把逐字节 XOR 换成了三角形卷积。低次系数形成天然的递推顺序，字节范围又提供了强剪枝。分析此类构造时，应把多项式等式展开到单个系数，而不是把整个高次多项式当作不可分割的大对象。
