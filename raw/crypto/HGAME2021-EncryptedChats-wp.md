# EncryptedChats

## 题目简述

题目伪装成经典 Diffie-Hellman 密钥交换，但双方明确把群切换成了模 $p$ 加法群。在乘法群中，公开量通常是 $g^a\bmod p$；在加法群中，“幂运算”变成重复加法，所以公开量退化为 $a\cdot g\bmod p$。只要求一次模逆就能恢复双方私钥，再据共享密钥导出 AES-CBC 密钥并解密两段 flag。

## 解题过程

题目给出生成元 $g$、模数 $p$ 以及双方公开量 $A$、$B$。在加法群中有

$$
A\equiv a\cdot g\pmod p,\qquad B\equiv b\cdot g\pmod p.
$$

因为 $p$ 是素数且 $g\not\equiv0\pmod p$，$g$ 在模 $p$ 下可逆，于是

$$
a\equiv A\cdot g^{-1}\pmod p,\qquad
b\equiv B\cdot g^{-1}\pmod p.
$$

双方共享值为

$$
S\equiv aB\equiv bA\equiv abg\pmod p.
$$

对应的恢复函数只有几行：

```python
def recover_shared_secret(g, p, A, B):
    inverse_g = pow(g, -1, p)
    a = A * inverse_g % p
    b = B * inverse_g % p
    assert a * B % p == b * A % p
    return a * B % p
```

完整解密代码如下：

```python
import hashlib

from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad

shared_secret = int(
    "4905095497614814897720707931100365448537842605147336610039337092558350789195193"
    "7264146758094161039423034483710757906932933306047332542716962101840218178124989"
    "1350056819936779382066261779363579971125715994259195059573452550592715145414375"
    "7053571949492867044458464493036843773391441833773386830575276945084171575196079"
    "7471565688016634919313320372496905585434076171419879128588997628768176875646105"
    "0422411760097924652138602990218232188153831183911049847555611583697693351674454"
    "1766969075634396229165498947104815958488739007504754328725237868258195936633926"
    "463820680575628329426579601827058447231181393158983481374574804"
)
pairs = [
    (
        "d3811beb5cd2a4e1e778207ab541082b",
        "059e9c216bcc14e5d6901bcf651bee361d9fe42f225bc0539935671926e6c092",
    ),
    (
        "b4259ed79d050dabc7eab0c77590a6d0",
        "af3fe410a6927cc227051f587a76132d668187e0de5ebf0608598a870a4bbc89",
    ),
]

key = hashlib.sha1(str(shared_secret).encode("ascii")).digest()[:16]
parts = []
for iv_hex, ciphertext_hex in pairs:
    cipher = AES.new(key, AES.MODE_CBC, bytes.fromhex(iv_hex))
    plaintext = cipher.decrypt(bytes.fromhex(ciphertext_hex))
    parts.append(unpad(plaintext, AES.block_size).decode("ascii"))

print("".join(parts))
```

## 方法总结

DH 的安全性依赖所选群上的离散对数困难性，不能只看公式中是否出现了 $g$、私钥和模数。把协议机械搬到加法群后，公开量是一次线性乘法，私钥可用模逆直接恢复。恢复共享值后还要严格复现密钥派生细节：参与 SHA-1 的是共享整数的十进制 ASCII 表示，AES 使用 CBC 模式和两组独立 IV，最后按发送顺序拼接两段明文。
