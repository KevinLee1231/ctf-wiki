# L3akCTF 2025 Skill Diff Writeup

## 题目简述

题目实现了一个 128 位分组、3 轮的自定义 SPN 密码。服务端为每次请求生成一把随机 16 字节主密钥，并在同一密钥下分别加密选手上传的文件和 flag。上传内容会补零到 16 字节倍数，所有分组独立加密，没有链式工作模式。

服务端没有 Web 漏洞；它只是一个限频的选择明文加密 oracle。目标是构造一批差分明文对，从密文统计中逐轮恢复四组轮密钥，再解密 `flag.enc`。

## 解题过程

### 分析轮函数

初始层先逐字节加主密钥：

$$
X\leftarrow X+K_0\pmod{256}.
$$

每一轮依次执行：

1. 在 $\mathbb Z/256\mathbb Z$ 上乘固定的 $16\times16$ 扩散矩阵 $M$；
2. 对第 $i$ 个字节做可逆仿射变换 $a_i x+b_i$，其中所有 $a_i$ 都是奇数；
3. 与 1 异或；
4. 查自定义 S-box；
5. 加轮密钥 $K_{r+1}$。

轮密钥由主密钥确定：

$$
K_{i+1}=\operatorname{SHA256}(K_i\mathbin\Vert K_0)[:16].
$$

加法差分在加轮密钥时会抵消，而 $M$ 和仿射乘法都可以在模 256 下精确追踪。唯一需要统计处理的是 S-box。

### 构造模加法差分表

这里使用的是加法差分，而不是 XOR 差分。对输入差 $\Delta x$ 和输出差 $\Delta y$，建立：

```python
ddt = [[[] for _ in range(256)] for _ in range(256)]
for dx in range(256):
    for x in range(256):
        dy = (S[(x + dx) % 256] - S[x]) % 256
        ddt[dx][dy].append(S[x])
```

`ddt[dx][dy]` 保存所有满足该差分转移的第一个 S-box 输出值。若末轮某一字节的两份密文差为 $\Delta C$，并假设末轮 S-box 输入差为 $\Delta x$，那么每个候选 $S(x)$ 都给出一个末轮密钥猜测：

$$
K_{3,i}=C_i-S(x)\pmod{256}.
$$

大量明文对会让正确密钥的计数显著高于错误猜测。

### 让扩散层只激活一个字节

若希望经过第一轮矩阵后只有第 $j$ 个字节出现差分 $\delta$，选择输入差

$$
\Delta P=M^{-1}(0,\ldots,0,\delta,0,\ldots,0)^T.
$$

官方脚本预先筛选了两组高概率差分路径：

- 第一组每种路径生成 200000 对明文，用于恢复末轮密钥 $K_3$；
- 第二组每种路径生成 10000 对明文，用于在剥掉末轮后恢复 $K_2$；
- 最后对 16 个输入位置各生成 100 对明文，用于恢复 $K_1$。

总数为

$$
8\cdot200000+8\cdot10000+16\cdot100
=1681600
$$

对，即约 53.8 MB 原始选择明文，低于服务端 60 MB 上传限制。服务端每五分钟只允许一次请求，所以应先在本地生成完整的 `plaintext.txt`，确认长度为 16 的倍数后再上传一次。

### 恢复末轮密钥

对每条高概率路径和每个受影响的输出字节，官方解法同时统计两个可能的末轮输入差分，并按两个频率表中的排名之和给密钥候选打分。这样可以容忍模加法进位导致的相邻路径分支。

核心过程可以写成：

```python
cd = (ct2[pos] - ct1[pos]) % 256

for s0 in ddt[expected_dx_0][cd]:
    freq0[(ct1[pos] - s0) % 256] += 1

for s0 in ddt[expected_dx_1][cd]:
    freq1[(ct1[pos] - s0) % 256] += 1
```

先对 $K_3$ 的前 14 个字节保留少量高分候选，第 15 个字节暂时枚举 0 到 255，第 16 个字节随后补枚举。对每个组合逆一轮，再检查差分的非零位置是否与 $M$ 某一列的支撑完全一致。使用数个不同路径的明文对反复过滤后，只剩唯一的 $K_3$。

### 逐层恢复 $K_2,K_1,K_0$

已知 $K_3$ 后，可以完整逆掉最后一轮：

```python
def decrypt_one_round(block, rk):
    block = [(block[i] - rk[i]) % 256 for i in range(16)]
    block = [inv_sbox[x] ^ 1 for x in block]
    block = [(inv_a[i] * (block[i] - b[i])) % 256
             for i in range(16)]
    return list(inv_M * vector(block))
```

在倒数第二轮边界重新做 DDT 计数，即可恢复 $K_2$。其中一个未被主路径覆盖的字节直接枚举，再用差分激活位置筛选。

逆掉两轮后，第三批明文对在每个坐标只保留一个已知差分。由仿射层可知期望的 S-box 输入差为

$$
\Delta_i=2a_i\pmod{256}.
$$

对每个字节独立统计即可得到 $K_1$。再逆掉这一轮，剩余关系只有

$$
X=P+K_0\pmod{256},
$$

因此任取一个分组便可计算

$$
K_0=X-P\pmod{256}.
$$

最后必须重新运行密钥扩展验证：

```python
assert generate_round_keys(K0) == [K0, K1, K2, K3]
```

这一步同时检验四轮密钥是否因统计噪声产生了误判。

### 解密 flag

`flag.enc` 也是逐块独立加密。每个分组依次逆 $K_3,K_2,K_1$ 三轮，再减去 $K_0$：

```python
for block in blocks:
    block = decrypt_one_round(block, K3)
    block = decrypt_one_round(block, K2)
    block = decrypt_one_round(block, K1)
    block = [(x - k) % 256 for x, k in zip(block, K0)]
```

拼接并去除服务端补入的零字节，得到：

```text
L3AK{3ven_th3_0dd_d1fferential_p4th_1s_a_j0y!!!}
```

## 方法总结

这是一道完整的选择明文差分攻击题。突破口不是 Web 服务，而是短轮数、自定义 S-box 的高概率模加法差分，以及可逆线性扩散层。利用 $M^{-1}$ 精确控制第一轮活跃字节，再从最后一轮开始按 DDT 统计轮密钥，逐轮逆推即可恢复主密钥。远程接口强限频且每次重新生成密钥，因此明文集合必须在本地一次准备完整，不能边试边查。
