# Cold Boot 2

## 题目简述

附件给出一个 2048 位 RSA 公钥模数 $N$，以及从冷启动内存中识别出的私钥材料。两个素因子 $p,q$ 的大量十六进制半字节已经衰减为问号，但其余位置仍然保留。目标是恢复完整的 $p,q$，验证 $N=pq$，再对规定格式的字符串求 MD5。

虽然载体背景是内存取证，实际恢复完全由 RSA 乘法约束决定，因此归入 crypto。

## 解题过程

整数乘法的低 $k$ 位只取决于两个因子的低 $k$ 位。于是可以从十六进制字符串最右端，也就是最低有效字节开始逐步恢复：

1. 找到 $p$ 或 $q$ 中最靠右的未知字节。
2. 若整个字节未知则枚举 256 种；只缺一个半字节则枚举 16 种。
3. 对候选后缀计算乘积，只保留与 $N$ 同长度低位后缀一致的组合。
4. 递归处理下一个未知位置；若后续无解则回溯。

核心约束可以缩写为：

~~~python
def suffix_matches(p_suffix, q_suffix, modulus_hex):
    product = format(
        int(p_suffix, 16) * int(q_suffix, 16),
        "x",
    )
    width = len(p_suffix)
    return product[-width:] == modulus_hex[-width:]
~~~

官方 solver 正是按两个十六进制字符为一个字节从右向左搜索，并保存原始带问号字符串用于回溯。实际运行恢复出的两个 1024 位候选都带有 ASN.1 风格的前导“00”；去掉前导字节后验证：

~~~text
N == p * q: True
~~~

题目要求的 MD5 输入严格为：

~~~text
lowercase_hex(p) x lowercase_hex(q)
~~~

其中分隔符两侧各有一个空格，且不包含两个前导“00”。本地核对得到：

~~~text
md5(...) = ae20b24296a934e794020890ba4f9558
~~~

因此 flag 为：

~~~text
shellmates{ae20b24296a934e794020890ba4f9558}
~~~

## 方法总结

部分 RSA 素因子泄漏不一定需要直接上格算法。若已知位分布在整个 $p,q$ 中，乘法的低位局部性允许从最低有效位逐字节约束和回溯。恢复后必须同时检查 $N=pq$ 和最终哈希的精确序列化格式；前导零、大小写、因子顺序或分隔空格不同都会产生完全不同的 MD5。
