# TSGCTF2020 Beginner's Misc WP

## 题目简述

服务读取一个 UTF-8 字符串，先对其字节做 Base64 编码，再把编码结果直接交给 Python `eval`：

```python
exploit = input("? ")
if eval(b64encode(exploit.encode("UTF-8"))) == math.pi:
    print(open("flag.txt").read())
```

因此提交内容本身不需要是 Python 表达式；需要构造一个有效 UTF-8 字符串，使其 Base64 文本恰好成为一个求值结果与双精度 `math.pi` 相同的算术表达式。

## 解题过程

Base64 每 3 字节编码为 4 个字符，可以反向挑选四字符块。目标表达式只使用数字、`/` 和 `+`，例如：

```text
<巨大整数>/<巨大整数>+<整数>/<整数>
```

先枚举由 4 个十进制数字组成、Base64 解码后能与相邻块共同形成合法 UTF-8 的模式。官方脚本使用两组数字模板：

```ruby
[0].product([4,5,6,7], [4,5,6,7], [2,6])
[0].product([0,1,2,3], [4,5,6,7], [0,1,4,5,8,9])
```

接着从高位向低位同时延长第一组分子与分母。设已经选出的前缀为 $r_a,r_b$，尝试一个四位块 $a,b$ 及最后一位 $i,j$，判断新分数可能覆盖的区间是否包含剩余目标：

$$
\frac{10000r_a+10a}{10000r_b+10b+9}
\le t\le
\frac{10000r_a+10a+9}{10000r_b+10b}.
$$

若包含，就在 $i,j\in[0,9]$ 中选择与 $t$ 最接近的组合。另取一段可安全解码的短分数作为修正项，反复随机搜索，直到 Python 浮点求值与 `math.pi` 完全相等。这里比较的是 IEEE-754 双精度结果，不要求两个有理数在实数意义上等于真正的 $\pi$。

仓库 solver 给出的答案含 16 个 Unicode 字符，UTF-8 编码后为 30 字节：

```text
㮼뎼מ;㍿׿9ێ|ӟ7׽>׍{
```

其 UTF-8 字节重新编码后为：

```python
466864681547442/178524580583170+746/1417
```

在题目使用的 Python 中验证：

```pycon
>>> 466864681547442/178524580583170+746/1417
3.141592653589793
>>> _ == math.pi
True
```

提交后得到：

```text
TSGCTF{Y0u_t00k_the_first_step_0f_the_misc_w0rld!_G0_and_s0lve_all_the_remaining_challenges}
```

## 方法总结

本题的关键是反向利用 Base64 的 3 字节到 4 字符映射，把“合法 UTF-8 输入”与“合法 Python 数字表达式”同时当成约束。四字符分块使 UTF-8 可行性能够预先枚举，而区间剪枝让巨大有理数可以逐段逼近目标。最终只需命中与 `math.pi` 相同的浮点舍入值。由于决定性障碍是表示层编码与数值构造，本题归入 Crypto，而不是泛化的 Misc。
