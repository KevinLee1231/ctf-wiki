# WhitegiveRSA

## 题目简述

题目给出 RSA 公钥参数 $(N,e)$、密文 $c$，并直接泄露了 $N$ 的两个素因子 $p$、$q$。因此不需要分解模数，只需计算欧拉函数、私钥指数并完成常规 RSA 解密。

## 解题过程

已知参数为：

```python
N = 882564595536224140639625987659416029426239230804614613279163
p = 857504083339712752489993810777
q = 1029224947942998075080348647219
c = 747831491353896780365654517748216624798517769637260742155527
```

先验证 $N=pq$，再计算：

$$
\varphi(N)=(p-1)(q-1),\qquad d\equiv e^{-1}\pmod{\varphi(N)}
$$

官方 PDF 的示例代码把公钥指数写成了 `65535`，但这一数值不能直接使用。实际检查可得：

$$
\gcd(65535,\varphi(N))=3
$$

因此 $65535$ 在模 $\varphi(N)$ 下没有逆元，PDF 中的 `gmpy2.invert` 会失败。同期题解记录的实际指数是 `65537`；它与 $\varphi(N)$ 互素，并能解出符合 flag 格式的明文。完整核验与解密代码如下：

```python
from math import gcd

N = 882564595536224140639625987659416029426239230804614613279163
p = 857504083339712752489993810777
q = 1029224947942998075080348647219
e = 65537
c = 747831491353896780365654517748216624798517769637260742155527

assert p * q == N
phi = (p - 1) * (q - 1)
assert gcd(e, phi) == 1

d = pow(e, -1, phi)
m = pow(c, d, N)
plaintext = m.to_bytes((m.bit_length() + 7) // 8, "big")
print(plaintext.decode())
```

输出为：

```text
hgame{w0w~yOU_kNoW+R5@!}
```

指数 `65537` 与最终结果还可在 [vict0r 的 HGAME 2021 部分题解](https://www.cnblogs.com/vict0r/p/14366289.html) 中交叉核对；关键参数、错误原因和完整解密过程均已写入正文。

## 方法总结

RSA 已知 $p$、$q$ 时，核心步骤就是由 $\varphi(N)$ 求私钥指数。但抄录参数后必须先验证 $N=pq$ 与 $\gcd(e,\varphi(N))=1$；若模逆不存在，不能继续套公式。本题的 PDF 恰好存在指数笔误，利用互素性检查和解密后明文格式可以同时发现并纠正它。
