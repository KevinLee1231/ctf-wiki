# BYUCTF 2023 - RSA1

## 题目简述

附件给出 RSA 的 `n`、`e = 7` 和密文 `c`。生成模数时只用了两个约 64 位素数，因此 `n` 只有约 128 位，远低于安全规模。

## 解题过程

对 `n` 做整数分解可得到：

```text
p = 18413880828441662521
q = 15631612382272805561
```

随后按标准 RSA 解密：

```python
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)
m = pow(c, d, n)
plain = m.to_bytes((m.bit_length() + 7) // 8, 'big')
```

明文为：

```text
byuctf{too_smol}
```

## 方法总结

RSA 的安全性首先取决于模数分解难度，而不是指数看起来是否复杂。两个 64 位素数的乘积可被现代工具迅速分解；实际系统应使用足够大的随机素数，使模数至少达到当前推荐的安全位数。
