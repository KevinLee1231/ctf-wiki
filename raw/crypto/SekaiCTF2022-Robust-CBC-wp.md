# Robust CBC

## 题目简述

题目实现了一个 CBC-MAC 变体。完整块消息返回最终分组密文的高 63 位，非完整块经 PKCS#7 填充后返回低 63 位。服务允许三次签名查询，随后要求为未查询过的消息伪造标签。

高、低标签分别泄露同一个 128 位中间状态的两端，只剩中间 2 位未知。枚举这 2 位即可恢复完整状态，再利用 CBC-MAC 的链式结构构造等价的单块消息；每次连接成功率为 $1/4$。

## 解题过程

对一个完整块 $M$，初始状态为零，CBC-MAC 状态为：

$$
Y=E_K(M).
$$

选择：

```text
M  = 00010203040553656b61690b0c0d0e01
M' = 00010203040553656b61690b0c0d0e
```

第二条消息少一个字节，PKCS#7 会补上 `01`，所以两条查询实际进入分组密码的块完全相同。完整块查询返回：

$$
t_{\mathrm{hi}}=\operatorname{MSB}_{63}(Y),
$$

非完整块查询返回：

$$
t_{\mathrm{lo}}=\operatorname{LSB}_{63}(Y).
$$

因此：

$$
Y=t_{\mathrm{hi}}\mathbin\Vert b_0b_1
\mathbin\Vert t_{\mathrm{lo}},
$$

只需猜测未知的两位 $b_0b_1$。

第三次查询两块消息 $M\Vert B$，其中：

```text
B = 101112131415161718191a1b1c1d1e1f
```

其状态为：

$$
T=E_K(Y\oplus B).
$$

服务返回 $T$ 的高 63 位。构造一块未查询过的新消息：

$$
X=Y'\oplus B,
$$

其中 $Y'$ 是猜测出的完整状态。若两位猜中，则：

$$
E_K(X)=E_K(Y\oplus B)=T,
$$

所以第三次查询得到的标签可以直接用于 $X$。

官方脚本把两端标签拼接并固定猜测为 `00`：

```python
def forge(high_tag, low_tag, middle_bits):
    state = (
        bin(int(high_tag, 16))[2:].zfill(63)
        + middle_bits
        + bin(int(low_tag, 16))[2:].zfill(63)
    )
    block = int(state, 2) ^ int(
        "101112131415161718191a1b1c1d1e1f", 16
    )
    return block.to_bytes(16, "big").hex()
```

猜中概率为 $1/4$。失败后重新连接，新实例允许再次进行三次查询；重复直到验证通过，得到：

```text
SEKAI{TrCBC_15_VuLn3r4bL3_70_len_4tt4cK}
```

## 方法总结

MAC 的标签截断方式必须固定，不能让消息长度决定泄露同一内部状态的不同位段。本题通过“完整块取高位、填充块取低位”拼出了 126 位状态，再用 CBC 链式关系把状态恢复转化为消息伪造。审计自制 MAC 时，应同时检查填充分支、标签截断和内部状态是否能被跨查询组合。
