# BYUCTF 2023 - 006 I

## 题目简述

附件只有一个未加盐的密码哈希，需要识别算法并恢复口令。哈希长度和格式对应 MD5，口令存在于常见的 `rockyou.txt` 字典中。

## 解题过程

Hashcat 的 MD5 模式号为 0：

```bash
hashcat -m 0 006_1.txt rockyou.txt
hashcat -m 0 006_1.txt --show
```

字典命中口令：

```text
brittishhottie
```

按题目格式提交：

```text
byuctf{brittishhottie}
```

## 方法总结

未加盐的快速哈希不适合保存密码：同一口令始终产生同一摘要，且 GPU 可以高速遍历大型泄漏字典。识别时应结合摘要长度、字符集和题目上下文，但最终要用实际计算验证候选，而不是只相信在线“识别器”。
