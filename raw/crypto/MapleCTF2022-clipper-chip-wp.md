# clipper-chip

## 题目简述

题目虚构了一颗 67 位流密码加速芯片 MB9001C67。数据手册说明 MODE 引脚用于连续 67 个时钟装载密钥，之后芯片输出密钥流与输入的异或结果，并特别警告不得复用密钥。源码表明内部由长度为 17、19、31 的三个 LFSR 组成，反馈掩码分别为 `0x100ab`、`0x40112`、`0x40000576`，输出通过多数函数组合。

密文含已知前缀 `flag: maple{`，因此可以用相关攻击分别恢复较短寄存器，再求出剩余 31 位状态。

## 解题过程

多数函数 $M(a,b,c)$ 在 $a=b$ 时必然输出该公共值，所以组合密钥流与任意一个输入 LFSR 都存在明显统计相关性。先把已知明文与密文异或得到一段已知密钥流，穷举 $2^{17}$ 个第一寄存器状态和 $2^{19}$ 个第二寄存器状态，分别生成等长序列并按匹配位数排序。正确状态的相关得分会显著高于随机候选。

剩余 31 位不能直接穷举。把每一位初始状态建成 Z3 位向量，严格复现 LFSR 的右移、反馈异或和多数函数；固定已经恢复的两个寄存器，约束每个输出位等于已知密钥流，求解第三个寄存器。芯片串行装载密钥时位序与整数常见表示相反，组合三个状态后还要按源码顺序反转 67 位：

```python
known = xor(ciphertext[:len(prefix)], b"flag: maple{")

# 先按相关得分恢复 17、19 位状态，再用 Z3 约束 31 位状态。
key_bits = bits17 + bits19 + model_bits31
key = int("".join(map(str, key_bits[::-1])), 2)
```

用恢复出的初始状态生成完整密钥流，与密文异或，得到：

```text
maple{c0rr3l4710n_4nd_c4u54710n.HAiBDKZP3Jggoqyb}
```

## 方法总结

组合生成器的安全性取决于布尔组合函数能否抵抗相关攻击；寄存器总长为 67 位并不意味着必须穷举 $2^{67}$。应先利用多数函数降低两个短状态的搜索复杂度，再把剩余状态交给约束求解器。实现时最容易出错的是反馈方向、输出时机和串行装载位序，最好用源码中的一次加密结果逐位校验。
