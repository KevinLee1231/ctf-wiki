# safe-xor

## 题目简述

题目把布尔 XOR 扩展成 `True`、`False`、`None` 三值运算，并用它作为 LFSR 的反馈，迭代 $2^{999}$ 次后给出状态。看似状态空间和轮数都极大，但这套“安全 XOR”正好等价于 $\mathbb F_3$ 上的线性运算。

## 解题过程

建立映射：

```text
None  -> 0
True  -> 1
False -> 2  （即 -1 mod 3）
```

检查 `safeXor` 的真值表可以发现，返回值正是两个映射值在 $\mathbb F_3$ 上相加。于是整个移位寄存器是线性变换。若状态长度为 $N$，一步矩阵 $M$ 的前 $N-1$ 行负责左移，最后一行全为 1，负责把全部状态求和作为反馈。

题目执行 $2^{999}$ 次迭代，生成脚本利用重复平方计算：

```sage
for _ in range(999):
    M = M * M
```

这恰好得到 $M^{2^{999}}$。把公开三值状态映射到 $\mathbb F_3$ 向量 $v$ 后，逆变换即可恢复初态：

```sage
initial = (M^-1 * vector(GF(3), v)).list()
bits = "".join("1" if x == 1 else "0" for x in initial)
print(int(bits, 2).to_bytes((len(bits) + 7) // 8, "big"))
```

得到：

```text
grey{!safe,_!xor,_wow..,..,.,}
```

## 方法总结

自定义逻辑运算应先完整列真值表，再尝试在小有限域中寻找代数表示。这里 `None` 不是异常值，而是 $0$；另外两个布尔值对应 $\pm1$，使反馈仍然完全线性。面对天文数字轮数，不应模拟迭代，而应把状态更新写成矩阵并用快速幂；逆向则计算相同大幂矩阵的逆。
