# N1CTF 2023 e2$m4 Writeup

## 题目简述

题目在 SM4 的轮函数外增加了可逆的字节置换层 $P$，并在指定轮次执行 `Dance`：把四个 `Dance_Box` 循环移动两位。服务端用同一把 128 位密钥，以不同的 `dance_time` 对同一段、恰好包含两个分组的 flag 加密，给出五组密文。

每个 32 位字的四个字节分别经过不同 S 盒并循环移位：$P_i(x)=\operatorname{ROTL}_8(S_i(x),2+i)$。关键缺陷是第 1、3 个 S 盒完全相同。`Dance` 虽然改变了轮函数中各 S 盒的位置，却会在相邻两份密文之间留下可控差分，因此可以把它当成一次人为注入的末轮故障。

## 解题过程

SM4 一轮可写成 $X_{i+4}=X_i\oplus T(X_{i+1}\oplus X_{i+2}\oplus X_{i+3}\oplus rk_i)$，其中 $T=L\circ S$。先按 SM4 的逆序输出规则把每个密文分成四个 32 位字，再比较 `dance_time` 相邻的两组密文。

假设当前处理的是最后一轮，`Dance` 前后的第一个 P 盒相同，那么输出差分中的这一项会抵消。对剩余部分有：

$L^{-1}(\Delta X_{35})=S(U\oplus rk_{31})\oplus S(U'\oplus rk_{31})$。

这里 $U$、$U'$ 都能由两份密文和公开的 `Dance_Box` 计算。官方求解器将 $L$ 表示成 $GF(2)$ 上的 $32\times32$ 矩阵并求逆，从而得到 S 盒输出差分。然后逐字节枚举 $x\in[0,255]$，保留满足下式的候选：

`S[x] ^ S[x ^ input_delta] == output_delta`

候选中的 $x$ 再与已知的轮输入异或，即得到对应的轮密钥字节。单个分组通常仍有少量候选，而 flag 有两个 ECB 分组；对两个分组的候选集合取交集后，每个字节都唯一确定。

得到末轮密钥后，先逆掉已经恢复的轮，再对下一对相邻密文重复同样的差分恢复过程。连续恢复最后四个轮密钥后，按 SM4 密钥扩展逆向 32 轮，最后与系统参数 `FK` 异或即可得到主密钥：

```python
rkey = recovered_last_four[::-1]
for i in range(32):
    rkey = inv_key_round(rkey, SM4_CK[-1-i])
master_key = b''.join(long_to_bytes(rkey[i] ^ SM4_FK[i]) for i in range(4))
```

用恢复出的主密钥和正确的 `dance_time=31` 逆向全部轮函数，官方 `sol.sage` 的离线复算结果为：

```text
n1ctf{Go0d_j0b_u_h4ck_th3_6ox}
```

## 方法总结

本题的核心不是直接攻击 SM4，而是识别 `Dance` 造成的结构化差分。两个相同 S 盒使相邻配置中的一部分轮输入保持不变，线性层又可以完全求逆，于是问题被化为逐字节查询 S 盒差分分布表。两个 ECB 分组负责消除候选歧义，连续四组相邻密文负责恢复四个末轮密钥，最后再逆密钥扩展。分析自定义分组密码时，应优先检查组件复用、轮间置换以及同一明文在不同配置下的输出差分。
