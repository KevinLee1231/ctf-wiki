# N1CTF 2023 e2Is0 Writeup

## 题目简述

服务端随机生成 20 个 ASCII 字母组成的 `guess`，把其字节串视为约 160 位整数 $n$，计算 $\sqrt n$，并把高精度十进制表示的小数部分数字串作为 $j$ 不变量。随后在 $\mathbb{F}_{p^2}=\mathbb{F}_p[i]/(i^2+1)$ 上构造 $j(E)=j$ 的曲线，随机取一个 3 阶核生成 3-同源 $E\to E'$。

题目公开 $p$，允许提交一次整数 $a$，内部随机取 20 位指数 $r$，并返回 $j(E')^{a^r-1}$ 的实部。目标是从这一项泄漏中恢复原始 `guess`。

## 解题过程

### 把随机指数变成求逆

提交 $a=-1$。服务端先在 $\mathbb{Z}/p^2\mathbb{Z}$ 中计算指数；当随机的 $r$ 为奇数时，`(-1)^r - 1` 的标准非负代表元为：

$x=p^2-2$。

随后这个整数被用作 $\mathbb{F}_{p^2}$ 中的幂指数。非零元素群 $\mathbb{F}_{p^2}^{\times}$ 的阶为 $p^2-1$，而 $p^2-2\equiv-1\pmod{p^2-1}$，所以服务端实际返回 $j(E')^{-1}$ 的实部。若 $r$ 为偶数，指数为 0、返回值为 1，重新连接即可。

设 $j(E')=u+vi$，本次泄漏为 $s$，则：

$s=\operatorname{Re}((u+vi)^{-1})=u/(u^2+v^2)$，

从而得到 $v^2=-u^2+s^{-1}u$。这把未知的虚部平方表示成了实部 $u$ 的多项式。

### 用三阶模多项式恢复原曲线

三阶同源满足经典模多项式关系 $\Phi_3(j(E),j(E'))=0$。本题的 $j(E)=J$ 位于基域中，代入 $J$ 和 $u+vi$ 后，将实部、虚部分开得到两个 $\mathbb{F}_p$ 上的多项式方程。

官方解法先对这两个方程关于 $v$ 求 resultant，再利用 $v^2=-u^2+s^{-1}u$ 消去所有 $v$ 的偶次幂，最后继续消元得到只含 $J$ 的一元多项式。枚举其根，并用 `Phi_3` 和泄漏方程回代验证，即可筛出服务端最初使用的十进制小数数字串 $J$。

### 从截断平方根恢复 guess

令 $d$ 为已知数字串 $J$ 的十进制位数，$R=J/10^d$，并写成：

$\sqrt n=t+R+\varepsilon$，其中 $t=\lfloor\sqrt n\rfloor$，$|\varepsilon|<10^{-d}$。

展开并移项后，$n-t^2-2tR-R^2$ 极小；同时 $n$ 约 160 位、$t$ 约 80 位。把 $n-t^2$、$t$ 和误差项的尺度编码进三维格：

```python
L = Matrix(ZZ, [
    [10^d, 0, 0, 10^(2*d)],
    [0, 10^d, 0, -2*J*10^d],
    [0, 0, 10^(d+zeta), -J^2],
])
```

对 $L$ 做 LLL 后，从短向量读出 $t$ 与 $n-t^2$，计算 $n=t^2+(n-t^2)$，再按 20 字节大端序解码为 `guess`。对官方求解器内置的样例数据进行兼容性修正后，复算得到 `WYJGDRRczKLowmjlztmr`。远程实例提交恢复出的字符串即可取得：

```text
n1ctf{0h_you_c4n_get_j_fr0m_th3_h4lf@#$%}
```

[Maple3142 的公开复现](https://blog.maple3142.net/2023/10/23/n1ctf-2023-writeups/#e2is0)还给出了另一种等价消元顺序：同时保留 $j(E')^{-1}$ 的虚部为未知量，将模多项式和乘法求逆关系分离实虚部后连续计算 Sylvester resultant；其最终恢复目标与官方脚本相同。

## 方法总结

本题的突破点是选择 $-1$ 消除随机指数：只要指数奇偶性合适，复杂的幂查询就退化为求逆实部。一次泄漏虽不足以直接恢复 $j(E')$，但 3-同源提供了额外的模多项式约束，resultant 可以依次消去虚部和邻接曲线的实部。最后，服务端把平方根的小数部分以高精度十进制数字保存，造成一个误差极小的近似整数关系，可用低维 LLL 恢复原 160 位整数。
