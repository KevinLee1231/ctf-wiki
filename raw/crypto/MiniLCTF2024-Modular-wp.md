# miniLCTF 2024 Modular Writeup

## 题目简述

题目生成 1024 位素数 $p$ 和秘密 $s$，对 16 组公开的 $t_i$ 给出

$$h_i=(s+t_i)^{-1}-e_i\pmod p,$$

其中误差满足 $0<e_i<2^{328}$。这属于 Modular Inversion Hidden Number Problem：逆元被加上了相对较小的未知误差，需要用格攻击恢复 $s$。

## 解题过程

### 消去秘密量

由定义有

$$1=(s+t_i)(h_i+e_i)\pmod p.$$

取第 0 组与第 $i$ 组相减并消去 $s$，整理得到

$$
(t_i-t_0)e_0e_i
+\bigl(h_0(t_i-t_0)+1\bigr)e_i
+\bigl(h_i(t_i-t_0)-1\bigr)e_0
+h_0h_i(t_i-t_0)+h_i-h_0
\equiv0\pmod p.
$$

未知量是 $e_0$、其余 15 个 $e_i$ 和 15 个乘积 $e_0e_i$。线性化后共有 31 个小量，每条关系还带一个模数倍数。按误差上界 $B=2^{328}$ 缩放：一次项乘 $B$，二次项乘 $B^2$，再把模 $p$ 的关系嵌入整数格。使用 15 条消元关系与固定坐标构造出的格维数为

$$3(16-1)+2=47.$$

这一建模来自 MIHNP 的标准格化思路；[Boneh、Halevi 与 Howgrave-Graham 的原始论文](https://www.iacr.org/archive/asiacrypt2001/22480036.pdf)说明了逆元隐藏数问题的攻击框架。这里最重要的不是保留链接，而是正确编码上面的双线性关系与两级误差界。

### LLL 恢复误差与秘密

对缩放后的 47 维基执行 LLL，从短向量读出 $e_0,e_i,e_0e_i$。候选必须同时通过三类校验：

```python
B = 2**328

assert all(0 < ei < B for ei in errors)
assert all((h[i] + errors[i]) * (s + t[i]) % p == 1
           for i in range(16))

key = sha256(long_to_bytes(s)).digest()[:16]
flag = unpad(AES.new(key, AES.MODE_CBC, iv).decrypt(ct), 16)
```

由任意一组正确误差即可反求

$$s=(h_i+e_i)^{-1}-t_i\pmod p.$$

本地复现得到

```text
s = 9248940038040839057598632265764855803828614592033151220667438062454710430448514351740132586277363244788388587249049064222965708602595485072348985210053249
```

16 个误差全部小于 $2^{328}$，最大值的位长正好为 328。AES 密钥为 `97ffe023e10d9b5955f0e9a893b74784`，解密结果为：

```text
miniLCTF{3njoy_th3_Lattic3}
```

## 方法总结

逆元型隐藏数问题不能直接按普通线性 HNP 处理。关键是先在两条逆元方程之间消去 $s$，把问题转成关于 $e_0$、$e_i$、$e_0e_i$ 的低次数模关系，再用不同尺度约束一次项和二次项。恢复候选后必须回代全部 16 组等式，避免把偶然短向量误判为秘密。
