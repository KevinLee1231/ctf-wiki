# Easy RSA

## 题目简述

程序为 flag 的每个字符分别生成两个只有 8 位的小素数 $p,q$，随机选择与 $\varphi(n)$ 互素的指数 $e$，并输出四元组 $(e,p,q,c)$。由于 $p$、$q$ 直接泄露，可以对每个字符独立计算私钥指数并解密。

## 解题过程

对每个四元组有：

$$
n=pq,\qquad \varphi(n)=(p-1)(q-1)
$$

$$
d\equiv e^{-1}\pmod{\varphi(n)},\qquad m\equiv c^d\pmod n
$$

Python 3.8 及以上可以直接用 `pow(e, -1, phi)` 求模逆：

```python
flag = []

for e, p, q, ciphertext in records:
    phi = (p - 1) * (q - 1)
    private_exponent = pow(e, -1, phi)
    message = pow(ciphertext, private_exponent, p * q)
    flag.append(chr(message))

print("".join(flag))
```

## 方法总结

RSA 的安全性要求攻击者不知道 $p$、$q$。本题直接输出因子，相当于公开了 $\varphi(n)$，因此每个字符都能按标准 RSA 私钥公式还原。题目逐字符生成新模数不会增加安全性，反而把解密拆成了许多独立的小问题。
