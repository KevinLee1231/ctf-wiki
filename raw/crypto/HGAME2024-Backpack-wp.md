# Backpack

## 题目简述

题目给出 48 个约 96 位的正整数 $a_i$ 和一个背包和 `bag`，要求恢复二进制选择向量。生成脚本把恢复出的比特串转成整数 $p$，再提交 `sha256(str(p))` 形式的 flag。

这不是依赖超递增序列的 Merkle–Hellman 背包。其密度为

$$
d=\frac{n}{\log_2(\max a_i)}\approx0.500436,
$$

低于常用的低密度经验界 $0.9408$，可以把子集和关系嵌入格中并使用 LLL 找短向量。

## 解题过程

目标是寻找 $x_i\in\{0,1\}$，满足：

$$
\sum_{i=0}^{47}x_i a_i=\text{bag}.
$$

构造一个 $49\times49$ 的整数格。前 48 行的对角元为 2、末列为对应的 $a_i$；最后一行为 48 个 1，末元素为 `bag`：

$$
L=
\begin{pmatrix}
2I_{48} & a\\
\mathbf 1 & \text{bag}
\end{pmatrix}.
$$

若 $x$ 是正确选择向量，则“最后一行减去所有被选中的行”得到

$$
(1-2x_0,\ldots,1-2x_{47},0),
$$

其坐标只有 $\pm1$，范数很短，LLL 通常会把它约化到前几行。由于短向量可能整体取反，脚本应同时测试两种符号解释，而不是死认某个固定方向。

```python
from hashlib import sha256

bag = 1202548196826013899006527314947
n = len(a)

lattice = Matrix(ZZ, n + 1, n + 1)
for row, value in enumerate(a):
    lattice[row, row] = 2
    lattice[row, -1] = value
lattice[-1, :] = 1
lattice[-1, -1] = bag

for vector in lattice.LLL().rows():
    if vector[-1] != 0 or any(abs(vector[i]) != 1 for i in range(n)):
        continue

    for sign in (1, -1):
        # 由 1-2*x_i 还原选择位。
        selected = [(1 - sign * int(vector[i])) // 2 for i in range(n)]
        if sum(bit * value for bit, value in zip(selected, a)) != bag:
            continue

        # 生成端逐位取 p 的最低位，因此输出时要反向拼接。
        bit_string = "".join(map(str, reversed(selected)))
        p = int(bit_string, 2)
        print(p)
        print(f"hgame{{{sha256(str(p).encode()).hexdigest()}}}")
        raise SystemExit
```

```text

```

对十进制字符串 `268475474669857` 计算 SHA-256，得到：

```text
hgame{04b1d0b0fb805a70cda94348ec5a33f900d4fd5e9c45e765161c434fa0a49991}
```

## 方法总结

- 先计算背包密度；低密度是尝试 LLL 子集和攻击的重要信号。
- 构造格时，短向量的末坐标应为 0，其他坐标应为 $\pm1$，这两个条件可用于筛选 LLL 输出。
- LLL 只保证找到短向量，不保证向量符号固定；应同时检查向量与其相反数，并用原子集和方程验证。
- 比特端序属于生成逻辑的一部分。恢复选择向量后，还要按题目从 $p$ 的最低位依次取位的顺序反转，才能得到正确整数。
