# spiral-baby

## 题目简述

题目提供一个 16 字节分组的自制 SPN，并开放任意明文加密。`spiral-baby` 只执行一轮：先模 255 加轮密钥，再经过 S 盒和固定的螺旋位置置换，最后再加旋转后的轮密钥。由于轮数只有一轮，每个输入字节对某个固定输出位置的影响没有扩散到其他字节。

## 解题过程

先用编号矩阵 `0..15` 运行一次 `spiralLeft`，求出输入位置 `pos` 经 `spiralRight` 后对应的输出位置。固定其余 15 字节，只让第 `pos` 个字节遍历 $0,1,\ldots,254$，一次拼接为 255 个分组提交，减少网络往返。

对该位置的每个首轮密钥猜测 $k\in[0,254]$，计算：

$$
d_i=C_i[\operatorname{rot}(pos)]-S((P_i[pos]+k)\bmod255)\pmod{255}.
$$

若 $k$ 正确，$d_i$ 就是固定的末轮密钥字节，对全部 255 个明文都相同；错误猜测通常无法满足这个条件。逐位置执行即可恢复完整初始密钥：

```python
for k in range(255):
    tail = [
        (cts[i][rotated[pos]] - SBOX[(pts[i][pos] + k) % 255]) % 255
        for i in range(255)
    ]
    if len(set(tail)) == 1:
        key.append(k)
        break
```

用源码中的 `Spiral(key, rounds=1).decrypt()` 解密加密 flag，得到：

```text
maple{0nt0_th3_r34l_sp!r4l_0be088}
```

## 方法总结

一轮代换—置换网络没有形成雪崩效应，选择明文可以把 16 字节问题拆成 16 个独立的 255 候选问题。分析自制分组密码时，应先画清每层的数据依赖和位置映射；如果某个输入仍只影响单一输出，就优先构造差分或不变量，而不是把整个密钥空间一起穷举。
