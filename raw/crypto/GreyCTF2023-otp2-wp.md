# GreyCTF 2023 OTP2

## 题目简述

OTP2 删除了前一题直接打印的整数内积，但仍返回用户 token 对私钥的线性组合，以及用同一随机数构造的 6 个群元素。通过消去随机掩码，可以得到以 OTP 线性组合为指数的群元素；再利用随机素数 $p$ 的 $p-1$ 中足够多的小因子做部分离散对数，并用格恢复 6 个 16 位 OTP。

## 解题过程

记私钥为 $s_i$、OTP 为 $\theta_i$、用户 token 为 $k_i$。服务返回

$t=\sum s_ik_i$，

$C_0=g^r,\qquad C_i=g^{rs_i+\theta_i}\pmod p$。

计算

$$
A=\dfrac{\prod_{i=1}^{6}C_i^{k_{i-1}}}{C_0^t}
=g^{\sum_{i=0}^{5}k_i\theta_i}\pmod p
$$，

随机数 $r$ 和所有私钥项都会消去。

官方解法随机选择约 90 位的 $k_i$。对每次连接的 $p-1$ 做 ECM 部分分解，保留大约 5 到 40 位的互异小素因子；若这些因子的乘积 $K$ 还不到约 110 位，就重连获取新的素数。对每个因子 $q\mid p-1$ 投影到阶为 $q$ 的子群：

```sage
e_q = discrete_log(
    A^((p - 1) // q),
    g^((p - 1) // q),
    q
)
```

CRT 合并后得到

$S=\sum k_i\theta_i$。

这里每个 $k_i$ 约 90 位、$\theta_i<2^{16}$，所以内积不到约 110 位；只要 $K$ 超过该上界，CRT 结果就是普通整数 $S$，而不只是模 $K$ 的剩余类。

最后构造格，把关系 $\sum k_i\theta_i-S=0$ 放大 $X=2^{100}$。前六行分别含单位向量和 $Xk_i$，末行含 $-XS$ 与 $2^{16}$。LLL 会找出形如

$(\theta_0,\ldots,\theta_5,0,2^{16})$

的短向量。取前六项并提交，得到：

```text
grey{I_forgot_to_remove_the_debug_message_qgn9fe58yMwJdMRf}
```

## 方法总结

指数掩码若在多个分量间复用，攻击者可用公开的线性哈希精确抵消它。之后问题变成“有限群中的小指数线性组合”：先借助 $p-1$ 的光滑部分把指数恢复为足够大的模数，再利用秘密仅 16 位这一界通过 LLL 找短向量。若当前 $p-1$ 的光滑部分不足，重连不是碰运气求 flag，而是在选择可计算离散对数的群实例。
