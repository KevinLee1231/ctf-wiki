# gcd or more?

## 题目简述

题目采用 Rabin 加密：公开模数的两个素因子 $p$、$q$ 以及密文 $c=m^2\bmod n$，其中 $n=pq$。因为平方映射在合数模数下不是一一对应，解密时要分别在模 $p$、模 $q$ 下开平方，再用中国剩余定理组合出四个候选明文。

## 解题过程

题目参数如下：

```python
p = 85228565021128901853314934583129083441989045225022541298550570449389839609019
q = 111614714641364911312915294479850549131835378046002423977989457843071188836271
c = 7665003682830666456193894491015989641647854826647177873141984107202099081475984827806007287830472899616818080907276606744467453445908923054975393623509539
```

两个素数都满足 $p\equiv q\equiv3\pmod4$，所以密文的模平方根可直接计算为：

$$
r\equiv c^{(p+1)/4}\pmod p,\qquad
s\equiv c^{(q+1)/4}\pmod q
$$

再求满足 $ap+bq=1$ 的 Bézout 系数 $a$、$b$。组合 $(\pm r,\pm s)$ 可得到四个模 $n$ 的根：

$$
x\equiv aps\pm bqr\pmod n
$$

完整实现如下：

```python
p = 85228565021128901853314934583129083441989045225022541298550570449389839609019
q = 111614714641364911312915294479850549131835378046002423977989457843071188836271
c = 7665003682830666456193894491015989641647854826647177873141984107202099081475984827806007287830472899616818080907276606744467453445908923054975393623509539
n = p * q


def extended_gcd(x: int, y: int) -> tuple[int, int, int]:
    if y == 0:
        return x, 1, 0
    g, a1, b1 = extended_gcd(y, x % y)
    return g, b1, a1 - (x // y) * b1


r = pow(c, (p + 1) // 4, p)
s = pow(c, (q + 1) // 4, q)
g, a, b = extended_gcd(p, q)
assert g == 1

roots = {
    (a * p * s + b * q * r) % n,
    (-a * p * s - b * q * r) % n,
    (a * p * s - b * q * r) % n,
    (-a * p * s + b * q * r) % n,
}

for root in roots:
    assert pow(root, 2, n) == c % n
    plaintext = root.to_bytes((root.bit_length() + 7) // 8, "big")
    print(plaintext)
```

四个根都能通过平方校验，但只有一个候选是可读的 flag：

```text
hgame{3xgCd~i5_re4l1y+e@sy^r1ght?}
```

## 方法总结

Rabin 解密与 RSA 不同：即使已知因子，也天然会得到四个平方根。正确流程是先利用素数的模 $4$ 性质求局部平方根，再通过扩展欧几里得算法和 CRT 组合全部符号分支，最后依据编码结构筛选明文；只计算一个根可能会漏掉真正的 flag。
