# pen-and-paper

## 题目简述

附件给出一段自定义 Vigenère 密文。密钥长度为 13，但实现有两个不同于标准 Vigenère 的细节：标点和空格同样消耗密钥位置；每处理完 13 个输入字符，密钥整体左旋一位。题目没有提供可直接运行的自动 solver，官方资料给出的是一个交互式辅助页面，因此需要从实现准确还原密钥索引，再结合英文统计与已知明文人工校正。

## 解题过程

设输入位置从 0 开始编号为 $i$。第 $i$ 个字符先使用当前密钥的第 $i\bmod 13$ 位，而此前每完整处理 13 个字符，密钥又左旋了一位。因此原始密钥下标为：

$$
j(i)=\left(i+\left\lfloor\frac{i}{13}\right\rfloor\right)\bmod 13.
$$

这个公式必须对所有字符推进；若只在字母处增加计数，后面的列会全部错位。可以把字母密文按 $j(i)$ 分成 13 组，对每组尝试 26 个 Caesar 偏移，用字母频率或英文 n-gram 给候选评分，再在交互页面中逐位调整。解密字符时采用：

```python
j = (i + i // 13) % 13
plain = (cipher - key[j]) % 26
```

将候选明文与开头常见英文短语对照，可以稳定恢复原始密钥：

```text
MVITIITXPMZQM
```

完整明文中明确写出：

```text
The flag you are looking for is VIGENEREWITHATWIST.
```

仓库没有额外的提交包装器；结合本场统一 flag 格式，提交内容为：

```text
maple{VIGENEREWITHATWIST}
```

## 方法总结

自定义古典密码题最容易错在“看起来像标准算法”就直接套工具。应先把状态更新写成位置公式，明确哪些字符消耗密钥、轮换发生在处理前还是处理后，再做统计分析。本题真正的变化量只有额外的 $\lfloor i/13\rfloor$，还原这个索引后仍是 13 组普通 Caesar 密码。
