# UMDCTF 2018 - Apple

## 题目简述

题面称 Mac 的 Option 键卡住了，并给出一串看似特殊符号的文本：

```text
¨ÂÎÇˇÏ-”Ï¨˜ÇˇˆØ˜–´Á–Íˇ¨Ç’
```

这些字符不是随机乱码，而是普通按键在 macOS 键盘上与 Option 键组合后的输入结果。关键是逆向键盘映射，而不是分析字符本身的 Unicode 数值。

## 解题过程

在美式 Mac 键盘布局中，按住 Option 后再按字母或符号键，会输入 `¨`、`Â`、`Î`、`` 等特殊字符。题面已经提示 Option 键持续按下，因此逐字符查回产生该符号的原始按键即可。

前几组映射为：

```text
¨ -> U
Â -> M
Î -> D
Ç -> C
ˇ -> T
Ï -> F
” -> {
```

对整串应用同一映射后得到：

```text
UMDCTF-{FUNCTION-KEY-STUCK}
```

计算该字符串的 SHA-1：

```text
da6c727c69c114d77145349a609fcbd35303e312
```

结果与 `README.md` 中的官方摘要一致，说明大小写、连字符和花括号均已恢复正确。

## 方法总结

遇到由大量非 ASCII 字符组成、同时又带有键盘提示的文本时，应优先考虑输入法或键盘修饰键映射。先用已知 flag 前缀建立少量对应关系，再反查完整键位，比盲目尝试 Unicode 归一化更直接；最后用官方摘要校验精确结果。
