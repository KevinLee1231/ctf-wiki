# rsa-apprentice

## 题目简述

题目给出 RSA 参数 $n,e$ 和两段密文 $c_1,c_2$。模数只有约 140 位，远低于安全强度，可以直接分解；两段解密结果按顺序拼接即为 flag。

## 解题过程

用 Sage 分解 $n$，计算私钥指数：

$$
\varphi(n)=(p-1)(q-1),\qquad d=e^{-1}\bmod\varphi(n).
$$

完整恢复代码为：

```sage
n = 1216177716507739302616478655910148392804849
e = 65537
c1 = 257733734393970582988408159581244878149116
c2 = 843105902970788695411197846605744081831851

(p, _), (q, _) = factor(n)
d = inverse_mod(e, (p - 1) * (q - 1))
m1 = int(power_mod(c1, d, n))
m2 = int(power_mod(c2, d, n))

part1 = m1.to_bytes((m1.bit_length() + 7) // 8, 'big')
part2 = m2.to_bytes((m2.bit_length() + 7) // 8, 'big')
print((part1 + part2).decode())
```

输出为：

```text
tjctf{n0t_s0_S3cur3_Cryp70}
```

## 方法总结

- RSA 安全性取决于模数位数与素数生成质量；标准指数 $65537$ 无法弥补一个可瞬间分解的小模数。
- 多段密文分别做标准 RSA 解密后要按题目生成顺序拼接，并使用大端整数转字节。
- 先评估模数位数和现成分解能力，避免在明显的小模数上寻找不存在的高级漏洞。
