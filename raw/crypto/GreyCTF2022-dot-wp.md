# GreyCTF2022 - Dot

## 题目简述

服务随机生成三维复向量 $v_1$，每个实部和虚部都是 64 位整数。选手可提交一次向量 $v_2$，并得到复内积 $\langle v_1,v_2\rangle$ 的实部；随后必须完整猜出 $v_1$。关键在于把六个 64 位未知量编码进一次超大系数线性组合，再用 LLL 恢复。

## 解题过程

对 $v_1=(a_i+b_i\mathrm i)$、$v_2=(x_i+y_i\mathrm i)$，源码计算共轭内积，因此泄露值为

$$P=\sum_{i=0}^{2}(a_i x_i+b_i y_i).$$

选择六个约 399 位的随机系数作为 $x_i,y_i$。未知向量各分量都小于 $2^{64}$，可构造一个 7 行、8 列的整数格：前六行放单位阵并在倒数第二列放相应系数的相反数，最后一行放泄露值 $P$ 与缩放量 $2^{64}$。

```python
rows = []
for i, coeff in enumerate(coeffs):
    row = [0] * 8
    row[i] = 1
    row[6] = -coeff
    rows.append(row)
rows.append([0] * 6 + [P, 2**64])

short = Matrix(ZZ, rows).LLL()[0]
guess = short[:6]
```

把六个整数重新配对成三个复数并提交即可。公开仓库把服务 flag 主体替换为点号，只保留后缀 `UsDJk3ENW55hG9ktZG4X`；因此此处不伪造缺失正文，实际服务会在向量完全相等时返回完整 flag。

## 方法总结

一次线性泄露并不等于只泄露一个未知量：当未知量都很小、攻击者又能选择极大的独立系数时，整组未知量可以成为格中的唯一短向量。恢复后应先在本地验证点积等式和 64 位范围，再向服务提交。
