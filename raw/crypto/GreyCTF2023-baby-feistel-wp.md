# GreyCTF 2023 Baby Feistel

## 题目简述

题目实现 19 轮 Feistel 网络，轮函数为 `MD5(right || key)`，每轮密钥再通过一个 16 次多项式在模 $5^{55}$ 下更新。程序断言同一密钥下加密两次能还原任意明文，而密钥就是 flag 中间的 16 字节。这个自反性质泄露了密钥调度的固定点条件。

## 解题过程

设密钥更新多项式为

$F(x)=\sum_{n=0}^{16}M_nx^n\pmod{5^{55}}$。

Feistel 解密需要按相反次序使用轮密钥。若初始密钥满足 $F(k)=k$，则 19 轮全部使用同一个 $k$，轮密钥序列自然正反相同；结合函数末尾的左右交换，同一个 `encrypt` 再执行一次就是逆运算。这正好解释源码中的 1000 次随机自反断言。

于是求解转化为寻找

$F(k)-k\equiv0\pmod{5^{55}}$。

可以从模 5 的根开始逐位提升。若当前候选 $s$ 是模 $5^i$ 的根，枚举下一位 $j\in\{0,1,2,3,4\}$，检查

$q=s+j5^i$

是否满足模 $5^{i+1}$ 的方程：

```python
roots = [0]
for i in range(55):
    lifted = []
    for s in roots:
        for digit in range(5):
            q = s + digit * 5**i
            if (F(q) - q) % (5**(i + 1)) == 0:
                lifted.append(q)
    roots = lifted
```

把最终候选编码成 16 字节大端整数，并筛选可打印字符串，得到内部密钥 `vuln_f1x3d_p01n7`。补上格式后为：

```text
grey{vuln_f1x3d_p01n7}
```

## 方法总结

本题无需攻击 MD5。决定性信息是“同一函数调用两次等于恒等映射”，它把 Feistel 的轮密钥对称性转化为多项式固定点。模素数幂的方程适合按 $5$ 进制逐位提升，最后再用长度和可打印性筛选实际密钥。
