# cipher-master

## 题目简述

题目实现了 48 位分组、96 位主密钥的四轮 SPN 密码 LNR，并用 CBC 分别加密一张公开 BMP 和 flag。已知原图与其密文提供大量明密文对，而轮数过少、6 位 S 盒存在明显线性偏差，因此可以做线性密码分析恢复轮密钥。

![作为已知明文提供的 NO FLAG 位图，其原始字节与对应密文组成分析样本](TJCTF2022-cipher-master-wp/known-plaintext-meme.bmp)

## 解题过程

先按 CBC 关系把公开图片转换为分组密码的输入输出对：

$$
X_i=P_i\oplus C_{i-1},\qquad Y_i=C_i.
$$

官方脚本为四个 S 盒建立线性逼近表，统计每个输入掩码与输出掩码满足奇偶关系的偏差，再穿过逆置换选择能够覆盖末轮单个 6 位子密钥块的线性特征。对每个候选 $k\in[0,63]$，部分逆最后一轮并统计关系成立次数；绝对偏差最大的候选就是对应的末轮子密钥块。

脚本先恢复八个 `K5` 块，并据此补出倒数第二轮输入；随后以同样方法恢复经过逆置换的 `K4P`，再计算：

```python
k4 = permute(k4p, pbox)
k3 = xor(k5, subs(rotate(k4), sbox1))
k2 = xor(k4, k3)
k1 = xor(k3, subs(rotate(k2), sbox1))
key = from_blocks(k1) + from_blocks(k2)
```

这正是对题目密钥扩展的逆运算。用恢复的 12 字节主密钥初始化 `LNRCipher`，CBC 解密 `flag.txt.enc` 并去除填充，得到：

```text
tjctf{4NaLyZ1ng_C1ph3rs_i5_preT7y_Fun_1snt_1T_f5a841b3}
```

原图的画面语义不参与攻击，但完整 BMP 字节是建立明密文对所必需的已知明文。

## 方法总结

- 少轮 SPN 的安全性取决于 S 盒偏差、扩散层和轮数共同作用，不能凭“有 S 盒和置换”判断安全。
- CBC 已知明文需先异或前一密文块，才能得到底层分组密码的明文输入。
- 恢复末轮子密钥后，应利用密钥调度的代数关系逆推出主密钥，而不是逐块暴力搜索 96 位空间。
