# TSGCTF2020 Beginner's Crypto WP

## 题目简述

附件只有两个断言。设 flag 的大端整数为 $m$，它最多 50 字节；程序把 $m$ 左移 10000 位，再要求结果的十进制表示以给定的 175 位常数 $c$ 结尾：

```python
assert len(open("flag.txt", "rb").read()) <= 50
assert str(
    int.from_bytes(open("flag.txt", "rb").read(), "big") << 10000
).endswith(str(c))
```

十进制后 175 位等价于模 $10^{175}$ 的同余。左移则等价于乘 $2^{10000}$，所以目标是从一个非互素模方程中恢复受 50 字节上界约束的 $m$。

## 解题过程

断言给出：

$$
m\,2^{10000}\equiv c\pmod{10^{175}}.
$$

分解模数：

$$
10^{175}=2^{175}5^{175}.
$$

左侧天然被 $2^{175}$ 整除，而题目常数也满足相同条件；这一部分没有提供关于 $m$ 的额外信息。转到模 $5^{175}$ 后，$2^{10000}$ 与模数互素，可以直接求逆：

$$
m\equiv c\left(2^{10000}\right)^{-1}\pmod{5^{175}}.
$$

flag 最多 50 字节，因此 $0\le m<2^{400}$；另一方面 $5^{175}>2^{400}$，所以该同余类在允许范围内至多有一个代表元。求解代码为：

```python
c = 1002773875431658367671665822006771085816631054109509173556585546508965236428620487083647585179992085437922318783218149808537210712780660412301729655917441546549321914516504576

modulus = 5 ** 175
m = c * pow(2 ** 10000, -1, modulus) % modulus
flag = m.to_bytes((m.bit_length() + 7) // 8, "big")
print(flag)
```

本地运行仓库 solver 得到：

```text
TSGCTF{0K4y_Y0U_are_r3aDy_t0_Go_aNd_dO_M0r3_CryPt}
```

旧版 Python 若不支持 `pow(a, -1, n)`，也可用欧拉定理，以 $\varphi(5^{175})=5^{175}-5^{174}$ 计算逆元。

## 方法总结

本题把“十进制后缀”转换成模 $10^k$ 的同余，再利用 $10^k=2^k5^k$ 拆开处理。由于乘数含有大量 2，不能直接在模 $10^{175}$ 下求逆；真正可逆的是模 $5^{175}$ 的分量。最后由 flag 长度上界保证同余解唯一。遇到左移、十进制后缀和长度限制的组合时，应先写出模方程并检查各素因子上的可逆性。
