# 蒙特卡罗轮盘赌

## 题目简述

服务端用蒙特卡罗方法投掷 $400000$ 个点估算圆周率，选手要把结果猜到小数点后五位，并在五局中赢得三局。蒙特卡罗统计过程本身没有可利用的数学偏差，突破口在于 C 标准库伪随机数生成器的种子可预测。

## 解题过程

### 确认随机数状态会连续复用

服务端只在游戏开始时初始化一次随机数生成器：

```c
srand((unsigned)time(0) + clock());
```

每次估计圆周率都会连续调用 `rand()`：

```c
double rand01(void) {
    return (double)rand() / RAND_MAX;
}

double getpi(void) {
    int M = 0;
    const int N = 400000;
    for (int i = 0; i < N; i++) {
        double x = rand01();
        double y = rand01();
        if (x * x + y * y < 1) {
            M++;
        }
    }
    return (double)M / N * 4;
}
```

设程序启动时的种子为

$$
s = \operatorname{time}(0) + \operatorname{clock}().
$$

`time(0)` 只精确到秒，能由本地时间估计；程序刚启动时 `clock()` 的值也只有一千左右。种子空间因此很小。一旦恢复 $s$，后续全部 `rand()` 输出和三次圆周率估计都已确定。

### 用前两局泄漏筛选种子

五局三胜允许先故意输两局。随便提交两个错误答案，服务端会公布这两局的正确结果，记为 $p_1,p_2$。本地从“当前 Unix 时间加约 $1500$”附近向正负两侧枚举种子；对每个候选种子执行与服务端完全相同的两轮 `getpi()`，同时匹配 $p_1$ 和 $p_2$。

官方求解器的核心逻辑如下：

```c
int middle = 1500 + (unsigned)time(0);
int sign = 1;

for (int i = 0; i < 10000; i++) {
    int seed = middle + i / 2 * sign;
    srand(seed);

    double test1 = getpi();
    double test2 = getpi();
    if (fabs(test1 - p1) < 1e-6 &&
        fabs(test2 - p2) < 1e-6) {
        printf("%1.5f %1.5f %1.5f\n",
               getpi(), getpi(), getpi());
        break;
    }
    sign = -sign;
}
```

实际编写时不要在同一个 `printf` 的多个参数中直接调用三次 `getpi()`，因为 C 语言不规定函数实参的求值顺序；应先按顺序保存为 `p3`、`p4`、`p5`，再输出。官方 `solv.c` 也是这样处理的。

为了与服务端一致，最好在同版本的 glibc 环境中编译求解器，因为 C 标准没有规定 `rand()` 的具体算法。使用优化编译可显著缩短枚举时间：

```bash
gcc solv.c -O3 -lm -o solv
```

连接服务后立即启动本地求解器，把服务端泄漏的前两次正确结果输入进去。找到唯一匹配种子后，依次提交求出的后三个值，即可连赢三局。

## 方法总结

伪随机算法是否安全，取决于内部状态能否被预测，而不是输出看起来是否随机。本题同时暴露了三个弱点：低熵时间种子、只初始化一次的连续状态，以及失败后公布正确结果。先利用两次已知输出恢复状态，再预测后续输出，是典型的 PRNG 状态恢复思路。复现 C 程序时还要注意 libc 实现和浮点格式必须与目标环境一致。
