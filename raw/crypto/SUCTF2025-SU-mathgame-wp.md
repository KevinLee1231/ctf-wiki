# SU_mathgame

## 题目简述

服务连续设置三关数学验证：

1. 提交一个合数，使其对 1000 个随机底数都满足费马同余 $a^{N-1}\equiv1\pmod N$；
2. 提交 900～999 bit 的正整数 $a,b,c$，满足
   $$
   \frac{a}{b+c}+\frac{b}{a+c}+\frac{c}{a+b}=4;
   $$
3. 已知 Möbius 变换 $T$ 的三个输入输出对 $(z_i,T(z_i))$，计算新点 $z$ 的像。

三关分别对应 Carmichael 数构造、齐次丢番图方程的正整数解，以及 Möbius 变换的交比不变量。

## 解题过程

### 第一关：构造足够大的 Carmichael 数

Chernick 构造给出：如果 $6k+1$、$12k+1$、$18k+1$ 均为素数，则

$$
N=(6k+1)(12k+1)(18k+1)
$$

是 Carmichael 数。它是合数，却对所有与 $N$ 互素的底数满足费马同余。选择足够大的 $k$ 还能让随机底数碰到非互素值的概率可以忽略。官方 exp 使用：

### 第二关：使用椭圆曲线上的正有理点

原方程是齐次的：若 $(a,b,c)$ 是有理解，则同时乘以分母最小公倍数即可得到整数解。令 $c=1$、通分后得到一条平面三次曲线；将其化到 Weierstrass 形式后，可以在相应椭圆曲线上组合生成元，寻找映回 $a,b>0$ 的有理点，再整体清分母。

### 第三关：利用交比不变性

Möbius 变换保持四点交比。设服务给出的三对点为 $(z_1,w_1)$、$(z_2,w_2)$、$(z_3,w_3)$，待求点为 $z$，则可直接由交比等式解出 $w=T(z)$。官方 exp 的化简形式为：

```python
A = (w1 - w2) * (z - z2) * (z1 - z3)
B = (w1 - w3) * (z1 - z2) * (z - z3)
w = (w3 * A - w2 * B) / (A - B)
```

完整交互主线如下：

```python
io.sendlineafter(b"number: ", str(ans1).encode())
io.sendlineafter(b"a, b, c: ", f"{a},{b},{c}".encode())

pairs = sage_eval(io.recvline().decode(), locals={"I": ComplexField(999).gen()})
z = sage_eval(io.recvline().decode(), locals={"I": ComplexField(999).gen()})
(z1, w1), (z2, w2), (z3, w3) = pairs

A = (w1 - w2) * (z - z2) * (z1 - z3)
B = (w1 - w3) * (z1 - z2) * (z - z3)
io.sendline(str((w3 * A - w2 * B) / (A - B)).encode())
```

服务仅以 50 bit 复数精度比较结果，因此使用题目同等或更高精度计算即可稳定通过。

## 方法总结

- 核心技巧：分别用 Carmichael 数、椭圆曲线有理点和交比不变量满足三个独立验证器。
- 识别信号：大量随机费马测试并不等价于素性测试；齐次三元有理方程可以先求有理解再清分母；三个点对唯一确定 Möbius 变换。
- 复用要点：服务端使用 Python `/` 检查超大整数等式存在浮点语义风险，但官方给定解能够通过；本地推导和验证仍应使用精确有理数。第三关不需要恢复随机矩阵，直接利用交比即可。
