# tetraethyllead

## 题目简述

题目提供一个 64 bit、7 轮自定义 Feistel 密码的加密 oracle，允许查询 1024 次。密钥为 `b"\x00" + secrets.token_bytes(7)`，即只有 56 个未知 bit。轮函数混用按密钥生成的 S 盒、32 bit 乘法、三次方、移位与旋转。目标是在查询额度内恢复密钥并提交。

## 解题过程

决定性弱点是高位差分

$$
\Delta=0x80000000.
$$

对于 32 bit 模运算，翻转输入最高位后再与固定奇数或偶数相乘，输出最高位的传播只依赖乘数最低位，约有 $1/2$ 概率保持可预测关系；加法和三次方不会充分打散该特征。代码中的两次 `word ^= word << 5` 也不会改变最高位差分。三轮 `r345` 使用的左右旋转量在模 32 后互相抵消，进一步保留了这条差分路径。

每次随机选 64 bit 明文 $P_0$，构造

$$
P_1=P_0\oplus(1\ll63)\oplus(1\ll31),
$$

即左右 32 bit 分支都注入最高位差分。查询两份密文后，仅保留满足

$$
\Delta C_L\oplus\Delta C_R=0x80000000
$$

的对。512 对查询正好耗尽 1024 次额度，通常能收集 7 到 8 组可攻击样本。

```python
from secrets import token_bytes

MASK64 = (1 << 64) - 1
DELTA = (1 << 63) | (1 << 31)

usable = []
for _ in range(512):
    p0 = int.from_bytes(token_bytes(8), "big")
    p1 = p0 ^ DELTA
    c0 = oracle(p0)
    c1 = oracle(p1)
    dc = (c0 ^ c1) & MASK64
    if ((dc >> 32) ^ (dc & 0xffffffff)) == (1 << 31):
        usable.append((p0, c0, c1))
```

把这些样本写入 `solve.h` 后，官方 C++ 程序从最后一轮向前测试子密钥。先根据筛选后的差分对穷举后半 32 bit 子密钥 `k1`，错误候选会在多对样本上迅速被淘汰；确定 `k1` 后，再通过本地加解密一致性穷举前半部分 `k0`。首字节固定为零把最终搜索量限制到 56 bit 密钥空间中的对应切片。题目说明在单线程旧款 i5 上约需 5 分钟。

恢复出的 8 字节整数提交给仍在等待的服务，得到：

```text
tjctf{eep-oaep-182971039}
```

## 方法总结

- 自定义轮函数中最危险的是“看似复杂但对某个单 bit 差分近乎透明”的运算组合；应逐个检查乘法、移位和旋转对候选差分的传播。
- Feistel 结构适合从末轮回推。先用差分过滤获得少量高质量样本，再分段穷举子密钥，远优于直接遍历完整 56 bit 空间。
- 查询预算应预先计算：每个差分样本消耗两次 oracle，512 对恰好覆盖 1024 次，不能在交互阶段浪费请求。
