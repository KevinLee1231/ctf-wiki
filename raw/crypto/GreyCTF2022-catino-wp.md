# GreyCTF2022 - Catino

## 题目简述

服务把一个大整数的四次方根写成高精度十进制小数，并要求预测后续数字。每次失败会推进输出位置，因此可先故意失败收集靠后的 100 位，再利用已知前缀和位数上界通过格约简恢复被截断的大整数。

## 解题过程

服务总共进行大量轮次，官方解法先提交错误答案约 4900 次，记录接近尾部的连续十进制数字。设四次方根对应整数为 $x$，服务公开了 $x^4$ 的高位十进制信息，而尚未观察的尾部相当于一个有界误差 $y$。于是可写成

$$x^4=A\cdot 10^t+y,\qquad 0\le y<10^t.$$

把已知十进制前缀、未知尾数上界以及候选根的位数按官方 `sol.sage` 的方式嵌入格，LLL 返回的短向量给出满足该近似关系的 $x$。恢复后用高精度实数重新计算四次方根的小数展开：

```python
R = RealField(required_bits)
digits = str(R(recovered_n).nth_root(4)).replace('.', '')
answer = digits[next_offset:next_offset + 100]
```

将预测的 100 位提交给下一轮，服务返回：

```text
grey{FunFact_OurGreyCatIsActuallyABlackCat_LFP9eux3884hd2ag}
```

## 方法总结

这题的核心不是直接计算普通浮点四次方根，而是把十进制截断看成“小误差的整数关系”。收集数据时要明确小数点、轮次偏移和截断长度；恢复候选后还必须重新生成已知片段进行对照，避免因精度或索引差一位而提交错误。
