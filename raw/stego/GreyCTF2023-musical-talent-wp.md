# GreyCTF 2023 MusicalTalent

## 题目简述

附件是一段 MIDI。生成器把原文中的每种字符一一映射到不同音高，再按字符顺序写成等时长、互不重叠的音符，因此音符序列本质上是一份单表替换密文。flag 被隐藏在一大段英文取证资料中。

## 解题过程

解析 MIDI 的 `note_on` 事件，忽略力度为 0 的关闭事件，按时间顺序记录 MIDI note number。由于所有字符持续时间一致，每个音高正好对应一个字符：

```python
notes = []
for msg in midi:
    if msg.type == "note_on" and msg.velocity > 0:
        notes.append(msg.note)
```

先统计音高频率。最常见的符号通常对应空格，随后可用英语中的 `e`、`t`、`a` 等频率、重复词形和标点位置逐步建立替换表。flag 格式 `grey{...}` 又提供了强 crib：在解出的长文中寻找一个左花括号和右花括号包围的连续片段，并用周围英文验证映射。

公开仓库的生成器进一步确认了机制：它把原文转成小写，排序唯一字符集，再依次映射到固定的音名与八度组合。用同一映射回放可完整还原正文，其中的 flag 为：

```text
grey{y0u_h4v3_4_mus1c4l_t4l3nt_t00_c207584111e9a5bcd5d27813b719dee8}
```

## 方法总结

MIDI 在这里不是需要听辨的音乐，而是承载离散符号的容器。固定时值和一音一字使问题退化为单表替换；解析事件、做频率分析和使用已知 flag 格式，比保存钢琴卷帘截图更精确。处理媒体隐写时应先判断信息藏在波形、频谱，还是像本题一样藏在事件符号序列。
