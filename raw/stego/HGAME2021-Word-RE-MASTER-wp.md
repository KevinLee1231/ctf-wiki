# Word RE:MASTER

## 题目简述

附件包含无口令的 `first.docx` 和受口令保护的 `maimai.docx`。DOCX 本质上是 ZIP 容器，前者额外藏有 `password.xml`；其中的 Brainfuck 输出后者的密码。打开第二份文档并显示隐藏文字，会发现由空格和制表符组成的 SNOW 隐写数据，解码后得到 flag。

## 解题过程

`first.docx` 的文件属性提示 `Password is IN this docx.`，其中 `IN` 被特意大写。把 DOCX 当作 ZIP 解压，与普通 DOCX 的目录结构比较，可以发现额外文件 `password.xml`。该文件包含以下 Brainfuck 程序；空格和换行会被解释器忽略：

```brainfuck
+++++ +++[- >++++ ++++< ]>+++ +.<++ +[->+ ++<]> ++.<+ ++[-> +++<] >+.<+ ++[-> ---<]
>-.++ ++++. <+++[ ->--- <]>-. +++.+ .++++ ++++. <+++[ ->--- <]>-- ----.
+.--- --..+ .++++ +++++ .<+++ [->-- -<]>- ----- .<
```

运行后输出：

```text
DOYOUKNOWHIDDEN?
```

以此作为密码打开 `maimai.docx`。密码本身提示 `HIDDEN`，在 Word 选项中启用“显示隐藏文字”后，会出现一段看似空白、实际由空格与制表符构成的内容。文档里的图片字幕反复强调“雪”，对应 SNOW 空白字符隐写。

取消该段文字的隐藏属性，原样复制到纯文本文件，务必保留空格和制表符，再用 SNOW 解码。例如使用命令行版本：

```powershell
.\SNOW.EXE -C .\flag.txt
```

也可在 Linux 环境使用等价的 `stegsnow -C flag.txt`。输出为：

```text
hgame{Cha11en9e_Whit3_P4ND0R4_P4R4D0XXX}
```

## 方法总结

Office 文档题应同时检查可见内容、文档属性和 ZIP 容器结构。找到隐藏文字后还要区分普通隐藏文本与空白字符隐写；复制时若经过会合并空格、替换制表符或自动换行的编辑器，SNOW 载荷就会损坏，因此应保存为保留原始空白的纯文本。
