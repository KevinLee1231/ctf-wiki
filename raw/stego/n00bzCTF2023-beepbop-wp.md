# BeepBop

## 题目简述

WAV 中的“噪声”是慢扫描电视信号（SSTV），图像信息被调制在音频中。题面额外规定最终 flag 全部小写且不含数字。

## 解题过程

把 `chall.wav` 输入 QSSTV，选择自动检测或根据同步头识别模式，完整播放音频后即可恢复一张只包含 flag 文本的图像。该图像没有除文字外的独立视觉线索，因此直接转写而不再保留截图。

按照题面的大小写和字符规范，将画面语义规范化后得到：

```text
n00bz{beep_bop_you_found_me!}
```

## 方法总结

音频中出现规律性的扫频、同步脉冲时，应考虑 SSTV 等图像调制。恢复出的文字还需服从题面明确的规范；不能机械照抄生成素材中与比赛校验不一致的大小写或数字替换。
