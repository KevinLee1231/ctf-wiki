# Hakuya Want A Girl Friend

## 题目简述

附件 `hky.txt` 由十六进制字节文本组成。开头能看到 ZIP 本地文件头 `50 4B 03 04`，而文件尾部出现倒序的 PNG 签名 `0A 1A 0A 0D 47 4E 50 89`。因此附件实际把一个正序 ZIP 与一个整体字节倒序、且 IHDR 宽高被破坏的 PNG 拼在了一起；PNG 中保存着压缩包密码。

这道题的主要障碍是从复合载体中定位并恢复隐藏文件，归入 `stego`。

## 解题过程

先将十六进制文本还原为原始字节，再按文件签名分离两部分：

- 从 `50 4B 03 04` 开始的前半段按 ZIP 保存；
- 后半段以 `0A 1A 0A 0D 47 4E 50 89` 结束，这是 PNG 文件头 `89 50 4E 47 0D 0A 1A 0A` 的完全倒序形式，将这部分逐字节反转即可恢复 PNG 的基本结构。

恢复后的 PNG 仍不能正常显示。PNG 的 IHDR 块依次保存宽度和高度，块尾 CRC32 又能作为校验条件，因此可以枚举宽高并在 CRC 匹配时停止。官方题解给出的正确尺寸为宽 $576$、高 $779$。修复 IHDR 后打开图片，可读出压缩包密码：

```text
To_f1nd_th3_QQ
```

使用该密码解压前半段 ZIP，得到：

```text
hgame{h4kyu4_w4nt_gir1f3nd_+q_931290928}
```

官方 PDF 将前缀排成了 `hagme`；[另一份同期题解](https://nan0in27.cn/p/hgame2025_week1-%E5%89%A9%E4%BD%99%E9%A2%98%E8%A7%A3/)记录了相同的倒序 PNG 恢复过程，公开汇总题解也将最终前缀记为比赛通用的 `hgame`，因此这里按 `hgame{...}` 记录。

## 方法总结

- 核心技巧：用 ZIP/PNG 文件签名识别拼接边界，将倒序字节流复原，再利用 PNG IHDR 的 CRC32 约束恢复宽高。
- 识别信号：十六进制载体同时出现 `50 4B 03 04` 与倒序的 `0A 1A 0A 0D 47 4E 50 89`，说明其中混合了正序 ZIP 和倒序 PNG。
- 复用要点：遇到损坏 PNG 不应盲猜尺寸；先确认 IHDR 字段位置，再把块 CRC 当作可靠的验证 oracle。复合文件分离时应以完整格式结构为边界，避免只截取文件头而遗漏尾部数据。
