# Multi-track Drifting

## 题目简述

附件包含 Audacity 工程文件 `.aup`、同名 `_data` 目录和参考 MP3。秘密不是可听见的语音，而是被绘制在多个音轨的频谱图中；必须让 Audacity 按工程结构加载分块音频，再切换显示模式。

## 解题过程

保持 `.aup` 与同名 `_data` 目录的相对位置不变，用 Audacity 打开工程文件。`.aup` 只保存工程描述，真正的音频块位于 `_data` 目录；若只复制 `.aup`，项目会显示缺失数据。

工程加载后，对各音轨执行以下操作：

1. 打开音轨名称旁的下拉菜单。
2. 将显示方式由 `Waveform` 切换为 `Spectrogram`。
3. 调整轨道高度和时间缩放，使全部隐藏字符完整出现在视野中。
4. 按音轨及时间顺序读取字符；必要时单独静音或独奏某条轨道，避免重叠干扰。

频谱中的文字拼成：

```text
greyhats{y0U_C4n_sEE_sOuND_2?_692C234B}
```

## 方法总结

音频隐写不只存在于波形、元数据或可听内容中，频率随时间的二维分布也能承载文字。遇到 Audacity 工程时应保留工程文件与数据目录的配对关系；检查时同时尝试波形、频谱、左右声道和多轨布局。最终文本应写入 WP，频谱截图不是复现解法的必要条件，因此本篇不额外保留图片。
