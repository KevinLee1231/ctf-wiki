# beep-boop-robot

## 题目简述

题目只给出 `robot.wav`，听感是规律的长短蜂鸣和停顿。题面还限定 flag 花括号内是全小写单词串，因此决定性信息隐藏在音频的时域脉冲长度中，本质是摩尔斯电码音频解码。

## 解题过程

先观察波形或频谱，选出稳定载波频率，再按有声段和静音段持续时间聚类：短有声段记为点，约三倍时长的有声段记为划；较短静音分隔点划，较长静音分隔字符和单词。

仓库给出的官方复现命令是：

```bash
morse-audio-decoder robot.wav
```

也可以自行阈值化振幅包络后按时长解码。工具输出连成一词：

```text
THISISALLONEWORDLMAO
```

按题目要求转为小写并补上 flag 格式：

```text
tjctf{thisisallonewordlmao}
```

## 方法总结

- 音频中规则的两档脉冲长度与分层静音间隔是摩尔斯电码的典型特征。
- 自动解码前先确认载波、时间单位和噪声阈值；工具输出异常时，直接检查包络与分段时长更可靠。
- 题面给出的大小写和“无空格”约束属于结果规范，应在解码完成后应用，而不是改变原始信号判断。
