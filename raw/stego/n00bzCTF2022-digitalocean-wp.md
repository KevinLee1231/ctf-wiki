# DigitalOcean

## 题目简述

附件是一份 5 页 PowerPoint。flag 被拆开放在每页画布外的文本框中，正常放映看不到，但 OOXML 中仍保留了文本和坐标。

## 解题过程

`.pptx` 是 ZIP 容器。读取 `ppt/slides/slide1.xml` 至 `slide5.xml`，比较每个文本框的变换坐标与页面尺寸 `9144000 × 5143500`。负数横坐标或纵坐标大于 `5143500` 的文本框位于可视区域之外。五页依次恢复出：

```text
n00bz{D1g1t4l_0c34n
1s_5p0n50r1ng
_u5_2000_d0ll4r5_
w0r7h_0f_cr3d1t5
_7h4nk_y0u_s0_much}
```

题面说明最终结果全部小写。还要注意，第二页 OOXML 实际写成 `5p0n50r1ng`，而官方公布并用于提交的 flag 写成 `5pon50r1ng`；这不是单纯的大小写转换。归档时保留官方提交值：

```text
n00bz{d1g1t4l_0c34n_1s_5pon50r1ng_u5_2000_d0ll4r5_w0r7h_0f_cr3d1t5_7h4nk_y0u_s0_much}
```

## 方法总结

演示文稿的可视画布不是全部证据。对象即使被拖到页面外，文本仍存在于 OOXML。检查这类附件时应同时查看幻灯片 XML、页面尺寸、对象坐标和文本顺序，并依据题面明确的大小写规则整理结果。
