# LSB

## 题目简述

题名直接提示 LSB，但载体是 WAV。文本被顺序写入音频样本的最低有效位，需要按字节恢复隐藏数据。

## 解题过程

使用 `stegolsb` 的 WAV 恢复功能：

```bash
stegolsb wavsteg -r -i chall.wav -o flag.txt -b 100
```

其中 `-r` 表示恢复，`-i` 和 `-o` 指定输入输出，`-b 100` 给出足够覆盖文本的恢复字节数。查看输出文件即可得到：

```text
n00bz{L5B_1n_w4v_f1l3s?!!!}
```

## 方法总结

LSB 并不限于图像像素；PCM 音频样本同样可以承载位流。提取时应确认音频未经过有损压缩，并把恢复长度设置得足以包含完整终止内容。
