# GreyCTF 2023 Face Unlock

## 题目简述

应用把上传图片中的人脸编码与一张静态授权照片比较，`face_recognition.compare_faces` 的容差为 0.4。系统只检查图片中恰有一张脸，没有活体检测或挑战响应，因此打印照片、屏幕照片或原始参考照片都可以作为重放样本。

## 解题过程

服务端加载 `auth_faces` 目录中的所有人脸编码。提交接口将 Base64 图片解码后提取编码，并执行：

```python
results = face_recognition.compare_faces(
    valid_faces,
    uploaded_face,
    tolerance=0.4,
)
if any(results):
    return FLAG
```

模型只比较静态特征向量，无法判断镜头前是真人还是另一张照片。获取授权对象的一张清晰正脸照片，确保画面中只有一张脸，将图片文件 Base64 编码后填入 `img` 字段提交即可。与授权编码的距离低于 0.4 时返回：

```text
greyctf{f4c3d_with_pr0bl3ms_9cd73c8bd213adf0443834f771a583db}
```

仓库包含的授权照片属于可识别个人信息，且不需要借助视觉标注才能解释漏洞，因此题解不再复制或展示该照片。

## 方法总结

人脸相似度不是活体证明。单帧验证必须结合眨眼、转头或随机动作等挑战响应，必要时再加入深度、红外和重放检测；高风险门禁还应使用另一独立因子。这里的核心不是制作对抗样本，而是模型外层认证协议允许普通照片重放。
