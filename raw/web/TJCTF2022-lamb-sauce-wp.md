# TJCTF2022 lamb-sauce

## 题目简述

首页只显示标题和一段视频，看不到 flag 链接。题目考查最基础的客户端源码检查：开发者把带随机 UUID 的 flag 文件路径留在 HTML 注释中，而静态服务器仍可直接访问该文件。

## 解题过程

查看页面源代码或直接请求首页后搜索 `flag`，可以发现：

```html
<!-- <a href="/flag-9291f0c1-0feb-40aa-af3c-d61031fd9896.txt">
     is it here?
</a> -->
```

HTML 注释只影响浏览器渲染，不会让内容从响应中消失。访问注释中的绝对路径：

```bash
curl 'http://target/flag-9291f0c1-0feb-40aa-af3c-d61031fd9896.txt'
```

服务器返回 `tjctf{idk_man_but_here's_a_flag_462c964f0a177541}`。

## 方法总结

随机文件名只有在路径保持秘密时才有意义，而发送到客户端的注释已经公开了它。Web 初始侦察应包括 HTML 源码、脚本、样式、网络请求和常见静态路径；页面上“看不见”与响应中“不存在”是两回事。敏感路由不应依赖前端隐藏，必须由服务端鉴权保护。
