# What the cow say?

## 题目简述

应用把用户输入拼接进 shell 命令，但过滤了 `&`、`|`、`;` 和部分敏感词。过滤没有覆盖反引号命令替换，也可以通过在单词中插入空引号绕过关键字匹配，因此能够执行任意读取命令。

## 解题过程

先用反引号包裹命令。shell 会先执行反引号内的内容，再把输出替换回外层命令：

```bash
`ls /`
```

根目录中可以看到 `flag_is_here`。若过滤器拦截字符串 `flag`，可用相邻空字符串拆开词法表示；shell 拼接后仍是同一个路径：

```bash
`ls /fla""g_is_here`
```

继续列出目录得到 flag 文件名，再同时拆分 `cat` 和路径中的 `flag`：

```bash
`ca""t /fla""g_is_here/fla""g_c0w54y`
```

空双引号不会产生字符，所以 shell 实际执行的是正常的 `cat /flag_is_here/flag_c0w54y`。

## 方法总结

- 核心技巧：用反引号触发命令替换，并用空引号拆分被黑名单匹配的关键字。
- 识别信号：应用过滤少量 shell 元字符和命令名，却仍把输入交给 shell 解释。
- 复用要点：黑名单必须同时考虑命令替换、引号拼接、变量展开和换行等语法；防御端应避免 shell 拼接，改用参数数组调用固定程序。
