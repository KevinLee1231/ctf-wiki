# GreyCTF2022 - shero

## 题目简述

PHP 接收参数 `f`，只允许 `.cat!? /|\-[]()$` 等 15 种字符，然后执行 `system("cat " . $file)`。虽然不能直接输入常见命令和字母，shell 的通配符、命令替换、`tr` 与 `wc` 足以合成任意字符串。

## 解题过程

用路径通配符表示现有命令，例如 `/???/[a-t]c??` 命中 `/bin/echo`，`/???/???/t?` 命中 `/usr/bin/tr`，`/???/???/[!c]c -c` 命中 `wc -c`。数字 $n$ 可由 $n-1$ 个 `c` 加换行送入 `wc -c` 得到；再用 `tr` 把 `c` 映射为八进制转义对应字符。

```text
6  => echo ccccc | wc -c
P  => echo c | tr c \120
```

对目标命令逐字符生成命令替换，最终让固定前缀 `cat ` 后执行管道构造出的 `/readflag sRPd45w_0`。密码来自 `readflag.c` 对字符串 `P4s5_w0Rd` 的索引重排；本地运行二进制也验证该口令通过。

服务源码中的真实 flag 为：

```text
grey{r35p3c7_70_b45h_m4573r_0dd14e9bc3172d16}
```

README 把 `b45h` 误写成了 `5h`，此处以实际 `flag.txt` 为准。

## 方法总结

字符白名单不能在保留 shell 解释能力的同时安全过滤命令。通配符、管道、命令替换和已有程序能构成新的字符集；正确做法是不用 shell，直接以固定参数数组调用受限程序，并对规范化后的文件路径做授权检查。
