# GreyCTF 2023 Fetus Web

## 题目简述

这是一道源码检查题。flag 被拆成两段，分别留在首页 HTML 注释和站点自身 JavaScript 文件的注释中；页面使用的模板图片与前端组件只是装饰，不包含额外解题信息。

## 解题过程

请求首页并查看原始响应，而不是只看浏览器渲染结果，可以在 HTML 尾部找到：

```html
<!-- Flag part 1: grey{St3p_1-->
```

继续检查首页加载的自有脚本 `/assets/js/main.js`，在源码注释中找到第二段：

```javascript
// Flag part 2: _of_b4by_W3b}
```

按标号直接拼接两段，得到：

```text
grey{St3p_1_of_b4by_W3b}
```

也可以用脚本分别请求两个资源并匹配注释，但没有必要抓取 Bootstrap 等第三方依赖；关键是沿首页引用定位站点自己维护的文件。

## 方法总结

页面不可见不等于响应中不存在内容。面对入门 Web 题，应依次检查 HTML 源码、注释、脚本和样式引用、常见静态资源及网络响应。只保留承载证据的文本即可，装饰图片没有必要作为题解资源归档。
