# 签到

## 题目简述

题目是 Hackergame 2021 的签到关。页面要求提交一个“比赛期间的时间”，但服务端实际接收的是 URL 查询参数中的 Unix 时间戳：从 1970-01-01 00:00:00 UTC 起累计的秒数。只要该时间戳落在比赛开放区间内，页面就返回 flag。

## 解题过程

浏览器地址栏中的参数可以直接修改，因此不需要分析复杂的前端逻辑。选择比赛期间任意一个确定时刻，例如北京时间 2021-10-23 16:54:07，将其换算为 Unix 时间戳：

```text
2021-10-23 16:54:07 +08:00 -> 1634979247
```

随后把页面查询参数改为：

```text
?page=1634979247
```

服务端把这个整数还原为日期并检查范围，校验通过后给出形如 `flag{HappyHacking2021-...}` 的结果，其中末尾校验串与选手账号有关。

如果不方便使用日期转换工具，也可以先找到大致时间戳，再根据页面反馈做二分或小范围增减；关键仍是让时间落在比赛区间，而不是猜 flag。

## 方法总结

- 核心技巧：识别并直接修改 URL 中的 Unix 时间戳参数。
- 识别信号：题目以日期或“页面编号”包装输入，但参数是十位左右的秒级整数。
- 复用要点：换算时要明确时区；Unix 时间戳以 UTC 为基准，北京时间需按 UTC+8 解释。
