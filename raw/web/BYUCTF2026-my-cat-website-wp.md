# My Cat Website

## 题目简述

站点允许提交 JSON 来更新猫咪对象，并在满足两个状态条件时返回 flag。后端使用递归合并函数处理任意嵌套键，且对象方法从模块全局变量读取开关；这形成了 Python 类污染到函数全局命名空间的利用链。

## 解题过程

源码中的合并逻辑会在目标属性存在时继续递归，否则直接 `setattr`。Python 绑定方法能够沿 `__class__` 访问类，再通过类上的 `to_dict` 函数访问其 `__globals__`。因此提交如下结构：

    {
      "is_happy": true,
      "__class__": {
        "to_dict": {
          "__globals__": {
            "give_flag": true
          }
        }
      }
    }

第一项把当前实例的 `is_happy` 置真；后面的路径把 `to_dict` 所属模块中的全局变量 `give_flag` 置真。再次触发序列化时，两个判断同时成立，服务返回：

    byuctf{y0u_m4d3_k1tty_h4ppy}

这不是 JavaScript 原型污染：利用对象、属性和特殊字段均属于 Python 数据模型。

## 方法总结

递归把不可信映射写入任意对象属性，会让 `__class__`、函数对象和 `__globals__` 成为危险路径。修复时应只允许业务字段，拒绝双下划线属性，并把输入解析到显式数据模型中，不能对运行时对象做通用深合并。
