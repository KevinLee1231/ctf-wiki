# UMDCTF 2018 - Robits

## 题目简述

题目以“爬虫到处都是”提示检查 `robots.txt`。站点把两个隐藏页面路径直接列在爬虫排除规则中，其中一个页面再用十六进制转义的 JavaScript 字符串保存 flag。

## 解题过程

访问：

```text
/robots.txt
```

可见两个 `Disallow` 路径：

```text
8291ebebf9640a6d24c8a6894937270833f4ba7b2f8721236590f3b182c75505
3976704ebabb2fb2e83e05bbd50955693ee41f5281eafc928c5d73ef2f59ff64
```

第二个路径由服务端映射到 `view/flag.html`。页面脚本中的数组内容是：

```javascript
"\x55\x4d\x44\x43\x54\x46\x2d\x7b"
"tH3_r0b1t5_@r3_h3r3\x7d"
```

将十六进制转义还原后得到：

```text
UMDCTF-{tH3_r0b1t5_@r3_h3r3}
```

当前仓库中该字符串及其带换行版本的 SHA-256 都与 README 保存的 `b15292...` 不一致，说明公开页面与摘要存在版本差异。本篇采用可由当前路由和页面源码直接恢复的字符串，不伪造无法验证的替代结果。

## 方法总结

`robots.txt` 只是在请求爬虫不要抓取路径，并不会阻止用户访问。发现隐藏页面后还应继续检查页面源码和脚本常量；若附件与摘要冲突，要把冲突本身记录为证据边界。
