# Code World

## 题目简述

浏览器访问题目时会经过 `302` 跳转，页面源码提示真正的入口被跳转隐藏。直接请求该入口得到 `405 Method Not Allowed`；改用 `POST` 后出现一个只接受“两数相加”表达式的计算器，目标是让结果等于 10。

## 解题过程

先关闭自动跟随跳转，观察原始响应与 `Location`：

```bash
curl -i '<challenge-url>/'
```

对真正入口发送 `POST` 后，服务提示参数名为 `a`，参数必须写在 URL 查询串中。直接提交 `a=1+9` 会失败，因为在 `application/x-www-form-urlencoded` 语义中，裸 `+` 会被解析为空格。

将加号编码为 `%2B`：

```bash
curl -X POST '<challenge-url>/?a=1%2B9'
```

服务端此时收到的参数值是字面量 `1+9`，计算结果为 10，校验通过。[公开参赛者记录](https://asjet.dev/2020/02/week1/)给出的验证结果为：

```text
hgame{C0d3_1s_s0_S@_sO_C0ol!}
```

## 方法总结

- 核心技巧：手工检查 `302` 响应、切换允许的方法，并对查询参数中的运算符做 URL 编码。
- 识别信号：`302` 后的隐藏入口返回 `405`，说明应先调整 HTTP 方法；表达式中的 `+` 失效则指向表单解码规则。
- 复用要点：在查询串和表单编码中，空格与 `+` 的转换很常见；需要传递字面量加号时应使用 `%2B`。
