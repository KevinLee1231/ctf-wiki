# PastebinX

## 题目简述

Paste 中出现账号 `@Abhinav78082932`，题目要求的不是用户名，而是该 X 账号的内部数字 ID。

## 解题过程

搜索用户名并确认对应 X 账号后，查看公开账号元数据或页面返回的数据对象，其中 `rest_id`/用户 ID 为：

```text
1596757063039799297
```

按题面规定的 `1d_` 前缀组合：

```text
n00bz{1d_1596757063039799297}
```

## 方法总结

社交平台的显示名、用户名和内部数字 ID 是三种不同标识。题面明确要求 ID 时，应从账号元数据中读取稳定数字值，而不是提交 `@` 用户名。
