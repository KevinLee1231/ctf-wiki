# Bridget Lives

## 题目简述

题目给出 Bridget 最后一张照片，要求回答拍摄者所在建筑。图中没有文字，定位依赖河道、白色弧形桥体、支撑索和拍摄高度的组合，再用地图街景验证观察方向，归入 OSINT。

## 解题过程

![从高层窗户俯视的新加坡 Robertson Bridge：白色弧形主梁横跨河道，桥面有斜拉杆与多组下方支撑，画面下缘还能看到室内玻璃反射。](DownUnderCTF2024-bridget-lives-wp/robertson-bridge-aerial-view.png)

对图片做反向图片搜索或以桥的独特形状搜索，可将地标收敛到新加坡的 Robertson Bridge。仅识别桥并不够：题目问的是“从哪里拍摄”，因此还要在地图街景中沿桥两侧比对视角。

桥面在画面中由近及远向右上方延伸，拍摄点明显高于桥面，且玻璃反射说明相机在建筑内部。官方解答进一步定位到桥旁 Four Points by Sheraton 的高层左侧、接近电梯的一列窗户；从该位置向下看，桥的弧梁、河岸树线与视角方向一致。

因此提交：

```
DUCTF{four_points_by_sheraton}
```

## 方法总结

反向图片搜索适合产生候选地标，但不能替代拍摄点验证。对于“从哪栋楼拍摄”这类题，要把候选桥/建筑与高度、朝向、前景遮挡和室内反射逐项比对。保留原图是必要的，因为白色弧梁与支撑结构正是该定位链不可替代的视觉证据。
