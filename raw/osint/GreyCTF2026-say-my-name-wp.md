# Say My Name

## 题目简述

题面说明一个外星生物的脸反复出现在 GreyCTF 2026 的视觉素材中，要求回答它的名字，并特别指定 flag 内容使用小写。没有下载附件、编码数据或可利用服务；决定性信息来自公开海报、页面和赛事视觉中的角色识别，因此应归入 OSINT 而不是 Stego。

角色是 **Bibble**。该形象的可识别特征是圆形、毛绒的浅蓝/青色身体、紫色条纹与头顶的粉色毛簇；不要因为题面称它为“alien”就只用泛化关键词搜索。题目需要的是角色专名，而不是物种描述。

## 解题过程

### 固定可比对的视觉线索

先从赛事的多个公开位置截取同一角色的清晰正面图，而不是只根据背景或某一张低清缩略图猜测。可稳定观察到的特征是大眼睛、圆滚的蓝绿色毛绒身体、紫色纹理、粉色头顶毛簇和小翅膀；这些特征组合指向 Bibble。

随后以角色的外观特征做图片或文字检索，核对公开角色图片中的颜色、纹理和身体比例，排除只在单一特征上相似的吉祥物。这里的验证目标是“多处赛事素材中的对象是否为同一命名角色”，并不需要从图片中提取隐藏文件、EXIF 或位平面数据。

### 组装答案

题面要求 flag 小写，故将已确认的专名规范化为 `bibble` 并套入赛事 flag 格式：

```text
grey{bibble}
```

### 验证

识别结果与题目仓库给出的官方 flag 一致：

```text
grey{bibble}
```

## 方法总结

- 核心技巧：视觉 OSINT 先把角色的多项稳定外观特征组合起来，再反向确认专名，避免以单一颜色或“像外星人”这类弱线索猜答案。
- 识别信号：题面要求回答在赛事物料、海报或网页中反复出现的人物/吉祥物名字，并给出大小写规则时，优先考虑公开媒体关联。
- 复用要点：区分“看图识别”和隐写。没有隐藏载荷、空间拼图或编码层时，不应因输入是图片而把题目误归为 Stego。
