# 猫咪问答喵

## 题目简述

题目要求从公开资料中回答六个彼此独立的问题，内容涉及中国科大信息安全战队、LUG 活动资料、旧版 Firefox 的系统兼容性、Linux 内核提交、SSH 主机指纹和学校网络资费文件。页面会反馈答对题目数量，因此允许先通过搜索得到高置信答案，再用格式约束和反馈排除歧义。

## 解题过程

### 1. NEBULA 战队成立时间

中国科大网络空间安全学院的新闻稿明确写明，星云战队（Nebula）成立于 2017 年 3 月，所以答案是：

```text
2017-03
```

新闻稿正文已经给出成立时间，不应把文章发布日期误当答案。原始出处为[中国科大星云战队在第六届强网杯再创佳绩](https://cybersec.ustc.edu.cn/2022/0826/c23847a565848/page.htm)。

### 2. GNOME Wayland 下出现显示问题的 KDE 程序

从 LUG 软件自由日活动页进入第一个闪电演讲的 slides。截图中的菜单项包含 `Configure Kdenlive`，底部面板还出现 `Project Monitor`、`Speech Editor` 等视频编辑界面特征，因此程序是：

```text
Kdenlive
```

活动资料入口为[LUG 软件自由日页面](https://lug.ustc.edu.cn/wiki/lug/events/sfd/)。关键不是记住活动页面位置，而是从截图中的独特菜单和面板文字反查软件名称。

### 3. Windows 2000 能运行的最后一个 Firefox 大版本

Firefox 12 安装程序仍能在未修改的 Windows 2000 上运行；Firefox 13 安装时会提示至少需要 Windows XP SP2，Firefox 13 的官方系统要求也不再包含 Windows 2000。因此答案是：

```text
12
```

这里的限制是“不修改系统配置和程序代码”，所以社区补丁或兼容层运行的更高版本不算。

### 4. 禁止 `argc == 0` 行为的首个 Linux 提交

新内核在使用 `execve(..., NULL, NULL)` 启动程序时，会把空字符串补成 `argv[0]`，同时在日志中留下：

```text
process '<name>' launched '<path>' with NULL argv: empty string added
```

在 `fs/exec.c` 搜索该字符串，再用 `git blame` 或提交历史定位首次引入它的非合并提交，得到：

```text
dcd46d897adb70d63e025f175a00a89797d31a43
```

可在 [Linux 官方 GitHub 镜像对应提交](https://github.com/torvalds/linux/commit/dcd46d897adb70d63e025f175a00a89797d31a43)核对补丁内容。

### 5. SSH 指纹对应域名

已知 ED25519 主机密钥的 MD5 指纹：

```text
e4:ff:65:d7:be:5d:c8:44:1d:89:6b:50:f5:50:a0:ce
```

在 Shodan 按 SSH 指纹搜索，会看到多个 `*.sdf.org` 主机使用该密钥；题目要求填写二级域名，所以答案为：

```text
sdf.org
```

也可以枚举满足“六个不同字母、1996 年注册”提示的候选域名，再用下面的命令核对服务端指纹：

```bash
ssh sdf.org -o FingerprintHash=md5
```

### 6. “网络通”20 元/月的正式实行日期

当前资费页面只能证明后来仍沿用该标准。继续以原文中的资费描述搜索旧通知，可以追溯到“网字〔2003〕1 号”文件；文件末尾明确写明本办法自 2003 年 3 月 1 日起实行，因此答案是：

```text
2003-03-01
```

原始证据为[关于实行新的网络费用分担办法的通知](https://ustcnet.ustc.edu.cn/2003/0301/c11109a210890/page.htm)。

六个答案依次为：

```text
2017-03
Kdenlive
12
dcd46d897adb70d63e025f175a00a89797d31a43
sdf.org
2003-03-01
```

## 方法总结

- 核心技巧：围绕原始新闻、活动资料、官方兼容性说明、源码提交和历史通知建立可核验的公开证据链。
- 识别信号：题目给出精确格式、时间、版本、指纹或文件编号时，应优先寻找一手资料，而不是直接采信搜索摘要。
- 复用要点：区分“发布日期”和“事件发生时间”、区分“官方支持”和“魔改可运行”，并把域名、哈希等答案回到原始服务或源码中复核。
