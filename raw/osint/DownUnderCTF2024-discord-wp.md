# discord

## 题目简述

题目把 flag 拆散在比赛 Discord 的两个公开频道，要求参赛者查找并拼接。关键证据来自公开社区账号/频道内容，而非本地程序或 Web 漏洞，归入 OSINT。

## 解题过程

加入赛事 Discord 后，先查看 `#team-search`。官方解答确认其中由 hex bug 发布的消息给出前半段：

```text
DUCTF{f1r57
```

再到 `#opt-in-updates`，可找到后半段：

```text
_0f_m4ny}
```

按原顺序拼接，不额外添加空格或换行：

```
DUCTF{f1r57_0f_m4ny}
```

## 方法总结

社区 OSINT 的关键是精确记录来源位置和字符串边界。拆分 flag 时先保留每一段的花括号、下划线和大小写，再以题目的 flag 格式检查拼接顺序。频道名和两段内容已足以复现结论，历史聊天截图会暴露无关账号信息，也不能增加技术证据，因此不保存图片。
