# UMDCTF 2018 - tracking-device

## 题目简述

附件 `gps_tracker_log` 是 KML 文件，包含八个没有名称的坐标点。KML 文档名已经给出 flag 前缀 `UMDCTF-{`，需要把坐标反向定位到城市并提取隐藏消息。

## 解题过程

KML 的坐标顺序是“经度、纬度、高度”，不能按常见的“纬度、经度”读取。八组坐标依次对应：

```text
-78.467838,  -0.180653  -> Quito
 77.972648,  45.241544  -> Ush-Tobe
-99.539734,  18.344848  -> Iguala
 13.191338,  32.887209  -> Tripoli
 -3.188267,  55.953252  -> Edinburgh
-119.772587, 36.746842  -> Fresno
-48.275380, -18.914608  -> Uberlândia
129.877667,  32.750286  -> Nagasaki
```

按文件中的点位顺序取城市首字母：

```text
Q U I T E F U N
```

结合 KML 文档名中的前缀，得到：

```text
UMDCTF-{QUITEFUN}
```

仓库的 `solve.txt` 保存了首个城市 `Quito`，与上述坐标顺序和解码方式一致。

## 方法总结

地理坐标题应先确认文件格式规定的轴顺序，再选择城市级而不是国家级地名。多个定位结果的首字母形成可读短语，是本题对地理定位精度和排列顺序的双重校验。
