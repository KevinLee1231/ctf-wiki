# back to the jungle

## 题目简述

题目围绕 DownUnderCTF 2023 出现过的角色 MC Fat Monke 展开。本地素材包含同名专辑封面、歌曲文本和音乐视频；线索要从角色的公开发布内容跳转到网页，再从网页中读取 flag。关键证据来自公开账号与媒体关联，归入 OSINT。

## 解题过程

先从专辑封面和文件名确认目标是 MC Fat Monke 新发布的 `Back to the Jungle`。官方解答指出，歌曲描述会把观察者引向对应音乐视频；视频歌词中连续出现“OSINT task”“find and search for data”“forum board”等表述，说明答案不在音频编码里。

播放视频到约 154 秒，笔记本屏幕上出现一个 MC Fat Monke 主题网页的地址和带 flag 的论坛画面。访问该页面后向下滚动即可看到完整字符串。题目配置给出的答案为：

```
DUCTF{wIr_G0iNg_b4K_t00_d3r_jUNgL3_mIt_d15_1!!111!}
```

专辑封面只用于确认音乐作品名称，画面中没有可独立定位地点或账号的细节；真正的证据是视频中的网页地址与网页内容，因此不复制该宣传性图片。

## 方法总结

媒体 OSINT 题先区分“载体”和“线索”。歌曲/视频往往不是待解码的文件，而是公开发布链的入口：标题、描述、视频帧中的 URL 和网页上下文构成可验证的跳转路径。遇到屏幕上的短暂信息应记录出现时间和可见文字，并把外部页面所给出的关键答案写进题解，避免只留一个失效链接。
