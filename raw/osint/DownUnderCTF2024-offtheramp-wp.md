# offtheramp

## 题目简述

题面刻意强调 `EXAMINE`，附件是一张海湾与船坡道照片。视觉场景本身缺少唯一地标，真正决定答案的是 JPEG 的 GPS EXIF 元数据以及由坐标反查出的地点名称，归入 OSINT。

## 解题过程

读取图片的 GPS 字段可得到：

```text
latitude  = -38.154431
longitude = 145.108247
```

将坐标放入地图后，海岸、泊车区和坡道对应 Olivers Hill Boat Ramp。官方解答提到图片查看器也会把 EXIF 坐标显示为地图卡片，并给出同一地点名称。

按题目要求把空格转换为下划线，提交：

```
DUCTF{olivers_hill_boat_ramp}
```

照片只提供海湾和坡道的通用远景，位置结论来自其内部元数据而不是肉眼可辨识的地理细节；为避免保留没有额外视觉价值的整图，WP 直接转写坐标和反查结果。

## 方法总结

带图片的 OSINT 题应先做低成本元数据检查。若图像没有唯一文字或地标而包含 GPS，坐标是比反向搜索更直接、可验证的证据。记录坐标、坐标系和反查出的标准地名即可重现推理；不要把普通风景图误写成视觉识别成功。
