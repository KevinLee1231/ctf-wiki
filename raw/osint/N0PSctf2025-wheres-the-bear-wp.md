# Where's The Bear

## 题目简述

绑架案链的第三题要求确定人质被关押的地点。上一题已经在 TopiaNews 的历史快照中找到会话 ID `1337` 和三名间谍，本题需要继续读取该对话的完整内容。

## 解题过程

archive.is 快照中的会话链接使用固定页面加数字 ID 的形式。进入 ID `1337` 后，不要只看首屏或参与者列表，而要展开完整聊天记录。三名绑匪在对话中讨论转移和看守 Bibzy，其中一条消息直接说出了关押地点：

```text
Pixel Candy Factory
```

这条信息与人物资料页无关，也不需要再做地理定位；题目询问的是故事世界中的地点名称。按照示例格式保留单词顺序，并用下划线替换空格：

```text
N0PS{Pixel_Candy_Factory}
```

## 方法总结

这一题的难点主要来自前一题建立的访问路径。获得会话 ID 后，应完整保存对话文本，并区分“碰面地点”“转移路线”和“实际关押地点”。本题的决定性证据是聊天中明确出现的 `Pixel Candy Factory`，无需从上下文猜测或使用第三方摘要。
