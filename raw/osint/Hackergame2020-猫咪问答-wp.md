# Hackergame2020 猫咪问答++ WP

## 题目简述

题目要求回答五个信息检索问题，内容涉及软件标志、RFC、USTC LUG 活动记录、校园街景和往届比赛统计。所有线索都能从公开资料得到，不需要校内权限；决定性主障碍是定位、交叉核对外部公开证据，因此归入 OSINT 方向。

## 解题过程

### 第一问：哺乳动物标志数量

逐项检查 23 个编程语言、软件或组织的标志。可计为哺乳动物的 11 项是：

```text
Docker
Golang
PHP
Plan 9
GNU
Firefox
MySQL
PostgreSQL
MariaDB
Apache Tomcat
Xfce
```

因此第一问填 `11`。Python 是蛇，LLVM 是龙，Swift 是鸟，Perl 是骆驼，Linux 是企鹅，OpenBSD 是河豚，Squid 是鱿鱼；GitHub 的 Octocat 属于虚构混合生物，官方答案不把它计入哺乳动物。若对这一问的边界判断没有把握，也可以先完成其余四问，再枚举 `0` 到 `23`。

### 第二问：信鸽 IP 的 MTU

“第一个以信鸽为载体的 IP 网络标准”指 1990 年发布的 RFC 1149，即 *A Standard for the Transmission of IP Datagrams on Avian Carriers*。文档明确建议将 MTU 设为 256 milligrams，所以填 `256`。

### 第三问：自由软件日开源游戏

USTC LUG 的 2019 年自由软件日活动记录中有主题《开源游戏 Teeworlds》。只统计名称 `Teeworlds` 的英文字母，共 9 个，因此填 `9`。

### 第四问：西区图书馆附近停车位

普通卫星图分辨率不足以稳定辨认划线，可在地图街景中定位中国科学技术大学西校区图书馆正前方、西南约 50 米处的 L 型灌木。沿灌木边缘逐个数相互连通的划线车位，共 9 个，填 `9`。

### 第五问：第六届比赛提交次数

USTC LUG 关于第七届信息安全大赛的宣传稿回顾了上一届统计数据，其中写明第六届比赛所有参赛者合计提交 17098 次 flag，因此填 `17098`。

五个答案依次为：

```text
11, 256, 9, 9, 17098
```

全部提交正确后，服务返回与当前用户绑定的 flag。

## 方法总结

信息检索题应把每个答案与证据类型对应起来：技术标准查 RFC 原文，社团活动查组织自己的历史页面，地理数量用街景复核，比赛统计优先找主办方总结。第一问存在分类边界，适合先列举明确项，再利用只有 24 种可能这一小搜索空间验证，而不是让一个争议标志拖住整题。
