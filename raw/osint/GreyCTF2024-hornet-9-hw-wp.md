# GreyCTF2024 Hornet 9 HW WP

## 题目简述

徽章通过 USB 串口提出七个与电路板有关的问题，要求全部使用小写回答。虽然题目放在 hardware 目录，决定性工作是读取芯片和元件信息并查询公开硬件资料，因此按 OSINT 归档。

## 解题过程

从主控芯片丝印、PCB 元件封装和 STM32/USB 公开资料可得到以下答案：

| 问题 | 答案 |
| --- | --- |
| MCU 型号 | `stm32f103c8t6` |
| 使用该 MCU 的常见开发板 | `bluepill` |
| 板上最小贴片电阻尺寸 | `0603` |
| 提供低价 PCB 制造的公司 | `jlcpcb` |
| HAL 全称 | `hardware abstraction layer` |
| 板上逻辑电平 | `3.3v` |
| USB 通信类别 | `communications device class` |

固件对每项执行精确的 `strcmp`，所以空格、大小写和缩写形式都必须与表中一致。依次输入七项后，固件设置黄色帽子解锁位并输出：

```text
grey{STM32_ExP3R1}
```

公开固件中的判断链也完整列出了这七个常量，可作为赛后复核证据。

## 方法总结

硬件外壳不等于硬件主障碍。本题没有利用引脚、总线或启动链，核心是把实物丝印与公开资料对应起来。对交互式问答还应检查固件是否使用精确字符串比较，避免因为合理但不同的缩写而失败。
