# sirkit

## 题目简述

题目给出 PCB 的 Gerber 制造文件和一份去掉位号对应关系的物料表，没有直接提供逻辑原理图。板上电路接收 5 位 `byte_num` 与 8 位 `byte_guess`，当猜中的字节等于内部目标字节时令 `guess_valid` 有效。目标是从制造数据恢复门级网表，再逐字节求出 flag。

## 解题过程

首先从 `F_Cu`、`In1_Cu`、`In2_Cu`、`B_Cu` 等铜层恢复焊盘之间的电气连通关系。Gerber 只描述几何图形，没有 KiCad 原理图中的网络名，因此需要把同一片连续铜箔触及的焊盘归为同一个 net，并结合钻孔与封装坐标跨层合并。`sch.csv` 能给出器件类型及数量，但位号已被移除，所以还要根据各封装引脚的接线形态确定芯片身份。

最容易先识别的是 15 片 `74LS40`。它包含两个四输入 NAND 门，DIP-14 的 3、11 脚未连接；这种两个固定空脚的特征能把它与其他同封装逻辑器件区分开。随后识别 4 片 `74LS04`：它是六反相器，1、3 脚都属于输入；观察这些引脚连接到上游输出而相邻的 2、4 脚作为输出，即可与二输入门芯片区分。

确定全部器件型号后，根据数据手册把每个门翻译成布尔约束。例如四输入 NAND 与反相器可分别表示为：

```python
gate_out = Not(And(a, b, c, d))
inv_out = Not(x)
```

再把恢复出的 net 当作共享布尔变量，按铜层连通关系连接各门。电路的外部输入是 `byte_num[4:0]` 和 `byte_guess[7:0]`，唯一关注的输出是 `guess_valid`。逐个固定字节下标 $i\in[0,31]$，枚举或让 Z3 求解满足以下条件的 8 位值：

```text
byte_num == i
guess_valid == 1
```

每个有效模型中的 `byte_guess` 就是该位置的字符。恢复到第 24 字节时已经得到闭合的 `}`，后面的七个 `X` 只是电路为 32 字节输入宽度设置的填充，无须计入 flag。最终结果为：

```text
DUCTF{51r_y35_s1r_c0ec4d}
```

## 方法总结

本题的难点不是某一种门电路，而是从制造层重新建立“焊盘—网络—门—布尔公式”的完整映射。处理去位号 BOM 时，应先找具有独特空脚或输入输出模式的器件作为锚点，再传播其余芯片类型。网表闭合后，逐字节约束 `guess_valid` 比试图整体化简数百个门更直接，也更容易用 Z3 检查唯一性。
