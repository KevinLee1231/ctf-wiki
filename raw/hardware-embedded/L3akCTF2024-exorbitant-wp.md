# L3akCTF 2024 eXORbitant Writeup

## 题目简述

附件是一个 Logisim 组合电路。它每次从 ROM 读取 2 字节 flag，把 16 个输入位送入 16 组 XOR 网络，再把得到的 16 位结果写入 RAM。RAM 中共有 16 个输出字，因此需要逆向同一个 $16\times16$ 的线性变换，恢复 32 字节明文。

每个输出位都只是若干输入位的异或，所以整个电路可写为有限域 $\mathrm{GF}(2)$ 上的线性方程：

$$
\mathbf{y}=M\mathbf{x}.
$$

## 解题过程

在 Logisim 中沿每个输出 XOR 门反向记录接入的输入线。用 `1` 表示该输入参与异或，得到矩阵 $M$ 的 16 行：

```python
masks = [
    "1010011011100110",
    "1100001000001110",
    "0111111010111010",
    "1111100101111000",
    "0001110001100110",
    "1000101001001001",
    "0100011110110011",
    "0000111111010101",
    "1101101111110101",
    "1011011101100011",
    "0000110010000100",
    "0100000011001000",
    "1111111100111001",
    "1010000010101111",
    "1100101011110011",
    "0111101010111100",
]
```

RAM 输出依次为：

```text
8094 6514 e9f3 cc9b a618 f075 eae8 30db
899f 6c8d 4bf2 34eb 30db b53a c777 0d65
```

可以对每个 16 位字单独建立约束。下面的脚本没有使用生成器中的明文常量，只根据电路矩阵和 RAM 输出求解：

```python
from z3 import Bool, Solver, Xor, is_true, sat

masks = [
    "1010011011100110", "1100001000001110",
    "0111111010111010", "1111100101111000",
    "0001110001100110", "1000101001001001",
    "0100011110110011", "0000111111010101",
    "1101101111110101", "1011011101100011",
    "0000110010000100", "0100000011001000",
    "1111111100111001", "1010000010101111",
    "1100101011110011", "0111101010111100",
]

words = [
    0x8094, 0x6514, 0xe9f3, 0xcc9b,
    0xa618, 0xf075, 0xeae8, 0x30db,
    0x899f, 0x6c8d, 0x4bf2, 0x34eb,
    0x30db, 0xb53a, 0xc777, 0x0d65,
]

plain = bytearray()

for block_id, word in enumerate(words):
    x = [Bool(f"x_{block_id}_{i}") for i in range(16)]
    solver = Solver()
    out_bits = f"{word:016b}"

    for row, mask in enumerate(masks):
        terms = [x[i] for i, used in enumerate(mask) if used == "1"]
        solver.add(Xor(*terms) == (out_bits[row] == "1"))

    assert solver.check() == sat
    model = solver.model()
    bit_string = "".join("1" if is_true(model.eval(v)) else "0" for v in x)
    plain.extend(int(bit_string, 2).to_bytes(2, "big"))

print(plain.decode())
```

输出为：

```text
L3AK{X0R_1s_EaS1lY_R3vErS1BLe!!}
```

仓库中的两张 PNG 分别只是电路起始状态和 RAM 十六进制窗口；前者的连接关系已完整写成矩阵，后者已转写为文本，因此不再保留低信息增益截图。

## 方法总结

只由 XOR 构成的组合逻辑本质上是 $\mathrm{GF}(2)$ 线性变换。识别出这一点后，可以用高斯消元、矩阵求逆或 SMT 求解，而不必对每个 16 位输入做 $2^{16}$ 次穷举。最容易出错的是位序：电路输入编号、二进制字符串的高低位和 RAM 十六进制显示顺序必须保持一致，恢复后应以已知 `L3AK{` 前缀校验。
