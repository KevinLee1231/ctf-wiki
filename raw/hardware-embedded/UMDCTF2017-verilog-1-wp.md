# Verilog 1

## 题目简述

`homework.v` 定义了一个 8 bit 输入 `d` 和九级寄存器链 `r`。每一级都要求上一级已置位，并对 `d[7:0]` 写出一组完整的按位真假条件。它本质上把八个输入字符硬编码成组合逻辑，再用时序链确认输入顺序。

## 解题过程

以第一项为例：

```verilog
r[0] <= ~d[7] & d[6] & d[5] & ~d[4]
      &  d[3] & d[2] & d[1] & ~d[0];
```

从 `d[7]` 到 `d[0]` 依次写成 0/1，可得 `01101110`，即 ASCII 字符 `n`。其余各级同理：

```text
r[0]  01101110  n
r[1]  00110000  0
r[2]  01011111  _
r[3]  01110011  s
r[4]  01010000  P
r[5]  00110001  1
r[6]  01100011  c
r[7]  00110011  3
```

`r[8] <= r[7]` 只是成功状态的延迟输出，并不增加字符。拼接八个字符得到：

```text
n0_sP1c3
```

因此 flag 为：

```text
UMDCTF-{n0_sP1c3}
```

其 SHA-256 与 README 中的摘要一致。

## 方法总结

这类 Verilog 题无需先搭建完整仿真环境。若一个布尔表达式同时约束了输入总线的每一位，就可以直接把取反项视为 0、正项视为 1，再按位序转换成 ASCII。还要区分“输入字符寄存器”和“成功状态寄存器”，避免把最后一级状态误算成额外字符。
