# Shooting Flags

## 题目简述

题目让徽章上的“士兵”按固定按钮序列行动，并通过 LED 输出编码后的 flag。仓库同时给出控制 Verilog 和官方解题概要，因此可从状态机还原按钮顺序、采样位序和 ASCII 重组过程。

## 解题过程

先观察无按钮时的基础射击图案：寄存器从 `8'b00000101` 开始循环左移，因此灯序列本身能帮助确认 LED 的物理左右方向。随后尝试按钮，顶层连接明确给出 `got_commanding_officer = ~btn[2]`，所以真正切换到 flag 显示的是按下第 3 个按钮。

现场解题时先在徽章代码中暂时禁用激光控制，避免它影响对 LED 的稳定观察，然后按住第 3 个按钮。`shooting_flag` 约以 4 Hz 更新时钟的分频结果轮换字符；第 $i$ 个字符还会循环左移 $i\bmod8$ 位后显示。每一步记录 8 个 LED 的亮灭，先按端口映射恢复字节，再对第 $i$ 组循环右移 $i\bmod8$ 位撤销旋转：

将每 8 位组合成一个字节，并用 ASCII 解码：

```python
raw = [...]  # 每次采样得到一个 8 位整数
data = bytes(((v >> (i % 8)) | (v << (8 - i % 8))) & 0xff
             for i, v in enumerate(raw))
print(data.decode())
```

输出：

```text
grey{eh_dont_only_wayang}
```

## 方法总结

本题应先从第一组已知行为恢复按钮排列，再读取 HDL 确认状态转移、LED 位序和扰动源。外部表格只是人工记录工具，关键规则已完整写入正文，因此不需要依赖该外链。读取硬件 LED 数据时，最常见错误是左右方向、LSB/MSB 顺序和激光触发的异步重置；这三点都应在转换 ASCII 前用已知字符前缀 `grey{` 校验。
