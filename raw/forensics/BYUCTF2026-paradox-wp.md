# Paradox

## 题目简述

抓包中有一组发往 UDP 端口 13337、外观类似 NTP 的 48 字节数据包。字符没有直接存入载荷，而是编码在四个时间戳字段与固定基准值的差中。

## 解题过程

先过滤 `udp.dstport == 13337`。每个载荷都按 NTP 布局放置四个 32 位秒字段，其起始偏移分别为 16、24、32 和 40。以大端读取这些值，再减去共同基准 `0x6553f100`，每个差值落在一个字节范围内，可直接转成字符。

核心恢复关系为：

    offsets = (16, 24, 32, 40)
    base = 0x6553f100
    chars = [int.from_bytes(pkt[o:o + 4], "big") - base for o in offsets]

按数据包顺序连接每组四个字符后得到：

    byuctf{S0_My_P4r4d0x_!d34_D!dnt_W0rk}

Wireshark 截图只标出了相同的时间戳数值，保留代码化的偏移与基准更便于复现。

## 方法总结

遇到“像标准协议但端口或字段分布异常”的流量，应同时检查字段语义和原始字节。时间戳、长度、序号等元数据都可以承载差分编码；必须明确端序、偏移和基准值，并用输出可打印性及 flag 格式交叉验证。
