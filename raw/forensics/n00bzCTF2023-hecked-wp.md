# Hecked

## 题目简述

题目给出服务器遭入侵时的 PCAP，要求确定易受攻击的服务、版本以及攻击者进入后执行的第一条命令，再按指定格式计算 MD5。

## 解题过程

在 Wireshark 中检查 FTP 控制流，可以看到服务横幅为 `vsFTPd 2.3.4`。继续跟踪相关 TCP 流，攻击者触发该版本著名的后门行为后获得命令通道，发送的第一条命令是：

```text
id
```

题面要求严格保留大小写和下划线，待哈希字符串为：

```text
vsFTPd_2.3.4_id
```

计算不带换行的 MD5：

```bash
echo -n 'vsFTPd_2.3.4_id' | md5sum
```

摘要为 `a806fef72a92508b7a64776bb83ad4cb`，所以 flag 是：

```text
n00bz{a806fef72a92508b7a64776bb83ad4cb}
```

## 方法总结

PCAP 取证要区分服务横幅、漏洞触发与后续命令三个阶段。本题最终摘要对大小写和拼接格式敏感，任何规范化都会得到错误答案。
