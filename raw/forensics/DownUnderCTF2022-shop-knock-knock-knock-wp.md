# DownUnderCTF 2022 Shop-Knock Knock Knock Writeup

## 题目简述

题目说明商店遭遇了密码喷洒或暴力破解，要求从 `DownUnderShop.JSON` 中识别攻击者 IP，再回答该地址所属 ISP 的滥用联系人邮箱。答案不使用 `DUCTF{}` 包裹，且不区分大小写。

这是一条“日志发现 → 注册信息归属”的调查链。WHOIS 只能在已经通过行为证据锁定 IP 后用于补充归属，不能把任意来源地址直接视作攻击者。

## 解题过程

先筛选 URL 中的 `/login`，按 `origin` 统计事件数。结果中 `58.164.62.91` 有 63 条登录相关记录，而其他来源最多只有 2 条，差异非常明显。

继续查看该 IP 的时间序列，可以看到：

- 数秒内重复向登录页发送 `POST`；
- 部分请求使用 `curl/7.64.1`；
- 同一来源此前还测试过基础 XSS，并浏览过 Web 安全相关页面；
- 请求模式不符合正常用户登录后继续购物的流程。

这些证据共同支持把 `58.164.62.91` 判定为爆破来源。随后对该地址做 IP WHOIS，查看网段的组织与 abuse/contact 字段。该地址属于 Telstra，注册信息给出的滥用联系邮箱为：

```text
abuse@telstra.net
```

这就是题目要求的答案。

## 方法总结

暴力破解调查应先用日志量、时间密度、请求方法和 User-Agent 建立行为证据，再查询 WHOIS。IP 地理位置或所属运营商本身不代表恶意；WHOIS 在本题中的作用只是把已确认的攻击源映射到负责处理滥用报告的联系人。归档时应记录关键 IP 与邮箱，避免未来 WHOIS 数据变化导致题解无法独立理解。
