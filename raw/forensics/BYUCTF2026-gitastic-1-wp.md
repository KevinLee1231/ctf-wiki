# Gitastic 1

## 题目简述

附件是一个 Git 仓库，flag 不在当前工作树，而被写入某次提交信息。需要检索版本元数据，而不是逐个打开现有文件。

## 解题过程

在仓库根目录查看完整日志，并直接按 flag 前缀搜索提交消息：

    git log --all --grep='byuctf{' --format=fuller

命中的提交说明中包含：

    byuctf{I_hop3_y0u_didnt_s3@rch_manually}

`--all` 会遍历所有本地引用可达的历史；若只运行默认 `git log`，可能漏掉其他分支上的对象。

## 方法总结

Git 取证不能只看工作树。提交消息、作者、标签、引用和不可达对象都是独立证据面。面对已知格式时，优先使用 Git 自带的结构化过滤功能，避免手工翻阅大量记录。
