# Strings

## 题目简述

WelcomeCTF2021 的 Strings 只提供一张能够正常打开的 `greycat.jpg`。题目名称提示不要只观察图像内容，而要检查文件中可打印的字符串。

## 解题过程

JPEG 解码器只关心格式结构和图像数据，文件中仍可能夹带或追加与显示无关的可打印内容。直接对原文件运行字符串提取，并筛选比赛 flag 前缀：

```bash
strings greycat.jpg | grep 'greyhats{'
```

也可以使用支持二进制文件搜索的工具：

```bash
rg -a -o 'greyhats\{[^}]+\}' greycat.jpg
```

两种方式都能从二进制字节流中定位到：

```text
greyhats{W4y2_T0_H1De_1nf0rm4t10N}
```

原图只是载体，其可见内容不参与定位 flag，因此无需把猫的截图复制到题解中。

## 方法总结

文件能够正常打开不代表其中只有规范图像数据。面对媒体取证题，应先进行低成本检查：识别文件类型、查看元数据、提取可打印字符串，再决定是否需要更深的结构分析。本题在字符串阶段即可闭环，继续做像素隐写反而会偏离证据。
