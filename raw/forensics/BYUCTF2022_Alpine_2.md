# BYUCTF 2022 - Alpine 2

## 题目简述

本题沿用 Alpine 1 的磁盘镜像，要求确定攻击者登录所使用的 IP。题面明确说明合法用户 Matt Johnson 从未远程登录，因此远程会话记录可以直接用于归因。

## 解题过程

将镜像启动到隔离环境或挂载并读取其登录数据库。原附件未保存在 Git 中，可从 Alpine 1 题面保留的 [Box 镜像链接](https://app.box.com/s/mi71hnua1osbnaludkxvmnbj1p65bi66/file/951434445088) 获取。

在系统内运行：

```bash
last
```

`last` 解析 `/var/log/wtmp`，列出用户名、终端、来源地址与会话时间。筛选 `mjohnson` 的远程 SSH 会话；由于题面排除了 Matt 本人的远程登录，记录中的来源地址就是攻击者地址：

```text
10.37.184.245
```

提交：

```text
byuctf{10.37.184.245}
```

## 方法总结

本题考查登录历史取证。`last` 的结论来自 `wtmp`，应与题面给出的“合法用户从未远程登录”条件一起使用；在真实事件中还应交叉核对 SSH 日志、时间线和 NAT/VPN 情况，不能仅凭一条会话记录确定个人身份。
