# Where am I

## 题目简述

附件是网络流量包。HTTP 会话中上传了一份 RAR，归档使用伪加密标志阻止正常解压；清除标志后可取得一张照片，最终答案不在照片画面中，而在 EXIF GPS 元数据里。决定性工作是从流量证据恢复文件并读取元数据，因此归入 Forensics。

## 解题过程

### 从 HTTP 流量恢复 RAR

在 Wireshark 中使用 `File -> Export Objects -> HTTP`，定位上传请求并导出对象。去掉 HTTP 边界或其它不属于归档的数据后，应以 RAR 签名开头：

```text
52 61 72 21 1A 07 00
```

若 WinRAR 报文件头损坏，可以先让 WinRAR 修复归档，再检查 RAR4 文件头的 `HEAD_FLAGS`。附件把加密标志位 `0x0004` 置 1，典型表现是标志从 `0x0020` 被改为 `0x0024`；将 `0x0024` 修回 `0x0020` 后即可无密码解压。

### 读取 EXIF 坐标

对解出的照片执行：

```bash
exiftool -GPSLatitude -GPSLongitude -GPSPosition photo.jpg
```

得到：

```text
GPS Latitude  : 39 deg 54' 54.18" N
GPS Longitude : 116 deg 24' 14.88" E
```

题目要求按“经度在前、纬度在后”的顺序，把度、分、秒和方向字母以下划线连接，并去掉秒的小数点：

```text
hgame{116_24_1488_E_39_54_5418_N}
```

## 方法总结

- 核心技巧：从 HTTP 对象恢复归档，清除 RAR 伪加密标志，再读取图片 EXIF GPS。
- 易错点：不要把归档修复与伪加密混为一谈；坐标格式要求经度在前，并把 `14.88`、`54.18` 写成 `1488`、`5418`。
- 复用要点：流量题应保留“网络对象 -> 归档 -> 文件 -> 元数据”的证据链，每一步都用文件签名或结构字段验证输出类型。
