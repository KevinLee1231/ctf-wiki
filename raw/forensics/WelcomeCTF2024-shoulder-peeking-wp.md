# Shoulder Peeking

## 题目简述

附件是 Windows Security 事件日志。访客先多次尝试登录某个账户，随后成功进入。目标是关联失败与成功的登录事件，确定被访问账户和首次成功时间。

## 解题过程

用 Event Log Explorer 或 Windows Event Viewer 打开 `Security.evtx`，重点过滤登录相关事件：

- 事件 ID `4625`：账户登录失败；
- 事件 ID `4624`：账户登录成功。

先按时间排序并寻找连续的 `4625`。在每条记录的详细字段中记下目标账户名，然后向后寻找同一账户的第一条 `4624`。这种“同一账户多次失败后首次成功”的序列正对应题面中的窥屏尝试。

关联结果显示账户为 `Rebecca Yeo`，成功时间为：

```text
21:26:19
```

按题目格式转换后得到：

```text
grey{rebecca_yeo_212619}
```

## 方法总结

事件日志取证不是搜索单条成功记录，而是按账户、事件类型和时间建立序列。`4625 → 4624` 的转变能区分正常登录与先猜错后成功的可疑行为，时间格式则应严格按题目要求规范化。
