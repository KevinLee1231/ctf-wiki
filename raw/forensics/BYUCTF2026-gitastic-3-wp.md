# Gitastic 3

## 题目简述

第三题的仓库包含大量标签。flag 位于一个附注标签的说明文字中，而不是标签所指向文件的内容。

## 解题过程

列出所有标签及其首行说明，并按 flag 前缀过滤：

    git tag -l -n99 | Select-String 'byuctf\{'

在 Bash 环境中等价地可以使用 `grep`。异常标签的注释给出：

    byuctf{that's_a_lot_of_tags_wow}

若只运行 `git tag`，只能看到标签名；必须使用 `-n` 或 `git for-each-ref` 读取附注标签对象的消息。

## 方法总结

轻量标签只是引用，附注标签则有独立对象、作者和消息。本题提醒我们在 Git 仓库中分别检查标签名、标签注释和目标提交，不能把三者当作同一种元数据。
