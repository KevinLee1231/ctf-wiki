# DownUnderCTF 2022 Shop-I'm just looking! Writeup

## 题目简述

题目要求从 `DownUnderShop.JSON` 的 HTTP 日志中识别针对商店执行漏洞扫描的工具名称。虽然可以用 IP 地理位置辅助缩小范围，决定性证据来自已经取得的日志，而不是外部公开情报，因此应归为取证。

正常顾客通常沿 `browse → product → checkout` 的业务路径访问；扫描器则会在很短时间内跳转到大量互不相关、具有已知漏洞探测特征的路径。

## 解题过程

按来源 IP 聚合请求数和不同 URL 数量，再检查不符合正常购物流程的来源。`194.163.140.128` 在数秒内访问了多个可疑路径，其中三条直接包含工具名：

```text
2021-01-01T09:01:12.000+0000  /wp-content/uploads/simple-file-list/nuclei.php
2021-01-01T09:01:16.000+0000  /nuclei.txt
2021-01-01T09:01:20.000+0000  /include/nuclei.txt
```

这类路径不是普通用户浏览商品时会连续请求的资源。`Nuclei` 是基于模板批量探测已知漏洞和错误配置的扫描器；这里无需依赖网站介绍才能作答，因为日志路径已经直接泄露了工具名称。

题目要求首字母大写，答案为：

```text
Nuclei
```

## 方法总结

识别 Web 扫描活动时，应同时使用行为和内容证据：先以来源 IP、时间密度、请求方法及 URL 多样性找出异常会话，再从探测路径、参数或 User-Agent 中归因具体工具。仅凭“来自境外 VPS”不能证明恶意，真正有区分力的是短时间内跨越大量非业务路径的模板化请求序列。
