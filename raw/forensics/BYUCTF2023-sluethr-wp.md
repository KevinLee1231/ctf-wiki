# BYUCTF 2023 - Sluethr

## 题目简述

题目提供一台虚拟机，默认凭据为 `vagrant:vagrant`，并声称只有从该虚拟机访问 `sluethr.byuctf.xyz` 才能取得 flag。决定性证据在虚拟机的本地域名解析配置。

## 解题过程

先比较两种环境：宿主机能解析目标域名，而虚拟机内浏览器无法按正常 DNS 得到相同结果。Linux 的名称解析在查询 DNS 前会检查 `/etc/hosts`，因此查看：

```bash
cat /etc/hosts
```

文件中存在针对 `sluethr.byuctf.xyz` 的静态映射，同时注释还保存了完成 flag 所需的最后五位。按照该映射访问网站，并将页面信息与注释拼合，即可得到完整值：

```text
byuctf{e8e823dbeac61d61b26565c518907549}
```

仓库没有收录原始 VDI，只保留了官方说明，因此这里记录的是官方证据链，无法在当前附件树中重新挂载验证镜像内容。

## 方法总结

当同一域名在两台机器上的行为不同，应依次检查 `/etc/hosts`、解析顺序、DNS 配置和代理，而不是只反复刷新浏览器。本题把“限定从某台 VM 访问”转化为本机工件调查。
