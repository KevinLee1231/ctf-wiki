# Hot Stuff

## 题目简述

附件是打印机作业数据，其中出现多条 `LAVAFLOW` 命令。命令参数中的三位数字不是坐标，而是三位八进制 ASCII 字节。

## 解题过程

从打印数据中筛出连续的三位数字参数，逐个按八进制转为整数，再解释为字符：

```python
tokens = ["146", "154", "157", "157", "162", "151", "163", "154", "141", "166", "141"]
print("".join(chr(int(x, 8)) for x in tokens))
```

得到 `floorislava`，按 flag 格式提交：

```text
n00bz{floorislava}
```

## 方法总结

打印机语言中大量数字容易被误判为坐标或尺寸。观察每组固定为三位且落在可打印 ASCII 的八进制范围，是识别编码的关键；解码后还应检查结果是否形成连续自然语言。
