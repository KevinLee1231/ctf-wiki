# Plane

## 题目简述

题目虽然是地点坐标，但决定性证据不来自公开搜索，而是 JPEG EXIF 中的 GPS 字段，因此归入取证。

## 解题过程

使用 `exiftool plane.jpg` 可读出：

```text
GPS Latitude  : 13 deg 22' 12.00" N
GPS Longitude : 13 deg 22' 12.00" W
```

度分秒转十进制度：

$$13+\frac{22}{60}+\frac{12}{3600}=13.37.$$

西经取负值，按题面保留两位小数：

```text
n00bz{13.37,-13.37}
```

## 方法总结

媒体题应先检查元数据，再决定是否需要 OSINT。坐标转换要正确处理半球符号：南纬和西经为负，且最后再按题目要求舍入。
