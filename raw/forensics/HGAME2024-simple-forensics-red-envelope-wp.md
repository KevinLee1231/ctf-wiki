# 简单的取证,不过前十个有红包

## 题目简述

本题沿用上一题的 VMDK 磁盘镜像。需要先在磁盘中找到记录 VeraCrypt 密码的图片，再用该密码挂载加密容器 `vera.hc`，读取其中的 `flag.txt`。它是一条“磁盘证据检索 → 密码线索 → 加密卷挂载”的取证链。

## 解题过程

### 在 VMDK 中寻找密码线索

把镜像载入 Magnet AXIOM 等取证工具后，可直接在图片证据中搜索关键字 `password`；也可以只读挂载磁盘并检查桌面文件。目标图片名为：

```text
secret_password.jpg
```

图片内容只有一行文本，不含需要保留的视觉结构，因此直接转写为：

```text
veracrypt_password
968fJD17UBzZG6e3yjF6
```

输入时要严格区分大小写与数字：密码为 `968fJD17UBzZG6e3yjF6`。

### 挂载 VeraCrypt 容器

在磁盘中导出 `vera.hc`，用 VeraCrypt 选择一个空闲盘符并输入上面的密码。题目没有要求额外的 PIM 或密钥文件，保持自动检测即可。挂载成功后，加密卷中只有 `flag.txt`，其内容为：

```text
hgame{happy_new_year_her3_1s_a_redbag_key_41342177}
```

原 PDF 的 Magnet AXIOM、密码图片和 VeraCrypt 界面截图均只承载上述文件名、密码和操作结果；这些信息已无损写入正文，故不额外保存界面截图。

## 方法总结

- 后续题复用前一题镜像时，应继续围绕已有证据源检索，而不是把它当成全新的附件重新猜格式。
- 取证软件的全文检索可快速定位文件名或图片 OCR 中的 `password`，但也应记录证据的原始文件名和所在镜像。
- VeraCrypt 密码区分大小写；应从原图逐字符核对，尤其注意 `f`、`J`、`D`、`U`、`B`、`Z` 与数字的组合。
- 解密容器后应直接记录 `flag.txt` 原文，避免手工重输导致下划线、数字或大小写错误。
