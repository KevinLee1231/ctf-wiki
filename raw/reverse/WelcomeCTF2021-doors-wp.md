# Doors

## 题目简述

WelcomeCTF2021 的 Doors 是一个四阶段 Python 校验程序。每扇门接收一个十进制整数，通过位运算、算术、固定随机序列或 MD5 链进行验证；四个正确口令还会作为种子解密 flag 的各个片段。

## 解题过程

第一扇门要求：

```python
(key & 0xfff) == 0x246
(key >> 12) == 0x942
```

直接拼接高低位：

$$
key=(0x942\ll12)\mathbin{|}0x246=9708102.
$$

第二扇门把十进制数拆成高位与末三位：

```python
(key % 1000) ** 3 == 78402752
((key // 1000) ^ 861) == 189
```

$\sqrt[3]{78402752}=428$，高位为 $861\oplus189=992$，所以口令是 `992428`。

第三扇门以固定种子 `52318` 打乱位置数组，再按该顺序重排输入的七个十进制数字。复现相同的 `random.shuffle`，逆置换目标 `2478123`：

```python
random.seed(52318)
positions = list(range(7))
random.shuffle(positions)
# positions 为 [6, 0, 3, 4, 5, 1, 2]
```

得到口令 `2187324`。

第四扇门从低位到高位逐个取十进制数字，并校验：

```python
md5(f"{i}_{digit}_{remaining_key}".encode()).hexdigest()
```

由于只有六位，可直接枚举 `000000` 到 `999999`，完全复现循环并比较六个目标摘要，唯一口令是 `612381`。

依次输入：

```text
9708102
992428
2187324
612381
```

程序用对应种子生成四字节随机异或流，解开各段并拼接为：

```text
greyhats{0p3n_th3m_w17h_c0d3}
```

## 方法总结

四关分别考查位域拼接、十进制分段、固定 PRNG 置换和小空间摘要约束。最稳妥的方法是逐关照抄校验语义写逆运算或验证器，并在输入前用原函数复验，而不是试图一次性猜完整 flag。
