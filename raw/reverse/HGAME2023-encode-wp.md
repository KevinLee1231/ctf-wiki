# encode

## 题目简述

程序把每个 8 位输入字符拆成两个 4 位数：先存低半字节，再存高半字节，最后与一个整数数组比较。这相当于一种没有查表的 Base16 表示；恢复时把相邻两个半字节重新拼回一个字符即可。

## 解题过程

IDA 反编译出的核心逻辑为：

```c
for (int i = 0; i < 50; ++i) {
    encoded[2 * i] = input[i] & 0xF;
    encoded[2 * i + 1] = (input[i] >> 4) & 0xF;
}
```

设一对数据依次为 `low`、`high`，原字节就是：

$$
x = low \mathbin{|} (high \ll 4)
$$

在 IDA 中把 `dword_403000` 定义成整数数组并导出；去掉尾部用于补齐的零后，有效数据如下。另一篇[参赛者复盘](https://oacia.dev/hgame2023-reverse-writeup/)也给出了相同数组和结果，可用于复核从 PDF 截图转写的数据。

```python
encoded = [
    8, 6, 7, 6, 1, 6, 13, 6, 5, 6, 11, 7, 5, 6, 14, 6,
    3, 6, 15, 6, 4, 6, 5, 6, 15, 5, 9, 6, 3, 7, 15, 5,
    5, 6, 1, 6, 3, 7, 9, 7, 15, 5, 6, 6, 15, 6, 2, 7,
    15, 5, 1, 6, 15, 5, 2, 7, 5, 6, 6, 7, 5, 6, 2, 7,
    3, 7, 5, 6, 15, 5, 5, 6, 14, 6, 7, 6, 9, 6, 14, 6,
    5, 6, 5, 6, 2, 7, 13, 7,
]

plaintext = bytes(
    encoded[index] | (encoded[index + 1] << 4)
    for index in range(0, len(encoded), 2)
)
print(plaintext.decode())
```

输出为：

```text
hgame{encode_is_easy_for_a_reverse_engineer}
```

## 方法总结

- 核心技巧：识别按低四位、高四位拆分字符的编码，并按相反顺序合并。
- 易错点：数组顺序不是常见十六进制文本中的“高位在前”，而是低半字节先存。
- 复用要点：遇到 `& 0xF`、`>> 4` 和长度翻倍的输出数组时，应优先考虑半字节拆分，并用一个已知字符验证拼接方向。
