# dream

## 题目简述

交互程序要求先回答两句固定文本，再提交两个满足混合算术约束的整数，最后进行 12 次话题选择，使状态变量 `asked` 恰好等于 2351。所有判断都在源码中，核心是约束求解与状态机路径构造。

## 解题过程

前两句输入为：

```text
sing
maybe I asked for too [many challenges to be written]
```

对整数约束使用 Z3，或结合乘积和取模关系手工分解，得到唯一可用解：

```python
from z3 import BitVec, Solver

n1 = BitVec("n1", 32)
n2 = BitVec("n2", 32)
solver = Solver()
solver.add(((((n1 * 3) ^ (47342 - 534)) % 1313) * 35) % 1515 == 1370)
solver.add(((((n2 * 5) % 7777 | 1111) * 35 - 5) % 1000) == 80)
solver.add(n1 % n2 == 20202020)
solver.add(n1 * n2 == 14590347874298541)
assert str(solver.check()) == "sat"
print(solver.model())
```

```text
n1 = 131313131
n2 = 111111111
```

三种话题分别执行 `+1`、`平方`、`+22`。以下 12 步满足目标：

```text
+22, +22, +1, +1, +1, +1, square, +22, +22, +1, +1, +1
```

状态变化为 $0\to44\to48\to2304\to2348\to2351$。按顺序提交对应句子后得到：

```text
tjctf{5h3_ju5t_w4nt5_t0_st4y_1n_th4t_l4vend3r_h4z3_3a17362a}
```

## 方法总结

- 对混合位运算、模运算和乘积约束，位向量求解器比逐个猜测更稳妥；位宽应与程序实际整数语义一致。
- 后半段是小型状态机，可从目标值反推或用 BFS 搜索固定步数路径。
- 最终交互脚本应复用源码中的精确字符串，避免因标点、空格或大小写导致错误分支。
