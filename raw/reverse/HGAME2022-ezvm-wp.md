# ezvm

## 题目简述

题目用自定义虚拟机解释一段字节码来校验 32 字节输入。需要先恢复各个 opcode 的寄存器、栈、跳转和输入输出语义，再把字节码还原为普通控制流。最终加密只包含逐字节乘二和异或，可以直接逆运算得到 flag。

## 解题过程

先从解释器的 `switch-case` 为每个 opcode 建立语义。对解题最关键的操作包括：

| 操作 | 语义 |
| --- | --- |
| `OP_STREAM_IN` | 读入一个字符到 `eax` |
| `OP_PUSH_EAX` / `OP_POP_*` | 在虚拟栈与寄存器之间传值 |
| `OP_GET_MEM` / `OP_SET_MEM` | 读写输入缓冲区 |
| `OP_ADD eax, eax` | 将当前输入字节乘以 2 |
| `OP_XOR eax, esi` | 与当前密钥字节异或 |
| `OP_CMP`、`OP_JNE` | 比较并按相对偏移跳转 |
| `OP_STREAM_OUT` | 输出成功提示 |

把字节码翻译后，程序首先循环读取字符直到换行，然后检查有效长度必须为 `32`。加密循环对第 $i$ 个输入字节执行：

$$
c_i = (2p_i) \oplus k_i
$$

随后逐字节与内置密文比较。因为合法字符乘二后最低位必为 0，逆运算可以直接写成：

$$
p_i = \frac{c_i \oplus k_i}{2}
$$

从数据区提取密钥和密文：

```python
xor_keys = [
    94, 70, 97, 67, 14, 83, 73, 31,
    81, 94, 54, 55, 41, 65, 99, 59,
    100, 59, 21, 24, 91, 62, 34, 80,
    70, 94, 53, 78, 67, 35, 96, 59,
]

cipher = [
    142, 136, 163, 153, 196, 165, 195, 221,
    25, 236, 108, 155, 243, 27, 139, 91,
    62, 155, 241, 134, 243, 244, 164, 248,
    248, 152, 171, 134, 137, 97, 34, 193,
]

plain = "".join(
    chr((encrypted ^ key) // 2)
    for encrypted, key in zip(cipher, xor_keys)
)
print(plain)
```

输出为：

```text
hgame{Ea$Y-Vm-t0-PrOTeCT_cOde!!}
```

## 方法总结

自定义 VM 题应先恢复最小可用的指令语义，不必一开始就实现完整反汇编器。本题只需沿输入、长度检查、加密和比较四段控制流，便能把大量栈操作压缩成一个逐字节公式。确认运算顺序后，乘二与异或都可直接逆转，剩余工作只是准确提取密钥和密文数组。
