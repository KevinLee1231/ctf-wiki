# u

## 题目简述

题目给出一个用大量相似 Unicode 标识符混淆的 Python 脚本。还原别名后，程序包含 30 个整数 `stored`，生成集合

```python
list(set(pow(3, i, 256) for i in range(256)))[3:33]
```

作为 30 个乘数，并要求每一位满足 `factor[i] * ord(input[i]) == stored[i]`。

## 解题过程

先把 Unicode 名称逐个重命名：`ű` 是 `pow`、`ų` 是 `range`、`ṳ` 是 `list`、`ụ` 是 `set`、`ú` 是 `ord`。在题目使用的 Python 环境中重新执行乘数表达式，得到：

```text
[131, 9, 137, 139, 11, 145, 17, 147, 19, 25,
 153, 27, 155, 161, 33, 163, 35, 169, 41, 43,
 171, 49, 177, 179, 51, 185, 57, 187, 59, 65]
```

逐项整除即可恢复字符：

```python
stored = [
    12838, 1089, 16029, 13761, 1276, 14790, 2091, 17199, 2223, 2925,
    17901, 3159, 18135, 18837, 3135, 19071, 4095, 19773, 4797, 4085,
    20007, 5733, 20709, 17005, 2601, 9620, 3192, 9724, 3127, 8125,
]
factors = list(set(pow(3, i, 256) for i in range(256)))[3:33]
assert len(factors) == len(stored)

flag = "".join(chr(value // factor)
               for value, factor in zip(stored, factors))
print(flag)
```

结果为：

```text
byuctf{uuuuuuu_uuuu_uuu_34845}
```

这里的 `list(set(...))` 顺序属于实现细节，不应假定在任意 Python 实现和版本上都相同；最稳妥的做法是在题目指定环境执行原表达式，并将结果回放原断言验证。

## 方法总结

- 核心技巧：先去除 Unicode 标识符混淆，再对逐字符乘法校验做直接整除逆运算。
- 识别信号：单行混淆脚本若只是给 builtins 改名，应先建立别名表，避免被视觉相似字符掩盖简单数据流。
- 复用要点：保留目标运行时的容器顺序语义；恢复后必须重新运行原断言，而不能只凭 flag 外形判断正确。
