# BYUCTF 2023 - Sassie

## 题目简述

附件是剥离符号的 PIE ELF，运行时动态构造字符串、设置 5 秒 alarm、扫描 `/proc` 检测 GDB，并检查临时文件。通过检查后，它在固定 RWX 区域生成两阶段 shellcode，最终解密 flag。

## 解题过程

在隔离调试环境中跳过 alarm 和 GDB 检测分支，并创建要求的文件：

```bash
printf lol > /tmp/tmpt2nxegs1
```

程序验证该文件内容的 MD5 后，在 `0x54551300000` 一带映射可执行内存。第一阶段向 `0x54551300300` 写入预处理字节并生成第二阶段；第二阶段在约 `0x54551301000` 运行，用循环密钥：

```text
46 38 11 db d1 a3
```

异或 `0x54551300300` 的数据。对该区域设置观察点，单步越过解密循环后即可在内存/栈上读到：

```text
byuctf{sorry_f0r_b31ng_545513}
```

## 方法总结

动态字符串和自修改 shellcode会削弱静态 `strings` 的效果，但固定映射地址给了稳定断点。应先满足或旁路环境检查，再在“写密文、生成代码、执行解密”三个边界设置断点，避免在无关反调试逻辑中消耗时间。
