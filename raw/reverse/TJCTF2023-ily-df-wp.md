# ily-df

## 题目简述

题目提供一个终端版 Dwarf Fortress 游戏。世界生成器把 flag 位图转成地下沙块图案，但正常采集资源和挖掘需要很长时间。发布仓库的官方解法使用 GDB 修改玩家背包，触发源码中的隐藏递归清场条件，再快速落到地下查看图案。

## 解题过程

在 `nodelay` 处断下，输入 `Y` 通过说明页后执行 `finish`，从附近的 RIP 相对寻址取得全局 `astro.inv[256]` 地址。背包以物品字符的 ASCII 值为下标；隐藏条件为：

```c
astro.inv['F'] == 68 &&
astro.inv['N'] == 100 &&
astro.inv['V'] == 89 &&
astro.inv['O'] != 5 &&
astro.inv['D'] < 0
```

若该条件成立且正在挖岩石，`recur_smash` 会递归清除相连岩层。以官方运行中的背包地址为例，可写入：

```gdb
set ({int[256]}0x55555565990c)[70] = 68
set ({int[256]}0x55555565990c)[78] = 100
set ({int[256]}0x55555565990c)[86] = 89
set ({int[256]}0x55555565990c)[79] = 4
set ({int[256]}0x55555565990c)[68] = -5
continue
```

实际地址受 PIE/ASLR 影响，应以当次调试的 `lea` 结果为准。回到游戏后挖一个 `L` 岩块，递归清场并让角色落到底部；再向左清理遮挡，即可读出世界中的位图文字：

```text
tjctf{i-L0v3-you-Dwarf-Fortre$s}
```

仓库中的 `flag.png` 只是上述文字的 120×26 纯文本位图源，关键信息已完整转写，因此不保留低分辨率重复图片。

## 方法总结

- 游戏逆向应先找胜利条件、隐藏分支和关键状态数组，不必按正常玩法完成漫长资源循环。
- 全局数组用字符常量索引时，GDB 下标就是对应 ASCII 值；写入前应从源码逐项核对条件。
- PIE 地址不能照抄固定值，必须从本次运行的反汇编或符号表达式重新定位。
