# UMDCTF 2019 - LockPickSimV2

## 题目简述

附件是一个静态 Go 二进制。程序读取一个整数“锁芯编号”，转成浮点数后做一次固定乘法，再与目标常量比较。

## 解题过程

在 Go 主函数中可以定位到两个 IEEE 754 双精度常量：

```text
0x4630000000000000 -> 2^100
0x472f8f0000000000 -> 64632 * 2^100
```

校验等价于：

```python
pin = (64632 * 2**100) / 2**100
print(int(pin))
```

因此输入：

```text
64632
```

原始二进制实际输出：

```text
UMDCTF-{I_g0t_64632_pr0blems_but_@_l0ck_aint_one}
```

需要说明一处仓库不一致：这个由官方二进制直接生成的字符串，其 SHA-256 不等于 `README.md` 中记录的 `9747b34d...51fe505`。没有源码或其他官方材料能解释差异，因此这里以可执行文件的确定性行为为准，并保留该异常，不伪造一个只为迎合摘要的 flag。

## 方法总结

识别浮点常量时，不要把原始 64 位十六进制数当普通整数比较；应按 IEEE 754 重新解释。两个巨大常量的比值恰好是小整数，直接揭示输入。若程序输出与元数据摘要冲突，应报告证据链和冲突本身，而不是反向猜测不可验证的答案。
