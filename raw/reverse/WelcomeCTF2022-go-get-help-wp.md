# go-get-help

## 题目简述

附件提供 Go 程序及其 SSA（Static Single Assignment）形式。程序读取一个 34 字节字符串，通过固定位置字符、多个位置相等关系和数字转换检查 Flag。目标是从 SSA 中恢复这些约束，而不是爆破整个字符串。

## 解题过程

先在 `main.ssa` 中定位成功分支附近的字符串比较、索引取字节和 `strconv.Atoi` 调用。检查逻辑可整理为三类约束：

```go
len(flag) == 34
flag[:9] == "greyhats{"
flag[len(flag)-1] == '}'

flag[9] == flag[16] && flag[16] == flag[24] && flag[24] == flag[25]
flag[13] == '1' && flag[17] == '1' && flag[26] == '1'
flag[15] == flag[22] && flag[22] == '_'
```

其余比较同样逐项填入 34 个位置。对只给出“两个位置相等”的约束先归并为一组，再用该组中出现的常量一次性确定所有成员，可避免重复推导。最终恢复：

```text
greyhats{st4t1c_s1nGl3_4ss1Gnm3nt}
```

将字符串输入程序会走到 `You won! That's the flag!` 分支，官方公开源码中的检查函数也与上述结果一致。

## 方法总结

SSA 会把复杂表达式拆成大量单赋值临时变量，但索引、常量和控制流依旧可追踪。处理此类 Flag checker 时，应先恢复长度与格式，再把位置相等关系视为等价类，最后填充常量；这比按源码执行顺序逐行猜字符更清晰，也容易发现尚未受约束的位置。
