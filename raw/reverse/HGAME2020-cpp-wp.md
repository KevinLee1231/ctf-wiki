# cpp

## 题目简述

程序要求输入 `hgame{...}`，花括号内是 9 个由下划线分隔的有符号整数。校验逻辑把这 9 个数分成三组，每组三个未知数，并建立 9 条线性方程；同时还检查完整输入长度为 62。官方 PDF 只给出了题目标题，缺少可理解的解题过程，因此这里依据保留了校验式的[参赛者复盘](https://www.cnblogs.com/harmonica11/p/12203694.html)补全。

## 解题过程

按程序的解析顺序记 9 个整数为 $x_0,x_1,\ldots,x_8$，校验条件为：

$$
\begin{aligned}
x_0+x_2&=26727, & x_1+2x_2&=24941, & x_0+x_1+2x_2&=101,\\
x_3+x_5&=29285, & x_4+2x_5&=26995, & x_3+x_4+2x_5&=29551,\\
x_6+x_8&=29551, & x_7+2x_8&=25953, & x_6+x_7+2x_8&=29561.
\end{aligned}
$$

这些都是整数线性约束，可手算消元，也可用 Z3 避免处理负数时出错：

```python
from z3 import Ints, Solver, sat

x = Ints("x0 x1 x2 x3 x4 x5 x6 x7 x8")
s = Solver()
s.add(
    x[0] + x[2] == 26727,
    x[1] + 2 * x[2] == 24941,
    x[0] + x[1] + 2 * x[2] == 101,
    x[3] + x[5] == 29285,
    x[4] + 2 * x[5] == 26995,
    x[3] + x[4] + 2 * x[5] == 29551,
    x[6] + x[8] == 29551,
    x[7] + 2 * x[8] == 25953,
    x[6] + x[7] + 2 * x[8] == 29561,
)

assert s.check() == sat
m = s.model()
values = [m[v].as_long() for v in x]
print(values)
print("hgame{" + "_".join(map(str, values)) + "}")
```

解为：

```text
[-24840, -78193, 51567, 2556, -26463, 26729, 3608, -25933, 25943]
```

代回 9 条方程均成立，按程序要求用下划线连接后得到：

```text
hgame{-24840_-78193_51567_2556_-26463_26729_3608_-25933_25943}
```

该字符串长度恰为 62，满足额外的长度检查。

## 方法总结

- 核心技巧：把复杂的 C++ 输入处理剥离为整数解析与线性约束，再统一求解。
- 识别信号：大量加法、常数乘法和等值比较，且不存在模运算或非线性乘积，通常就是线性方程组。
- 复用要点：求出数值后还要复原精确输入语法；负号、下划线和总长度都可能是独立校验条件。
