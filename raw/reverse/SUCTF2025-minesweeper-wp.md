# minesweeper

## 题目简述

程序读取一行文本，先通过自定义十六进制表解码，再要求结果长度恰好为 50 字节。每个 bit 对应 $20\times20=400$ 个格子中的一个，1 表示有雷，0 表示无雷。

内置的 `problem[20][20]` 给出局部雷数。与传统扫雷不同，计数范围是以当前格为中心、包含当前格自身的 $3\times3$ 区域；值为 `-1` 的位置不施加约束。恢复全部 400 个二进制变量后，还要按程序的 bit 顺序打包，并使用被替换的十六进制字符表编码输入。

## 解题过程

主函数的关键流程为：

```c
char buf[102];
read(0, buf, 96);
answer = unhex(buf);
check(answer, decoded_length);
```

`check()` 首先验证 `decoded_length == 50`，随后逐格比较：

```c
if (problem[y][x] != -1
    && problem[y][x] != square_bombcount(answer, y, x))
    fail();
```

设 $b_{y,x}\in\{0,1\}$ 表示第 $(y,x)$ 格是否有雷。对每个有效提示 $p_{y,x}$，约束为：

$$
\sum_{dy=-1}^{1}\sum_{dx=-1}^{1}
b_{y+dy,x+dx}=p_{y,x},
$$

超出边界的格子按 0 处理。题目表如下：

用 Z3 为每个格子创建 0/1 整数变量：

```python
from z3 import Int, Or, Solver, Sum, sat
from hashlib import md5

blocks = [
    [Int(f"x_{y}_{x}") for x in range(20)]
    for y in range(20)
]

def cell(y, x):
    if not (0 <= y < 20 and 0 <= x < 20):
        return 0
    return blocks[y][x]

solver = Solver()
for row in blocks:
    for value in row:
        solver.add(Or(value == 0, value == 1))

for y in range(20):
    for x in range(20):
        if problem[y][x] == -1:
            continue
        around = [
            cell(y + dy, x + dx)
            for dy in range(-1, 2)
            for dx in range(-1, 2)
        ]
        solver.add(Sum(around) == problem[y][x])

assert solver.check() == sat
model = solver.model()
```

程序按行编号格子，并把第 $i$ 个格子的值放在第 `i // 8` 字节的第 `i % 8` 位，即每字节最低位在前：

```python
raw = bytearray(50)
for y in range(20):
    for x in range(20):
        bit = model.eval(blocks[y][x], model_completion=True).as_long()
        index = 20 * y + x
        raw[index // 8] |= bit << (index % 8)
```

标准十六进制串不能直接提交。`unhex()` 使用的字符表相当于把：

```text
0123456789abcdef
```

依次替换为：

```text
abcdef0123456789
```

所以最后执行：

```python
encoded = raw.hex().translate(
    str.maketrans("0123456789abcdef", "abcdef0123456789")
)
print(encoded)
print(f"SUCTF{{{md5(encoded.encode()).hexdigest()}}}")
```

得到提交串：

```text
f57503596fb80f955fa5cad3cb282aa18ac62922a1981ea7b53b07a30709b508f3176601154250d509b7bee0f2170b898617
```

程序对这段 100 字符文本计算 MD5，最终 flag 为：

```text
SUCTF{d661b98e4241de7423ef2d953098329d}
```

## 方法总结

本题需要把三层表示严格区分：Z3 中的 400 个格子、按低位优先打包的 50 字节，以及换表后的 100 字符输入。只求出雷区而忽略 bit 顺序，会得到整体不同的字节串；只按标准 hex 输出，也无法通过 `unhex()`。

约束建模时还要注意两个非传统细节：局部计数包含中心格，边界外按 0 处理。`-1` 仅表示该位置没有等式约束，并不表示该格一定无雷。最终同时用程序接受输入、编码串长度为 100、以及 MD5 flag 三项验证结果。
