# DownUnderCTF 2023 The Bridgekeepers 3rd Question Writeup

## 题目简述

题目提供一个网页脚本，要求回答守桥人的第三个问题。脚本定义了从 `a` 到 `m` 的多个状态数组，每个数组有 26 个入口；输入的 13 个小写字母分别作为数组下标，使程序在状态之间跳转。只有最终状态等于字符串 `blue` 才会通过检查。

## 解题过程

将 JavaScript 中的数组关系视为一张有向图：当前状态决定使用哪个数组，字符 `a` 到 `z` 分别对应下标 0 到 25。起点是状态 `a`，目标是 `blue`，输入长度固定为 13。

沿着能到达目标的边反向追踪，或对状态和深度执行广度优先搜索，可以得到下标序列：

```text
17, 4, 1, 4, 2, 2, 0, 15, 20, 17, 15, 11, 4
```

把 0 到 25 映射为 `a` 到 `z`：

```python
indices = [17, 4, 1, 4, 2, 2, 0, 15, 20, 17, 15, 11, 4]
answer = "".join(chr(ord("a") + index) for index in indices)
print(answer)
```

输出为 `rebeccapurple`。提交后得到 flag：

```text
DUCTF{rebeccapurple}
```

## 方法总结

网页只是载体，决定性步骤是还原脚本中的状态机。把字符输入改写为“状态、下标、下一状态”的图搜索问题后，复杂的嵌套数组就会变得清晰。最终答案还是一个合法的 CSS 颜色名，这也与题目的第三个问题相呼应。
