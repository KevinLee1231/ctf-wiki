# LockPickSim

## 题目简述

`lockpicksim` 读取一个十进制整数，随后对 100 做有符号除法。程序分别检查商和余数，而不是模拟真正的开锁过程。

## 解题过程

关键分支要求：

```text
input / 100 == 48
input % 100 == 1
```

因此输入必须满足：

$$
input=48\times100+1=4801
$$

运行程序并输入 `4801` 后，通过所有四个虚拟锁针并输出 flag：

```text
UMDCTF-{you_p1cked_4801_correctly}
```

该字符串的 SHA-256 与 README 中的 `8efae064580b576253700689ebc2c7f014f7626b5ad1decbd13c52832fd3df33` 一致。

## 方法总结

这类入门逆向题常把一个输入拆成商和余数分别比较。将两条约束重新组合即可直接求出原数，不需要枚举四位数字。分析时还应确认除数、符号和输入解析函数，避免把十进制文本误当作十六进制。
