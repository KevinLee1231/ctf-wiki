# jmp flag

## 题目简述

程序读取恰好 64 个字符，并通过内联汇编跳到每个字符对应的 128 字节函数块。全局 `out` 初始为全 1；有效函数只有在其“前置位掩码”均已清零时才异或清除自己的唯一位，非法字符会把 `out` 重新置为全 1。最终只有 64 个合法字符按唯一的拓扑顺序处理完才能使 `out == 0`。

核心是从函数块的掩码恢复字符的偏序，而不是构造控制流破坏，归入 Reverse。

## 解题过程

### 从函数块提取顺序

生成器对 flag 字符的第 $i$ 项构造：

$$r_i=\sum_{j<i}2^{b_j},$$

再生成检查 `!(out & r_i) && (out ^= 2^{b_i})`。因此 mask $r_i$ 中恰有 $i$ 个已要求清零的位，故其 popcount 就是该字符在 flag 中的位置。`t` 是首字符，掩码为 0，官方 solver 将它单独补回。

发布二进制中每个字符对应一个定长 128 字节函数块，起点为文件偏移 `0x1300`。对 128 块用 Capstone 反汇编：遇到 `and` 或 `movabs` 立即数便取得 mask；无有效掩码的块是非法字符。恢复步骤为：

```python
flag = ['~'] * 64
for byte, mask in valid_blocks:
    flag[mask.bit_count()] = chr(byte)
flag[0] = 't'
```

### 验证

拼出的 64 字符串作为输入时，按顺序清除 64 个不同 bit，`check()` 的 `out == 0` 成立。题目配置给出完整验证 flag：`DUCTF{tAb1HFK5h3ZgEX7UTMQfsivcPOaJ?nRy8jrYLVB9Ilempw6xWq2zC0d!SDukG4No}`。本文未运行 binary；函数块尺寸、掩码规则和结果由源码、生成器及官方 solver 静态确认。

## 方法总结

- 核心技巧：把位状态检查转成偏序图；若每步清除唯一 bit，前置 mask 的 popcount 直接给出拓扑位置。
- 识别信号：输入字符跳表、重复函数模板、全 1/全 0 位状态和条件 XOR 时，应抽取常量而非手工追踪 64 次跳转。
- 复用要点：先确认每个合法函数确实对应唯一被清除 bit；若依赖不是完整前缀，应改用图拓扑排序，不能只依赖 popcount。
