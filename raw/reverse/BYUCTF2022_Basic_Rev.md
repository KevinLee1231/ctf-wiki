# BYUCTF 2022 - Basic Rev

## 题目简述

附件是一个要求输入整数的 C++ 程序。即使输入正确，它也只打印 `Finished processing flag!`，不会把构造出的 flag 输出到终端，因此必须恢复 `constructFlag` 的数据流。

## 解题过程

反编译可见只有 `val == 289` 才进入 flag 构造分支。局部字符串从 `ctf` 开始，前置 `byu`，随后追加常量字符串、十进制数字与由 `val` 计算出的字符。逐项化简：

```text
char(289 - 236) = char(53)  = '5'
char(289 - 173) = char(116) = 't'
char(95)                      = '_'
to_string(4)                  = "4"
char(100 + 14)                = 'r'
```

按程序实际顺序拼接：

```text
"byu" + "ctf" + "{" + "t3" + "5" + "t" + "_" +
"fl" + "4" + "g" + "_p" + "l3453" + "_" +
"ig" + "n0" + "r" + "3" + "}"
```

得到：

```text
byuctf{t35t_fl4g_pl3453_ign0r3}
```

## 方法总结

程序输出不等于程序内部结果。面对“正确输入后仍不显示 flag”的逆向题，应跟踪字符串对象的每次追加，并把整数运算还原为 ASCII 字符，而不是只动态运行寻找输出。
