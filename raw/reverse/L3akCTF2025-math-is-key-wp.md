# L3akCTF 2025 Math Is Key Writeup

## 题目简述

题目给出一个经过 `-O3 -flto` 编译的 ELF，要求依次输入五个整数。程序用刻意低效的方式实现基本算术，并在优化时把大量逻辑内联，使静态反编译结果远比实际数学关系复杂。

决定性障碍是从优化后的检查器恢复五个输入约束，因此本文按 Reverse 归档。

## 解题过程

### 用采样恢复前两个函数

第一项检查可以在最终比较前下断点，替换输入并记录变换后的值。几组观测为：

```text
123 -> 0x1fca527
789 -> 0x1fca7c1
545 -> 0x1fca6cd
```

用多项式插值或直接观察差分可知函数为：

```text
f(x) = x + 33334444
```

比较目标为 `0x1538BEBAD`，所以：

```python
k1 = 0x1538BEBAD - 33334444
# 5663311617
```

第二项同样采样：

```text
123    -> -0x581fa8a81609
456    -> -0x581fa8a81222
789    -> -0x581fa8a80e3b
101112 -> -0x581fa8a37692
```

插值得到 $f(x)=3x-96892996818810$。程序要求结果等于 12，故：

```python
k2 = (12 + 96892996818810) // 3
# 32297665606274
```

### 解出其余三项

第三项是 64 位无符号加法：

$$
x+9371337133713371337=9696421969563673637
$$

所以：

```text
k3 = 325084835850302300
```

第四项要求输入小于 $10^{12}$，并同时被 7、857、2837 和 19843 整除。这四个数互质，取乘积即可：

```python
from math import prod

k4 = prod([7, 857, 2837, 19843])
# 337711251409
```

第五项只是与常量 `0x14feb1657751986` 比较：

```text
k5 = 94552598387169670
```

因此五个输入依次为：

```text
5663311617
32297665606274
325084835850302300
337711251409
94552598387169670
```

### 按程序给出的整数解码

五项均通过后，程序会打印一条 Python 解码命令，其中还包含由程序补上的尾部十进制数字。不能只把五个 key 自行拼接，否则会漏掉这段后缀。程序给出的完整整数为：

```python
a = 56633116173229766560627432508483585030230033771125140994552598387169670804300
print(a.to_bytes(32, "little"))
```

按 32 字节小端序转换后得到：

```text
L3AK{w31c0m3_b4cK_t0_m4th_cl455}
```

## 方法总结

高优化级别会破坏源码层面的函数边界，却不会改变输入与比较值之间的数学关系。面对被内联的低效算术，可以在最终比较点采样少量输入输出，用差分、插值或符号回归恢复低阶函数，而不必逐条解释优化器展开的指令。

求出验证输入后还应继续观察成功路径。本题的五个 key 只是让程序输出最终解码整数；真正的 flag 需要按程序指定的长度和小端字节序转换。停在“检查通过”而忽略后续输出，会得到不完整的拼接数据。
