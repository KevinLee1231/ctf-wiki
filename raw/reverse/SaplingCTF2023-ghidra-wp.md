# ghidra

## 题目简述

题目提供一个适合初次使用 Ghidra 的 ELF 程序。flag 的主体不是隐藏数据，而是 main 中依次调用的若干函数名拼接结果；需要通过反编译器查看调用图和符号名称。

## 解题过程

在 Ghidra 新建项目，导入 ghidra_intro，完成默认分析。进入 Symbol Tree 的 Functions，打开 main，并在反编译窗口按控制流顺序记录被调用的题目函数。

不要把启动代码、puts 等库函数混入结果，只拼接题目特意命名的函数。按 main 的实际调用顺序组合后得到：

~~~text
gH1dra_Is_w4Y_b3tteR_th4N_IDA_a346B0a627764h
~~~

按题目要求加上外层格式：

~~~text
maple{gH1dra_Is_w4Y_b3tteR_th4N_IDA_a346B0a627764h}
~~~

## 方法总结

初学逆向时应先区分程序入口胶水代码、库函数和业务函数。题目保留了符号，因此无需从汇编猜测算法；最短路径是从 main 的反编译结果沿调用顺序读取函数名。即使答案看起来像可搜索字符串，也应由调用关系验证其顺序。
