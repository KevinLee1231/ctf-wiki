# Greycademy2025 Artifact 10: Python

## 题目简述

附件是一段分三关检查整数的 Python 程序。通过全部检查后，程序把三个输入直接拼成 `grey{...}`，因此需要逐段读代码并逆运算。

## 解题过程

第一关连续要求：

```python
x - 50 >= 4787566 - 50
x + 100 <= 4787566 + 100
```

两式合起来唯一确定 `x = 4787566`；后续加乘只是障眼法，不参与返回值。

第二关从末尾的 `i == 61` 反向执行每一步：遇到减法就加回，遇到除法就乘回。

```python
i = 61
h = i + 49
g = h * 53
f = g + 39
e = f * 85
d = e + 46
c = d * 107
b = c + 67
a = b * 128
x = a + 17
print(x)  # 6833093649
```

第三关令 `a = 67x`，并根据 `a % 5` 选择数组补偿值。尝试五种余数，只有余数 1 对应 `FUNNY_ARRAY[1] = 12`，于是：

```text
67x + 12 = 497972353
x = 7432423
```

把三个答案交给原程序：

```text
4787566
6833093649
7432423
```

程序输出：

```text
grey{4787566_6833093649_7432423}
```

## 方法总结

代码阅读时应先识别真正影响分支的表达式，忽略只改变局部变量却不再使用的噪声。线性运算链可以从目标值逐步逆推；带数组索引和取模的关卡则枚举有限余数类，再检查整除性。最终将结果送回原程序，是比只看仓库 flag 更可靠的验证。
