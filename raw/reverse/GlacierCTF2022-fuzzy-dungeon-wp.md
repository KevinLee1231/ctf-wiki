# GlacierCTF2022 - Fuzzy Dungeon

## 题目简述

这是一个远程文字地牢。角色初始伤害为 5，正常路线无法在生命耗尽前击败 1000 HP、50 伤害的 Black Knight。源码把玩家伤害声明为 16 位无符号整数，并在隐藏门动作中反复减 3，为算术下溢留下入口。

## 解题过程

玩家字段与门动作分别是：

```cpp
unsigned short int damage;

// ACTION_DOOR
_player->damage -= 3;
```

从起点依次输入 `C, L, C, L` 到达隐藏门；不要在剑房拾取加伤害的剑。连续执行三次 `A`：

```text
5 -> 2 -> 65535 -> 65532
```

第二次减法已经发生模 $2^{16}$ 回绕，第三次后仍保留足以秒杀所有敌人的伤害。随后按 `R, R, C, L, C, R` 返回神殿，经治疗室和吟游诗人房间进入矮人房、军械库与 Boss 房。战斗进入房间时自动开始；一次攻击即可把 Boss 的生命降到 0。

官方交互脚本使用的完整输入序列是：

```python
moves = ["C", "L", "C", "L", "A", "A", "A",
         "R", "R", "C", "L", "C", "R"]
```

击败 Boss 后程序输出：

```text
glacierctf{1t5_oNlY_4_fl35h_w0unD}
```

## 方法总结

无符号整数不会变成负数，而会按位宽取模。允许玩家无限重复降低属性却没有下界检查，使“削弱”动作在越过零后变成巨大增益。这里的目标是理解游戏状态与数值语义并构造正确路线，不涉及执行边界逃逸，因此归 Reverse。
