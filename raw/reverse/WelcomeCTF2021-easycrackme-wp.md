# easycrackme

## 题目简述

WelcomeCTF2021 的 easycrackme 对输入依次执行六个检查。源码与反编译结果都表明，各检查分别约束长度、flag 外壳、十六进制字段、异或字段和 Base64 字段；目标是逆向组合出唯一合法输入。

## 解题过程

前三个检查直接给出结构：总长度必须为 `0x26`，前 9 字节为 `greyhats{`，最后一个字符为 `}`。

第四个检查读取第一个下划线前的内容，每两个字符按十六进制合成一个字节，并与 `olympics` 比较。因此该字段是：

```python
"olympics".encode().hex()
# 6f6c796d70696373
```

第五个检查取两个下划线之间的两字节，依次与 `0x20`、`0x21` 异或，结果必须是 `in`：

```python
bytes([ord("i") ^ 0x20, ord("n") ^ 0x21])
# b"IO"
```

第六个检查对最后一段执行 Base64 解码，并要求结果为 `tokyo`：

```python
base64.b64encode(b"tokyo")
# b"dG9reW8="
```

按固定外壳和下划线连接三段：

```text
greyhats{6f6c796d70696373_IO_dG9reW8=}
```

该字符串长度、前后缀及六个检查全部满足，因此也是提交的 flag。

## 方法总结

处理多检查 crackme 时，先把每个函数转写成独立约束，再按字符串切片位置拼接。十六进制、异或和 Base64 都只是可逆表示变换；真正容易出错的是下标、终止位置与字段分隔符。
