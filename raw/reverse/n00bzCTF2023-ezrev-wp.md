# EZrev

## 题目简述

附件是 Java `.class`。程序先按下标奇偶对字符异或，再对数组前后位置做交换和加减，最后与固定整数数组比较；所有步骤都可逆。

## 解题过程

反编译得到目标数组后，必须按加密的逆序撤销第二轮变换：

```python
data = [130, 37, 70, 115, 64, 106, 143, 34, 54, 134,
        96, 98, 125, 98, 138, 104, 25, 3, 66, 78, 24,
        69, 91, 80, 87, 67, 95, 8, 25, 22, 115]

for i in range(len(data) // 2):
    if i % 2 == 0:
        old_last = data[i] - 20
        data[i] = data[-1 - i] + 10
        data[-1 - i] = old_last
    else:
        data[i] -= 30

for i in range(len(data)):
    data[i] ^= 0x13 if i % 2 == 0 else 0x37

print("".join(map(chr, data)))
```

输出：

```text
n00bz{r3v_1s_s0_e4zy_r1ght??!!}
```

## 方法总结

可逆校验应从最终常量倒推，并严格反转操作顺序。涉及首尾交换时要同时恢复两个原值，不能只对当前下标做局部减法。
