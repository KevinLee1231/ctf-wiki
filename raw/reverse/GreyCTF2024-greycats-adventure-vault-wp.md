# GreyCTF2024 Greycat's Adventure - Vault WP

## 题目简述

Vault 会在屏幕上高速切换字符，试图让玩家无法读出 flag。与同系列前四题不同，这一项没有以完整明文直接出现在 `global-metadata.dat` 中，需要控制显示速度或逐帧记录字符变化，再按题目提示统一转成小写。

## 解题过程

先用速度修改器把游戏时间倍率显著调低，或录制屏幕后逐帧查看。屏幕依次出现的内容可转写为：

```text
GR.EY.{T.H3._N.UM.B3.R5._M.45.0N._W.H4.T_.D0._T.H3.Y_.M3.4N.??.!}.XX
```

这里的句点表示相邻帧之间的字符过渡，并不是 flag 的组成部分；末尾 `XX` 也在右花括号之后，应当丢弃。删除句点和花括号后的尾随字符，再按题面要求转为小写：

```text
grey{th3_numb3r5_m450n_wh4t_d0_th3y_m34n??!}
```

完整 flag 为：

```text
grey{th3_numb3r5_m450n_wh4t_d0_th3y_m34n??!}
```

## 方法总结

高速变化的 UI 文本有视觉时序价值，不能仅靠普通 `strings` 假定答案会完整存在。有效方法是减慢客户端时间或逐帧观察，再严格区分过渡标记、有效花括号边界和尾随噪声。本题没有保留纯终端截图，而是把视觉读取结果转写成可检索文本。
