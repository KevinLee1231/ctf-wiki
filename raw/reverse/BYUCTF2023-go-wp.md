# BYUCTF 2023 - Go

## 题目简述

Go 程序要求输入的 MD5 十六进制字符串等于 `27443509682471009008637982892046`，再把该字符串用 `strconv.Atoi` 转成随机数种子，生成 24 个伪随机数与静态数组异或。

## 解题过程

目标值是 32 个十六进制字符，但恰好只含十进制数字；直接寻找 MD5 原像不可行。可在比较后的成功分支处修改条件，或在 GDB 中把计算出的哈希缓冲区改为目标字符串。

进入成功分支后还有一个关键实现错误：这个由 32 个十进制数字组成的字符串远超 64 位整数范围，`strconv.Atoi` 返回错误，而程序忽略 `err`，所以 `intVar` 保持零：

```go
intVar, err := strconv.Atoi(hash)
if err != nil {
    // 空处理
}
rand.Seed(int64(intVar)) // 实际 seed = 0
```

因此也可直接把源码条件临时改为真，用 Go 的 `math/rand` 以种子 0 复现 24 个值，与 `some_bytes` 异或。输出为：

```text
byuctf{wake_up_to_g0_g0}
```

## 方法总结

逆向时不仅要绕过不可行的校验，还要继续追踪成功分支中的错误处理。这里 `Atoi` 溢出并未阻止执行，反而把随机种子固定为 0，使后续“随机”流完全可复现。
