# bitwise_operation2

## 题目简述

程序要求输入形如 `hgame{<32 个十六进制字符>}` 的字符串。花指令清理后，主体会把花括号内的 32 个十六进制字符分成两组，各还原为 8 字节数组，再经过循环移位、奇偶位交换和异或，最后与两组常量比较。

## 解题过程

十六进制解析函数每两个字符生成一个字节，因此内部数据实际是两个 8 字节数组。逆向时最容易误读的是连续三条位运算；它们本质上用 XOR swap 交换第一组字节的奇数位与第二组倒序字节的偶数位。根据比较常量反推输入，可直接写出等价求解程序：

```c
#include <stdint.h>
#include <stdio.h>

int main(void) {
    const uint8_t flag1[8] = "e4sy_Re_";
    const uint8_t flag2[8] = "Easylif3";
    const uint8_t table[8] = {76, 60, 214, 54, 80, 136, 32, 204};
    uint8_t a1[8];
    uint8_t a2[8];

    for (int i = 0; i < 8; ++i) {
        a1[i] = flag1[i] ^ table[i];
        a2[i] = flag2[i] ^ a1[i];
    }

    for (int i = 0; i < 8; ++i) {
        int j = 7 - i;

        a1[i] = (a1[i] & 0xaa)
              | ((a1[i] & 0x55) ^ ((a2[j] & 0xaa) >> 1));
        a2[j] = (a2[j] & 0x55)
              | (((a1[i] & 0x55) << 1) ^ (a2[j] & 0xaa));
        a1[i] = (a1[i] & 0xaa)
              | ((a1[i] & 0x55) ^ ((a2[j] & 0xaa) >> 1));

        /* 把低 3 位循环移到高位，即 8 位右旋 3 位。 */
        a1[i] = ((a1[i] & 0x07) << 5) | ((a1[i] & 0xf8) >> 3);
    }

    for (int i = 0; i < 8; ++i) {
        printf("%02x", a1[i]);
    }
    for (int i = 0; i < 8; ++i) {
        printf("%02x", a2[i]);
    }
    putchar('\n');
}
```

输出为：

```text
0f233e63637982d266cbf41ecb1b0102
```

补回固定格式得到：

```text
hgame{0f233e63637982d266cbf41ecb1b0102}
```

## 方法总结

- 核心技巧：先识别十六进制字符串到字节数组的表示转换，再逐层逆回位运算。
- 识别信号：`0xaa`、`0x55` 常用于拆分奇偶位，连续三次 XOR 赋值通常是无额外空间交换。
- 复用要点：C 的 `char` 是否有符号由实现决定；含有大于 127 的常量时应使用 `uint8_t`，并在移位后保持 8 位宽度。
