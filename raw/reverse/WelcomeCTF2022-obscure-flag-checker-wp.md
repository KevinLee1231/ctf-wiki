# obscure-flag-checker

## 题目简述

表层 ELF 不直接检查输入，而是把编译进自身的字节数组写成临时文件，`fork()` 后由子进程 `execl()` 执行，父进程再根据退出码判断答案。内层程序被 UPX 压缩，真正校验是一个 40 字节置换加 XOR。

## 解题过程

先从表层程序的 `write(fd, filebytes, filesize)` 调用或运行时临时文件中导出内嵌 ELF。若文件落地后很快被删除，可以在 `write` 完成、`unlink` 之前下断点复制；随后用 `upx -d` 解包并分析内层 `check()`。

内层变换为：

```c
tmp[pbox[i]] = input[i];
tmp[i] ^= sbox[i];
if (tmp[i] != target[i]) return false;
```

所以先撤销 XOR，再按同一个置换索引取回输入：

```python
sbox = [228,32,78,63,152,7,145,202,73,213,117,132,70,92,61,112,71,162,60,89,91,222,22,255,146,125,57,25,200,0,129,41,85,240,77,88,122,6,102,229]
pbox = [5,15,12,4,19,36,8,11,25,23,29,3,6,30,35,9,27,16,7,37,34,1,17,26,39,22,38,18,28,2,14,33,0,32,24,13,10,31,20,21]
target = [139,80,121,77,225,96,218,133,61,166,68,247,35,46,98,2,33,150,82,49,104,163,87,153,205,6,74,70,248,48,222,106,39,182,18,105,27,84,57,177]

tmp = [a ^ b for a, b in zip(target, sbox)]
flag = bytes(tmp[pbox[i]] for i in range(40))
print(flag.decode())
```

得到：

```text
greyhats{f0rK_1s_fOR_p4sTA_n07_For_r1C3}
```

## 方法总结

遇到父进程只负责落地、启动和检查退出码的样本，应把分析目标转移到内嵌子程序。外层的动态文件名和 `fork` 是包装，UPX 是第二层包装，核心校验仍可直接求逆。恢复置换时要严格区分 `tmp[pbox[i]]=input[i]` 与 `tmp[i]=input[pbox[i]]`，两者逆映射不同。
