# ai-art

## 题目简述

附件包含一个二进制和 6 行由空格、井号组成的字符画。程序把每个字符编码成 6×4 点阵字形，再对点阵执行局部旋转和整体转置。目标是逆向这些图像变换，并把每个 4 列宽的字形映射回内置字体表。

## 解题过程

从符号保留的二进制或源码可确认两步变换：每个 2×2 小块按固定方向旋转一次，然后将整幅 6 行图像作首尾对称转置。按生成过程的逆序执行逆变换；官方附件的 art.txt 对应实现可用一次 rotate 后再 transpose 还原。

还原后，每 4 列是一枚字符。把井号视为 1、空格视为 0，每行形成 4 位值，再按从上到下拼成 24 位掩码：

~~~python
def glyph_value(rows, col):
    value = 0
    for row in range(6):
        nibble = 0
        for bit in range(4):
            nibble = (nibble << 1) | (rows[row][col + bit] == "#")
        value = (value << 4) | nibble
    return value
~~~

程序的 font 数组以字符码为索引保存相同掩码。对每个字形查找其在 font 中的位置并转为 chr，得到：

~~~text
maple{who_gave_computers_the_right?}
~~~

## 方法总结

字符画题不应靠肉眼猜字。把渲染过程拆成可逆的几何置换与字形编码，逐层恢复并用内置字体表验证，能精确处理标点和大小写。变换逆序、2×2 旋转方向和每行位序是最常见的三个错误点。
