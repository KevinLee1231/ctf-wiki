# ezASM

## 题目简述

附件包含一段简单的 x86 校验逻辑：程序逐字节取 flag，与常量 `0x22` 异或后同内置字节数组比较。XOR 具有自反性，因此对密文字节再次异或 `0x22` 即可恢复原文。

## 解题过程

从汇编或反编译结果提取比较数组，并复现固定 XOR：

```python
ciphertext = bytes(
    [
        74, 69, 67, 79, 71, 89, 99, 113, 111, 125, 107, 81,
        125, 107, 79, 82, 18, 80, 86, 22, 76, 86, 125, 22,
        125, 112, 71, 84, 17, 80, 81, 17, 95, 34,
    ]
)

plaintext = bytes(value ^ 0x22 for value in ciphertext).rstrip(b"\x00")
print(plaintext.decode())
```

最后一个密文字节 `0x22` 解码为字符串终止符 `0x00`，去除该字节后得到：

```text
hgame{ASM_Is_Imp0rt4nt_4_Rev3rs3}
```

## 方法总结

- 核心技巧：从汇编中的逐字节比较循环提取常量数组和 XOR 密钥。
- 识别信号：循环中出现 `xor reg, 0x22`，随后将结果与连续内存字节比较。
- 复用要点：固定 XOR 的加密和解密操作相同；还原数组时要留意末尾是否把 `\0` 也参与了异或，避免把终止字节误当成 flag 内容。
