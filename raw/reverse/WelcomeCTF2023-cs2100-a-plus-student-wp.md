# CS2100 A+ student

## 题目简述

本题使用与 CS2100 相同的栈式 VM，但测试目标从乘法升级为模幂。每轮随机生成 24 位素数 $p$ 和与 $p-1$ 互素的 16 位指数 $e$，初始栈为 $[g,e,p]$，其中 $g=2$；提交程序必须使栈顶等于：

$$
g^e\bmod p.
$$

服务端连续验证 10 组随机参数，执行步数上限也提高到 $2^{24}$。

## 解题过程

指令集没有乘法、取模、减法和右移，仍需从 `NAND` 开始组合算术。官方 1198 行程序可按功能拆成三层：

1. 用 NAND 构造 NOT、AND、OR、XOR，并由逐位进位实现加法/减法；
2. 用移位加法实现乘法，同时在中间结果达到 $p$ 时做比较和模约减；
3. 使用平方-乘算法计算模幂。

高层算法为：

```python
def mod_pow(g, e, p):
    result = 1
    base = g % p
    while e:
        if e & 1:
            result = (result * base) % p
        base = (base * base) % p
        e >>= 1
    return result
```

在 VM 中，`DUP` 和 `SWAP` 用来保存 `result/base/e/p` 的固定栈布局；`JE`、`JNE` 实现循环和分支；`SHIFT` 生成位掩码。长 payload 的首行声明 `1198` 条指令，随后完整发送。通过全部随机测试后得到：

```text
greyhats{m4st3ry_0f_NANDs}
```

## 方法总结

- 核心技巧：把受限 NAND VM 分层抽象为布尔门、整数算术、模乘和平方-乘模幂。
- 识别信号：题目要求在自定义指令集中复现 `pow(g,e,p)`，并通过多组随机输入验证。
- 复用要点：超长 VM 程序应先在本地解释器上给每个宏做单元测试，再生成最终跳转编号；不要靠手工逐行调试整个模幂流程。
