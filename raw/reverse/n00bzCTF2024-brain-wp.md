# Brain

## 题目简述

附件是 Brainfuck。每一段循环先在相邻 cell 中构造某个 flag 字符的 ASCII 值，紧接着用 `<[-]` 回到该 cell 并清零，因此原程序不打印内容。

## 解题过程

重复片段形如：

```brainfuck
>+++++++++++[<++++++++++>-]<[-]
```

循环结束时，左侧 cell 已得到 $11\times10=110$，即字符 `n`，随后 `<[-]` 把它清零。把每个清零前改为先输出：

```brainfuck
>+++++++++++[<++++++++++>-]<.[-]
```

对源码中所有对应位置逐段检查并加入 `.`，运行修改后的 Brainfuck 即可依序输出：

```text
n00bz{1_c4n_c0d3_1n_br41nf*ck!}
```

另一种方法是删除每段用于清空字符 cell 的操作，再在可视化器中读取最终 cell 值。

## 方法总结

逆 Brainfuck 时应跟踪数据指针和 cell 值，而不是只看是否存在 `.`。本题的字符已经被计算出来，只是在输出前被销毁；在销毁点前插入观测即可恢复全部信息。
