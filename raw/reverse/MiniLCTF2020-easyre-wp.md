# MiniLCTF2020 - easyre

## 题目简述

Windows 程序包含远程调试器检查和自身校验和，但核心验证只是把 20 个有符号整数各加 `0x64`，再逐字节与输入比较。静态恢复常量即可得到 flag。

## 解题过程

源码中的目标数组为：

```cpp
int flagNum[20] = {
    0x9, 0x5, 0xa, 0x5, 0x8, 0x17, 0x1, -3, 0xf, 0x15,
    0xe, 0x1, -61, 0xf, -5, 0x1, -3, 0xf, 0x15, 0x19
};
```

验证逻辑等价于：

```cpp
for (int i = 0; i < 20; ++i) {
    if (flag[i] != flagNum[i] + 0x64) {
        fail();
    }
}
```

直接恢复字符：

```python
nums = [9, 5, 10, 5, 8, 23, 1, -3, 15, 21,
        14, 1, -61, 15, -5, 1, -3, 15, 21, 25]
print(''.join(chr(x + 0x64) for x in nums))
```

输出：

```text
minil{easyre's_easy}
```

`CheckRemoteDebuggerPresent()` 只影响动态调试，自校验和也只是比较同一映像在两个时刻的求和值；两者都不改变目标数组的静态含义。

## 方法总结

逆向时先切开“反分析逻辑”和“输入约束”。只要目标常量和比较关系可静态读取，就不必先绕过全部反调试。还原有符号常量时要保留负数语义，不能把 `0xFFFFFFC3` 当作巨大的无符号整数。
