# trapdoor

## 题目简述

程序正常运行只打印 “Look closer...”，主函数没有通向 flag 的分支。但符号和反编译结果中还存在一个从未调用的 `decode` 函数，这就是题名所指的隐藏入口。

## 解题过程

`decode` 从地址 `0x601060` 开始遍历 33 个 32 bit 整数，每次给当前值加 1，再通过 `putchar` 输出。将该函数设为入口直接调用，或在反编译器中静态复现循环，都能恢复字符串：

```python
encoded = [
    0x54, 0x4C, 0x43, 0x42, 0x53, 0x45, 0x2C, 0x7A,
    0x73, 0x71, 0x60, 0x6F, 0x73, 0x74, 0x71, 0x64,
    0x5E, 0x73, 0x67, 0x64, 0x5E, 0x67, 0x68, 0x63,
    0x63, 0x64, 0x6D, 0x5E, 0x65, 0x6B, 0x60, 0x66,
    0x7C,
]
print("".join(chr(value + 1) for value in encoded))
```

对二进制中的完整数组执行后输出：

```text
UMDCTF-{trapture_the_hidden_flag}
```

其 SHA-256 与 README 中的 `749196d85c73f1186448e9e2643577920c3b816682363f3442737756817326c3` 一致。

## 方法总结

只沿 `main` 的可达控制流分析，容易漏掉刻意留下的未调用函数。应同时检查符号表、函数列表、交叉引用和全局常量。这里真正的编码只是逐字符减 1；难点在于发现没有调用者的解码例程。
