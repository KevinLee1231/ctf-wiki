# Flag Roulette

## 题目简述

程序先把全局字节数组逐字节异或 `0x41` 得到 flag，再生成 64 位随机数。只有随机数等于 `0x7777777777777777` 才完整打印 flag，其他情况只泄露前 0–5 个字符。目标是绕过概率条件恢复已在内存中解密的完整内容。

## 解题过程

静态分析可见解混淆函数：

```c
void deobfuscate_flag(void) {
    for (int i = 0; i < sizeof(flag); i++)
        flag[i] ^= 0x41;
}
```

最直接的方法是把全局数组的每个字节与 `0x41` 异或，无需参与随机游戏。另一种方法是在调试器中运行到 `deobfuscate_flag` 返回之后、最终 `printf` 调用之前，此时全局 `flag` 已是明文；查看传给 `%s` 的指针即可。

例如在 GDB 中根据当前二进制重新定位最终 `printf` 调用并下断点，命中后检查对应参数寄存器或直接打印全局变量。恢复结果为：

```text
grey{1_g0t_sup3r_dup3r_lucky_or_1m_just_pr0_r3verser}
```

## 方法总结

随机分支只控制“是否打印”，不控制“是否解密”。只要敏感数据在条件判断前已进入明文内存，静态复现解密或在正确时机调试都能绕过极低概率条件。
