# License

## 题目简述

程序要求输入 `dddd-dddd-dddd` 形式的 14 字符许可证，并用三种独立变换检查三个四位数字段。逐段逆运算即可恢复许可证，程序随后把它直接包进 `grey{...}` 输出。

## 解题过程

格式解析为：

```c
sscanf(license, "%4[0-9]-%4[0-9]-%4[0-9]%n", a, b, c, &n);
```

第一段把每个输入字符减 5 后与 `1142` 比较，所以逐字符加 5：

```text
1142 + 5 -> 6697
```

第二段对每个无符号字节循环左移 5 位，再与 `66 86 06 06` 比较。逆运算是循环右移 5 位：

```python
expected = [0x66, 0x86, 0x06, 0x06]
part2 = bytes(((x >> 5) | (x << 3)) & 0xff for x in expected)
print(part2)  # b"3400"
```

第三段把输入与 `0x55` 异或后和 `mbmc` 比较。异或是自身的逆运算：

```python
part3 = bytes(x ^ 0x55 for x in b"mbmc")
print(part3)  # b"8786"
```

组合三段得到许可证：

```text
6697-3400-8786
```

实际运行分发版验证：

```text
Enter License: 6697-3400-8786
Congrats! The flag is grey{6697-3400-8786}
```

## 方法总结

这类分段校验应按输入切片分别建模，不必把整个程序符号执行。字符加减、定宽循环移位和异或都有直接逆变换；尤其在旋转运算中要先确认操作数是 8 位无符号数，并在 Python 中用 `& 0xff` 保持相同宽度。
