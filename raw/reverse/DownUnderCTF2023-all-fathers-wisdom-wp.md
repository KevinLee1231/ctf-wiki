# DownUnderCTF 2023 All Father's Wisdom Writeup

## 题目简述

题目给出一个 Odin 编译的可执行文件。程序表面上不会输出 flag，但二进制中保留了未被正常调用的 `print_flag` 逻辑。关键不在动态利用，而在静态恢复该函数中保存的整数数组及逐字节变换。

## 解题过程

反编译 `print_flag` 后可以看到，程序先构造一组整数，再对每个元素执行与 `0x11` 的异或，最后以十六进制形式输出结果。Odin 中这里使用的 `~` 是按位异或运算，不应误读成单目取反。

将数组按原顺序取出并还原即可：

```python
encoded = [
    # 将反编译结果中的整数数组依次填入此处
]

decoded = bytes(value ^ 0x11 for value in encoded)
print(decoded.decode())
```

如果反编译器展示的是程序打印出的十六进制字节，也可以先逐项异或，再把结果按 ASCII 解码。恢复出的明文为：

```text
DUCTF{Od1n_1S-N0t_C}
```

## 方法总结

这道题的障碍是识别 Odin 程序中未走到的 flag 函数，并正确理解其位运算语义。遇到“主流程没有输出”的逆向题，应同时检查未引用函数、常量数组和格式化输出；看清语言运算符的含义后，逐字节异或即可完成恢复。
