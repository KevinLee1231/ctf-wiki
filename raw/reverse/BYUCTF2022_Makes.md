# BYUCTF 2022 - Makes

## 题目简述

附件是一个自动生成的大型 Makefile。每个目标输出 `1` 或 `l`，并可能递归调用另一个目标；需要找到其完整递归输出等于指定模式的目标名。

## 解题过程

先从每个 `target:` 行提取目标名，再逐个执行 `make <target>`，过滤 Make 自身的进入目录、命令回显和递归提示，只保留目标打印的 `1/l`。仓库记录指出必须跳过三个循环入口：

```text
Ja56c77a6        # 自环
n103193b0        # 与下一目标互相递归
l6f83d9ad
```

也可以直接把 Makefile 解析为有向图，记忆化计算每个无环目标的输出，从而避免启动数百个进程。对结果搜索题目要求的模式：

```text
1111111l11lll1ll11l11111111l
```

它出现在输出清单第 720 行；目标清单第 720 项是：

```text
y2f45206c
```

所以提交：

```text
byuctf{y2f45206c}
```

## 方法总结

Makefile 在这里就是一种依赖图程序。求值前应先检测自环和强连通分量，避免递归卡死；目标输出与目标名清单必须保持相同行号，才能从匹配字符串准确反查入口。
