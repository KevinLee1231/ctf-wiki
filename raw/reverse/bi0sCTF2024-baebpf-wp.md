# bi0sCTF 2024 - baEBPF

## 题目简述

远程程序分为两关，并以 eBPF 汇编转储作为逆向线索。第一关要求恢复文件名和 8 字节密码；通过后会给出第二段程序的密文输出与部分汇编。第二关使用 TEA 加密一段 Python 代码，解密并理解其中的递推异或逻辑后才能恢复 flag 内容。

## 解题过程

### 第一关：从 eBPF 比较逻辑恢复密码

程序公开的 map dump 含有 8 个字节：

```text
53 6c 77 64 69 6c 71 7c
```

结合汇编可见，输入的每个字符先与 5 异或，再与对应 map 值比较，即

$$
\operatorname{ord}(s_i)\oplus5=E_i.
$$

异或是自身的逆运算，所以逐字节计算 $s_i=E_i\oplus5$，得到密码 `Virality`。文件名在服务端逻辑中直接比较为 `flag.txt`。提交这两项后进入第二关；第一关显示的“找不到 flag”只是剧情提示，不是最终失败。

```python
encoded = [0x53, 0x6c, 0x77, 0x64, 0x69, 0x6c, 0x71, 0x7c]
password = bytes(value ^ 5 for value in encoded)
assert password == b"Virality"
```

### 第二关：TEA 解密代码

第二关输出一长串 32 位整数，部分汇编揭示它们按两个 32 位字组成一个 64 位 TEA 分组。密钥四个字完全相同：

```c
uint32_t key[4] = {
    0x12341234, 0x12341234, 0x12341234, 0x12341234
};
```

按标准 TEA 逆过程执行 32 轮：初始 `sum` 为 `0xC6EF3720`，轮常数为 `0x9E3779B9`，每轮先更新右半再更新左半。所有加减、移位都必须截断为无符号 32 位。每两个公开整数解出 8 字节，按目标机器的字节序拼接后即可得到一段 Python 脚本；末尾的零分组属于填充，不是代码正文。

### 还原递推异或

解密出的脚本定义递推数列

$$
a_0=1,\qquad a_1=3,
$$

$$
a_n=2a_{n-1}+3a_{n-2}.
$$

第 $i$ 个密文字节与 $a_{i^2+1}\bmod256$ 异或。由于只使用低 8 位，递推时可以每步取模 256，避免数值快速膨胀：

```python
def recurrence(n):
    a0, a1 = 1, 3
    if n == 0:
        return a0
    for _ in range(1, n):
        a0, a1 = a1, (2 * a1 + 3 * a0) & 0xff
    return a1

plain = bytes(value ^ recurrence(i * i + 1)
              for i, value in enumerate(enc_flag))
```

该递推的特征根为 3 和 -1，结合初值还可直接化简为 $a_n=3^n$，适合用 `pow(3, i*i+1, 256)` 交叉验证。官方脚本把循环上界写成 20，但密文数组实际只有 19 项；实现时应按 `len(enc_flag)` 遍历，避免在已经输出完整内容后触发越界异常。解出的 19 字节为：

```text
eBPF_wtF_1s_th4t???
```

最终 flag 为 `bi0sctf{eBPF_wtF_1s_th4t???}`。

## 方法总结

本题的两关都是从低层转储恢复高层语义。第一关的 eBPF 比较只是固定异或，map 值直接给出密码；第二关先按 32 位无符号语义逆 TEA，再执行解出的递推异或脚本。处理 TEA 时应特别注意分组顺序、字节序与 32 位溢出，处理最终脚本时则应以数组真实长度为准。
