# helloRe

## 题目简述

程序会把输入的每个字节与一组从 `0xff` 开始递减的数异或，再与内置字节数组比较。题目还加入了与时间有关的延时和少量反调试逻辑，但它们不参与 flag 校验；直接逆向比较数组即可恢复正确输入。

## 解题过程

沿主函数追踪输入校验，可以确认第 $i$ 个输入字节执行的运算为：

$$
c_i = p_i \oplus (0xff-i)
$$

异或是自身的逆运算，因此明文字节满足：

$$
p_i = c_i \oplus (0xff-i)
$$

从数据段抄出参与比较的 22 个字节：

```python
cipher = [
    0x97, 0x99, 0x9C, 0x91, 0x9E, 0x81, 0x91, 0x9D,
    0x9B, 0x9A, 0x9A, 0xAB, 0x81, 0x97, 0xAE, 0x80,
    0x83, 0x8F, 0x94, 0x89, 0x99, 0x97,
]

flag = bytes(value ^ (0xFF - index) for index, value in enumerate(cipher))
print(flag.decode())
```

运行后得到：

```text
hgame{hello_re_player}
```

## 方法总结

遇到带延时或反调试代码的入门逆向题，应先确认这些分支是否真的影响最终比较。只要校验逻辑是逐字节可逆变换，就可以从比较常量反推输入；本题的关键细节是异或量会随下标递减，而不是所有字节都与固定的 `0xff` 异或。
