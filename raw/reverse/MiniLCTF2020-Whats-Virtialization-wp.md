# MiniLCTF2020 - What's Virtialization

## 题目简述

程序用 NAND 万用门组合出 AND、OR、XOR，再配合 Fibonacci 常量和控制流平坦化掩盖普通的逐字节异或校验。发布源码还增加了 FNV-1a 与一组整数雪崩混合，以排除只满足位约束的非预期输入。

## 解题过程

底层原语是：

```cpp
int N(int a, int b) { return ~a & ~b; }
```

由它可组合出：

```text
AND(a,b) = N(N(a,a), N(b,b))
OR(a,b)  = N(N(a,b), N(a,b))
XOR(a,b) = N(AND(a,b), N(a,b))
```

把 Fibonacci 数组中的常量折叠后，主校验要求长度为 32，并把输入分成 `6 + 13 + 13` 字节。三段都与循环密钥 `020408` 异或，再分别和下面的目标串比较：

```text
}[^]|{
dtKcXxDmYgoNY
@D]pTYHp@Yw^O
```

异或是自身的逆，按相同密钥位置回推即可。仓库源码直接保留了用于核对的明文注释，回代全部位约束并通过新增 FNV-1a 校验后得到：

```text
MiniLCTF{Wh@t_iS_virti@liz@tiOn}
```

源码版本先执行 32 位有符号整数语义下的 FNV-1a，再依次执行 `h += h << 13`、`h ^= h >> 7`、`h += h << 3`、`h ^= h >> 17`、`h += h << 5`；上述 flag 的最终值为 `420679468`。它用于拒绝因按位包含关系而产生的其他候选。原参赛 WP 的临时求解器曾打印 `MiniM...`，那是手工数组拼接错误；当前源码注释和完整校验均确认正确前缀是 `MiniLCTF`。

## 方法总结

MBA/门电路混淆先做代数归一化：识别 NAND 后，复杂函数就能还原成普通布尔运算。控制流中的 Fibonacci、除法和取模大多只是常量编码。求出候选后仍要执行最终哈希，避免把只通过局部位约束的非预期解当成 flag。
