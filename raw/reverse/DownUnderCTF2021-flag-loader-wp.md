# DownUnderCTF 2021 - Flag Loader

## 题目简述

程序依次执行三项整数检查，全部通过后调用 `sleep(x1 * x2 * x3)`，再读取 flag。表面上需要等待很久，实际目标是利用 C 整数的固定位宽、无符号回绕和低位截断，使三个返回值的乘积在 32 位下恰好变成零。

## 解题过程

### 第一项：同时控制异或和与乘积

第一项将五个输入字节与 `DUCTF` 逐字节异或，把结果累加到 `unsigned char t1`；同时把各字节乘以位置权重后累乘到 `unsigned char t2`：

```c
unsigned char t1 = 0;
unsigned char t2 = 1;
for (int i = 0; i < 5; i++) {
    t1 += X[i] ^ s[i];
    t2 *= s[i] * (i + 1);
}
```

所有运算最终都截断为 8 位。可取：

```python
S = bytes([0x02, 0x01, 0x01, 0x01, 0x89])
```

此时异或项之和为 $512$，在模 $2^8$ 下等于零；源码中的 `t2` 是乘积而不是加权和，其实际结果为：

$$
\prod_{i=0}^{4} S_i(i+1) \equiv 112 = 2^4\cdot 7 \pmod{256}.
$$

因此第一项通过，且返回值已经提供四个因子 2。

### 第二项：构造无符号加法回绕

第二项给出 16 位随机数 `r`，要求非零的 32 位无符号整数 `x`、`y` 都大于 `r`，但满足：

$$
x+y\equiv r\pmod{2^{32}}.
$$

令 $v=v_2(r)$，在通常的 $v<8$ 情形取 $k=15-v$：

```python
x = r + (1 << k)
y = (1 << 32) - (1 << k)
```

加法会回绕到 `r`，而乘积低 16 位为 $2^{15}$：

```python
z2 = (x * y) & 0xffff
assert z2 == 1 << 15
```

若随机数使构造不满足断言，例如 `r` 含有过多因子 2，则断开后重连即可；solver 应在发送前本地验证全部条件。

### 第三项：让两个差值携带足够多的因子 2

第三项要求五个非零无符号数严格递增，且它们的 32 位和等于另一个 16 位随机数 `r`。可令：

```python
x1 = 2 - (r & 1)
x2 = 3
x3 = x2 + 2**7
x4 = (r - x1 - 2*x2 - 2**7 - 2**8) // 2
x5 = x4 + 2**8
```

奇偶性选择保证 `x4` 是整数；在 `r` 足够大时五个数严格递增，并且：

$$
(x_3-x_2)(x_5-x_4)=2^7\cdot2^8=2^{15}.
$$

同样应先检查正数、递增和求和条件，遇到过小的 `r` 就重连。

### 让等待时间回绕为零

三个函数的真实返回值至少分别含 $2^4$、$2^{15}$ 和 $2^{15}$，故：

$$
x_1x_2x_3\equiv0\pmod{2^{34}},
$$

赋给 32 位无符号乘法结果时必然回绕为零。`sleep(0)` 立即返回，程序输出：

```text
DUCTF{y0u_sur3_kn0w_y0ur_int3gr4l_d4t4_typ3s!}
```

## 方法总结

本题考查的是整数类型而不是求解普通方程：第一项在 `unsigned char` 中模 $2^8$，后两项利用 32 位无符号回绕和低 16 位截断，最后累计至少 34 个因子 2，使 `sleep` 参数在模 $2^{32}$ 下为零。分析时必须直接依据源码中的乘法、提升和截断规则；官方 solver 中用于解释第一项的加权和并不是程序真正返回的值。
