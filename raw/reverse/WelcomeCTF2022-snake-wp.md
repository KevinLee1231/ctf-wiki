# snake

## 题目简述

网页实现了一个 Phaser 贪吃蛇游戏。每吃到 100 个食物，脚本才在控制台输出一个字符；完整 Flag 需要 3300 个食物。输出字符由一个混淆过的线性同余生成器（LCG）与静态数组异或得到，因此无需实际通关。

## 解题过程

在 `index.html` 中定位 `food.total % 100 == 0` 分支：

```javascript
console.log(String.fromCharCode(
    _0x4f25d4() ^ key[Math.floor(food.total / 100 - 1)]
));
```

整理混淆函数中的算术常量后，生成器参数为 $a=75$、$c=74$、$m=65537$、初始状态 $x_0=73$，每次先返回旧状态，再更新：

$$
x_{i+1}=(75x_i+74)\bmod65537.
$$

把页面中的 33 个 `key` 值复制出来，直接复现字符生成：

```python
key = [46,5599,22934,23064,31475,60401,833,61602,36164,25074,38673,
       17946,42879,62979,13808,48910,6468,23327,46714,22427,50172,23724,
       13001,53850,37871,14495,39617,19456,25173,54004,45779,26505,25091]

x = 73
out = []
for value in key:
    out.append(chr(x ^ value))
    x = (75 * x + 74) % 65537
print("".join(out))
```

输出为：

```text
greyhats{d1d_y0u_3nj0y_th3_g4m3?}
```

## 方法总结

游戏次数限制往往只是延迟输出，真正的秘密仍在客户端逻辑中。沿“何时输出字符”反向追踪到字符表达式，再还原伪随机状态机即可。复现 LCG 时要确认函数返回的是更新前还是更新后的状态；相差一步会导致整串字符全部错误。
