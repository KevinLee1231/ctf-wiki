# average assembly assignment

## 题目简述

服务接受最多 35 条自定义“汇编”指令，解析后对 100 组随机正奇数字节测试程序是否计算整数平均数。真实 token 是 `OWO/UWU/QAQ/...`，分别对应 `MOV/ADD/SUB/...`；寄存器只有 `ACC`、`BAK` 与 `R0/R1`。必须提交能读取以 0 结尾的输入序列、求和计数并做整数除法的短程序，故主要障碍是恢复解释器语义与程序综合，归入 Reverse。

## 解题过程

### 指令语义和成功条件

Lexer 映射为：`OWO=MOV`、`UWU=ADD`、`QAQ=SUB`、`TVT=SAV`、`TOT=SWP`、`WOW=JMP`、`WEW=JZ`、`WAW=JNZ`、`LOL=label`。`INP` 把下一个输入字节放进 `R0`；评测长度是 1 到 19，所有字节均被置为奇数，目标值是 C 的 `ans /= l`，即正数向零截断平均。

官方 solver 的思路是把累计和保存到 `BAK`、计数保存到 `R1`：循环读取 `R0`，零则结束，否则执行 `SWP; ADD R0; SWP` 累加，并对 `R1` 加一。

### 用嵌套减法实现整除

解释器没有除法。将总和与计数交替置入 `ACC`/`BAK`，每轮从两者各减一；内层计数减到零时恢复计数并让商加一，外层总和减到零时结束。官方程序在整除时额外校正一次，使最终 `R0` 等于题目要求的平均数。以自定义 token 表替换普通 mnemonic，末尾写 `EOF` 结束输入。

核心结构为：

```text
读至 0：BAK += R0，R1 += 1
重复：从总和和计数同步减 1
      计数归零则商加 1 并重新开始一轮
      总和归零则输出商
```

### 验证

官方 solver 提供完整、在指令数上限内的提交程序；题目配置给出的验证值为 `DUCTF{y0u_pass!_dbfae0837abc0a239fd7abf93be8a01dfec}`。本文未连接服务或执行 submitted program，结论来自 lexer、parser/executor 与官方程序的静态复核。

## 方法总结

- 核心技巧：面对自定义汇编先恢复 token、寄存器更新、跳转落点和评测 oracle，再做最小程序综合。
- 识别信号：指令数严格受限、随机输入验证某个数值函数、却只给加减跳转时，常需以循环实现乘除或比较。
- 复用要点：不要把题面里的可爱 token 当作语义；应以 parser 的 token 表和 executor 中实际分支为准，并把结束标记纳入提交格式。
