# GlacierCTF2023 - skilift

## 题目简述

题目给出一个 64 位 Verilog 组合逻辑锁。输入 `key` 依次经过掩码、左移、与 ASCII 字符串 `HACKERS!` 异或、减去十进制 `12345678`，最终必须等于 `64'h5443474D489DFDD3`。

## 解题过程

从比较常量逆推。先撤销减法，再撤销异或：

```text
0x5443474d489dfdd3 + 12345678 = 0x5443474d495a5f21
0x5443474d495a5f21 XOR 0x4841434b45525321 = 0x1c0204060c080c00
```

Stage 2 是固定 64 位宽的左移 5 位，因此右移得到一个可用的移位前值：

```text
0x1c0204060c080c00 >> 5 = 0x00e0102030604060
```

该值与 `0xf0f0f0f0f0f0f0f0` 按位与后不变，所以可直接把它作为原始 key。低五位和被 Stage 1 清掉的位可能带来其它等价输入，但只需一个满足条件的解。

```python
target = 0x5443474D489DFDD3
hackers = int.from_bytes(b"HACKERS!", "big")
key = ((target + 12345678) ^ hackers) >> 5
print(f"{key:016x}")
```

提交 `00e0102030604060` 后 `lock` 变为 1，服务返回：

```text
gctf{V3r1log_ISnT_SO_H4rd_4fTer_4ll_!1!}
```

## 方法总结

这不是物理接口或采样信号题，而是对 HDL 描述的纯组合逻辑做行为还原。逆推时要保持 Verilog 的固定位宽、端序和字符串常量表示；遇到 AND 与移位等非双射步骤时，只需构造一个满足被保留位约束的前像。
