# BYUCTF 2023 - Chicken Again

## 题目简述

附件表面上是大量重复的单词 `chicken`，实际使用名为 Chicken 的栈式深奥编程语言。不同数量的连续 `chicken` 表示不同操作码。

## 解题过程

将文件交给 Chicken 语言解释器，或按语言规范把每行 `chicken` 的数量转成操作码并执行栈机。程序没有额外输入，运行结果就是一行文本：

```text
BYUCTF{ITS_ALL_CHICKENS?_ALWAYS_HAS_BEEN}
```

官方 README 中的终端截图只显示上述输出，因此已转写成代码块，不再保留无额外视觉信息的截图。

## 方法总结

重复词文本可能是 esolang 源码而非无意义填充。识别标题、词汇和行结构后，优先寻找语言规范或解释器；执行前仍应在隔离环境中确认解释器不会把题目源码当宿主命令运行。
