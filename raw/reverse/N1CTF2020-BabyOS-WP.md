# N1CTF 2020 BabyOS Writeup

## 题目简述

BabyOS 提供一个教学操作系统内核镜像和 FAT32 数据镜像。数据盘中的 `n1ctf` 程序被系统加载器再次加密；恢复程序后还能看到三轮 DES 和 RC4 两层校验。完整解法包含镜像取证、内核加载逻辑逆向、DES 差分分析和 RC4 解密，但决定性工作是恢复自定义 OS 的执行与校验算法，因此归入逆向。

## 解题过程

### 从两份镜像提取目标程序

先用 `file`、`binwalk` 和 FAT 工具识别镜像。FAT32 数据盘中能直接找到名为 `n1ctf` 的文件，但它不是可直接反编译的明文 ELF。对内核镜像 `a.img` 扫描可见引导区、内核和多个嵌入 ELF，重点分析系统调用分派与 `do_execute`。

### 逆出加载器异或层

`do_execute` 读取待运行文件后，用固定字符串循环异或，并把解密结果写到临时位置。密钥为：

```text
xpawqejc4654wqqwe1238##3213
```

对数据盘中 `n1ctf` 文件执行相同操作：

```python
key = b'xpawqejc4654wqqwe1238##3213'
plain = bytes(byte ^ key[i % len(key)] for i, byte in enumerate(cipher))
```

输出应恢复出合法 ELF 头；这是密钥和起始偏移正确的第一项验证。

### 恢复三轮 DES 输入

解出的程序读取第一段用户输入，把它派生为三轮 DES 的密钥，对固定已知明文加密并与内置密文比较。由于轮数只有 3，安全裕度远低于标准 16 轮 DES。利用已知明文/密文对进行差分分析：选择输入差分，统计 S 盒输出差分对各 6 位子密钥候选的支持度，再由高分候选组合出轮密钥。

将三轮子密钥逆向映射到 DES 主密钥位，补齐奇偶校验位，并用程序的三轮实现重算目标密文。只有完全相等的候选才保留。需要注意附件实现的位编号、初始置换和轮密钥顺序，不能直接假定与密码库接口一致。

### 用 RC4 解出第二段

通过第一层后，程序把同一第一段输入作为 RC4 key，处理第二段输入并与固定字节串比较。RC4 是对称流密码，因此直接对目标字节串再次执行相同 KSA/PRGA 即可恢复第二段：

```python
second = rc4(first_input, expected_ciphertext)
```

按程序要求拼接两段输入并在原 OS/模拟器中验证，校验成功后输出 flag。

## 方法总结

多层逆向要为每层设置可验证的边界：镜像格式正确、异或后出现 ELF、DES 重算匹配、RC4 再加密回目标。三轮 DES 的弱点来自轮数削减，不应泛化为标准 DES 可被同样轻易破解。对自制 OS，加载器往往比用户程序更早改变文件内容，直接对磁盘密文反编译容易走错方向。
