# r3loads

## 题目简述

题目把一张结果图片拆成 11,423 个加密片段。完整大附件通过外部网盘分发，当前仓库只保留了题目描述、配置和 checker；checker 明确给出的目标为：

```text
R3CTF{wH4T_4_FUnNY_4u70m4T1c_rev3r53_joUNey}
```

每个片段目录中都有一个 `beatme` 程序。它用大量细粒度运算函数把真正的 32 位运算拆散，且不同样本的移位量、轮常量、查表内容和密文均不同。人工逐个分析 11,423 份程序不可行，必须先恢复共同算法，再自动提取每份样本的参数。

## 解题过程

### 从运算函数还原加密轮

入口附近的 `sub_1630` 是核心。动态调试或用 Capstone 扫描调用点，可以把被拆散的操作重命名为：

```text
pow     乘方
add     加法
equ_add 累加
not     按位取反
box     表项读取
or      按位或
and     按位与
div     整数除法
mul     乘法
xor     按位异或
```

混淆主要是等价替换，例如：

$$
a\oplus b=(\neg a\land b)\lor(a\land\neg b)
$$

左移、右移也分别被替换为乘、除 $2^n$。把这些等价式折叠后，每个 `beatme` 都是在两个 32 位字上运行 1,145 轮的 XTEA 风格变换，并混入一个 RC4 风格的 256 项查找表。

对应的逆运算可概括为：

```python
total = delta * 0x479

for _ in range(1145):
    v1 -= (
        (((v0 << shift[3]) ^ (v0 >> shift[2])) + v0)
        ^ (total + key[(total >> 11) & 0xff])
    )
    total -= delta
    v0 -= (
        (((v1 << shift[0]) ^ (v1 >> shift[1])) + v1)
        ^ (total + key[total & 3])
    )
```

所有运算都按 `uint32_t` 截断。

### 自动提取每个样本的参数

不同文件的绝对地址会变化，但生成器留下的指令形态稳定。自动化脚本用 libdebug 在每个目录启动 `./beatme`，输入任意 8 字节，然后按特征字节搜索并下断点：

```text
mov esi, eax; mov edi, 2; call ...       -> 四个 shift
mov rdi, rax; call rcx; mov r8, [...]    -> delta
mov esi, ecx; mov rdi, rax; call r8      -> 查表地址
mov eax, [rbp-0x58]; cmp eax, imm32      -> 两个密文字
```

运行到对应断点后：

1. 从寄存器依次取得四个移位量；
2. 取得当前样本的 `delta`；
3. 从表地址读取 $256\times4$ 字节并拆成 256 个小端 32 位整数；
4. 从两条比较指令的立即数位置读取 8 字节密文；
5. 调用逆轮函数得到两个明文 32 位字。

这样无需依赖每份程序的符号名或固定装载基址。

### 拼回图片

片段编号决定输出顺序。每个样本解出 `(v0, v1)` 后按小端序追加：

```python
result += pack("<I", v0)
result += pack("<I", v1)
```

一次启动全部 11,423 个调试进程会在处理约四千个样本后耗尽资源，因此分成四段执行：

```text
1     - 2856
2857  - 5712
5713  - 8568
8569  - 11423
```

每段结果依次追加到 `output.jpg`。前两段已足以让图片中的 flag 区域可辨，完整跑完则能恢复整张图：

```text
R3CTF{wH4T_4_FUnNY_4u70m4T1c_rev3r53_joUNey}
```

## 方法总结

题目的规模是障眼法：11,423 个二进制不是 11,423 套算法，而是同一算法的参数化实例。先把布尔恒等式和乘除移位还原成 XTEA 风格轮函数，再用稳定的机器码特征动态提取参数，才能把线性的人工作业变成自动化重建。

[公开复现文章](https://blog.huanghunr.top/2025/07/10/r3ctf2025/) 给出了运算跟踪、libdebug 特征和四段处理脚本；正文已完整概括算法、参数提取点、拼接字节序与资源耗尽规避方法。
