# RCaaS

## 题目简述

题目提供一个已安装服务及其检查程序。程序读取指定文件中的输入，并通过一组相互关联的字节运算判断是否正确。需要从二进制中恢复 46 个输入字节，而不是攻击服务管理器本身。

## 解题过程

反编译检查函数后，可以看到每个输入字节都作为 8 位量参与加法、减法、异或和相邻字节关系，最终与常量比较。由于机器字节运算会自然模 $256$，建模时使用 8 位 BitVec 最直接：

    from z3 import BitVec, Solver

    x = [BitVec(f"x{i}", 8) for i in range(46)]
    s = Solver()
    for ch in x:
        s.add(ch >= 0x20, ch <= 0x7e)
    # 按反编译结果逐条加入等式与异或约束

同时加入已知格式 `byuctf{`、末尾 `}` 和可打印范围，能够排除无意义的模运算解。把反编译中的全部条件无损转写后求解，模型给出：

    byuctf{s3rv1c3s_c4n_3_r3v3rs3_3ng1n33r3d_t00}

将该字符串写入服务读取的目标文件，再运行原检查程序即可通过验证。

## 方法总结

关键是把服务外壳与真正的判定逻辑分开：systemd 等部署信息只说明输入位置，flag 仍由本地字节约束决定。面对大量 8 位运算时，应保留位宽，让求解器自动处理溢出，并用原程序回测模型结果。
