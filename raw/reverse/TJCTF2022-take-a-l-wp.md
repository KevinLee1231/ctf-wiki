# TJCTF2022 take-a-l

## 题目简述

程序内置一串不可读字符，先要求输入长度与该字符串相同，再逐字节检查 `(guess[i] ^ flag[i]) == 0x12`。这是固定单字节异或校验，运算可逆，不需要爆破或动态调试。

## 解题过程

从源码或二进制常量区取出密文：

```python
enc = "fxqftiuuus\x7fw`aaaaaaaaa'ao"
plain = ''.join(chr(ord(c) ^ 0x12) for c in enc)
print(plain)
```

因为 $a\oplus k\oplus k=a$，对每个密文字节再次异或 `0x12` 就恢复程序期望的输入。运行后得到：

```text
tjctf{gggamersssssssss5s}
```

将该字符串输入挑战程序，长度检查和逐字节比较均通过，程序输出 `W`。

## 方法总结

固定异或是最直接的可逆变换。分析时只需确认密文的真实字节序列、密钥和是否包含换行；这里 `fgets` 后主动减去一字节长度，换行不属于比较内容。对这种题使用完整反编译器并非必要，提取常量后写几行解码代码即可形成可复现验证。
