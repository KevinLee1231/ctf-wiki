# creakme3

## 题目简述

附件是 PowerPC 架构程序。程序把字符及其顺序拆成 89 个结构体元素，运行一段被称为“猴子排序”的逻辑；按第二个字段排好序后，依次输出第一个字段对应的 ASCII 字符。

## 解题过程

使用 Ghidra 或支持 PowerPC 的 IDA 版本加载程序。核心数据结构只有两个 `int`：

```c
struct alpha {
    int ch;
    int index;
};
```

比较循环在 `a[i].index < a[j].index` 时交换两个元素，最终效果是按 `index` 从小到大排列。没有必要复现低效的双重交换，提取数组后直接排序即可：

```text
hgame{B0go_50rt_is_s0_stup1d}
```

## 方法总结

本题的主要障碍是 PowerPC 架构与结构体数据恢复，而不是排序算法本身。确认两个字段分别代表字符和值域很大的顺序号后，只需按顺序号排序并把字符字段转成 ASCII。输出中仍有刻意加入的前后缀噪声，应按 `hgame{...}` 格式提取真正的 flag。
