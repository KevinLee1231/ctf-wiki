# VM

## 题目简述

题目提供一个自定义虚拟机和字节码。每一段字节码读取一个输入字符，把它与内嵌常量异或，再打印十进制结果；内嵌常量本身就是 flag 的对应字符。

## 解题过程

解释器的关键指令语义为：

```text
INPUT       把 getchar() 压栈
POP 0       弹到 r0
MOVC 1, c   把常量 c 写入 r1
XOR 0, 1    r0 ^= r1
PRINT 0     打印 r0
```

可以解析 `code` 文件中每个 `MOVC 1, c` 的第三个字节并顺序拼接；也可以给每次 `INPUT` 发送零字节，使输出直接等于常量字符码。编译字节码的源码明确给出：

```text
n00bz{x0r_XoR_xOR}
```

仓库 README 还列出一个多 `R` 的变体，但与实际 `challenge-code.c` 的 18 段常量不符，应以生成字节码的源码和实际程序为准。

## 方法总结

逆自定义 VM 时先建立 opcode、操作数宽度和寄存器语义，再观察重复指令模板。本题不需要利用解释器漏洞，逐段常量恢复已经足够。
