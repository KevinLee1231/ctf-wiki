# Greycademy2025 Artifact 13: Functions

## 题目简述

程序用一条复杂的 `scanf` 把 24 个输入字符写入不同 C 类型、相邻结构字段和一个指针的低字节，再逐项检查。目标是理解格式串、ASCII、小端序、浮点位表示和内存相邻关系。

## 解题过程

核心格式串为：

```c
scanf("%6s%c%ld%c%4c%4c%5c%c%1s",
      a, &b[0], &c, &d, (char *)&e, (char *)&f,
      &g.bof, (char *)&h, i);
```

逐段恢复：

- `%6s` 必须写成 `grey{p`。
- 下一字符覆盖 `b = "union"` 的首字节，使它成为 `onion`，所以是 `o`。
- `%ld` 读取十进制整数 1，所以是字符 `1`。
- 下一字符的 ASCII 值要求为 121，即 `y`。
- 写入整数 `e` 的四字节必须按小端组成 `0x70726f6d`，因此输入字节是 `morp`。
- 写入浮点 `f` 的四字节要求对应常量，实际字节是 `hic_`。
- `%5c` 从 `g.bof` 开始连续写入 `memor`：首字节令 `bof == 'm'`，后四字节按小端把 `victim` 改成 `0x726f6d65`。
- 随后的字符写入指针 `h` 最低字节。`haystack` 中索引 121 的值为 127，写入 `y`（`0x79`）使指针落到该位置。
- 最后一字符必须是 `}`。

将这些片段顺序拼接：

```text
[grey{p] [o] [1] [y] [morp] [hic_] [memor] [y] [}]
```

得到并由原二进制验证：

```text
grey{po1ymorphic_memory}
```

## 方法总结

`scanf` 的字段宽度决定消耗多少输入，但目标指针的类型决定这些字节在内存里如何解释。同一串可打印字符既可能是字符串，也可能是整数或浮点的原始位模式。分析时画出每个转换项的输入长度、目标地址和后续检查，再结合小端序与结构相邻布局，复杂格式串就能被拆成独立约束。
