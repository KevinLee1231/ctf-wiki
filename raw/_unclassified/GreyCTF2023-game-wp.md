# GreyCTF 2023 game

## 题目简述

服务生成一个 $128\times128$ 的零和收益矩阵。每轮玩家和服务器各选一个编号，玩家资金按对应矩阵元素变化；资金从 200 增长到 10000 即获胜。服务器先求自己的混合策略，还会偶尔针对玩家最近三次选择中的一个做最佳回应。正确做法是为当前随机矩阵求玩家的 maximin 混合策略。

## 解题过程

设玩家选择第 $i$ 行的概率为 $x_i$，保证收益为 $v$。建立线性规划：

$\max v$，

$\sum_i x_iM_{ij}\ge v\quad\text{对所有列 }j$，

$\sum_i x_i=1,\qquad x_i\ge0$。

用 `scipy.optimize.linprog` 或 PuLP 都能求解。若当前矩阵的最优 $v$ 太小，官方脚本关闭连接重新获取矩阵；它采用 $v\ge0.5$ 作为经验阈值。取得概率向量后，每轮独立按该分布采样行号：

```python
pick = random.choices(range(128), weights=probabilities, k=1)[0]
send(pick)
```

独立采样也使服务器针对旧选择的回应不能预测当前动作。持续更新余额；若提前破产或 10000 轮内没有达到目标，则重新选择一个更有利的矩阵实例。成功时服务输出：

```text
grey{Hey_you_are_good_at_this_game!__Yq9myj3kYTurr6Cr}
```

## 方法总结

对抗随机动作不能靠固定“最好的一行”，因为对手可选择专门克制它的列。线性规划求得的混合策略最大化最坏情况下的期望收益，而每轮独立采样避免给基于历史的对手留下可预测模式。该题的主障碍是通用博弈与优化算法，因此不机械归入密码或 AI。
