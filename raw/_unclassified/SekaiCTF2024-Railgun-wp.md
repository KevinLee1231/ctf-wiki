# Railgun

## 题目简述

在 $n\times n$ 网格左侧，第 $i$ 行发射一条初始向右上方运动的射线，射线在上下边界自动反弹。可以在任意内部水平边上放置双向反射器；射线经过反射器时翻转竖直方向。输入给出起点各行的能量排列 $p$ 和右侧目标各行的能量排列 $q$，要求布置反射器，使能量为 $p_i$ 的射线最终到达值相同的目标。

输出是 $n-1$ 个长度为 $n$ 的二进制串。题面 PDF 的彩图只说明射线在网格内折返的几何语义，算法和输出不依赖图片，因此不单独提取。

## 解题过程

### 把目标改写为标签归位

先建立每个能量值在 $q$ 中的目标行：

```cpp
vector<int> target_row(n);
for (int row = 0; row < n; ++row)
    target_row[q[row] - 1] = row;

for (int i = 0; i < n; ++i)
    label[i] = target_row[p[i] - 1];
```

现在从起点 $i$ 发出的射线携带标签 `label[i]`，目标变成让标签 $j$ 最终从第 $j$ 行离开。

### 构造一套基础走线

射线每经过一列，行坐标变化 $\pm1$；上下边界视为始终存在反射器。官方构造从底部输出槽位向上处理，并按奇偶性维护两组尚未安排的标签。奇偶性决定两条对角线能否在整数网格边上相遇。

对当前输出槽位：

1. 若同奇偶组中已有可直接接到该槽位的标签，就直接记录其临时终点。
2. 否则选择一个满足网格奇偶条件的标签，根据两条对角线路径的高度差计算中点列 `mid` 和水平边 `height`。
3. 在该交点放置一个反射器；某些方向还需在最左边界补一个反射器，使两条路径的方向相容。

这一阶段得到一个合法的基础布置，并记录当前右侧各行出现的标签排列 `rend`。它不一定已经是恒等排列，但所有射线路径及其相交位置已经确定。

### 记录可交换的路径交点

在当前布置上模拟每条射线。若射线穿过某条尚无反射器的内部水平边，就把它的标签记录到该边：

```cpp
for (int start = 0; start < n; ++start) {
    int row = start;
    bool up = true;
    for (int col = 0; col < n; ++col) {
        if (reflect[row][col])
            up = !up;
        else
            crossings[row][col].push_back(label[start]);

        row += up ? -1 : 1;
    }
}
```

当一条内部边恰好被两条射线从相反方向穿过时，在那里新增反射器会让两条路径交换后半段，因此等价于交换它们在 `rend` 中的终点。

### 用交点逐个拆开置换环

把 `rend` 看成一个置换并维护其环编号。若某个可用交点上的两个标签 $a,b$ 属于同一个非平凡环，则交换它们的终点会把该环拆成两个环，使置换离恒等排列更近。

官方代码从右向左扫描交点：

```cpp
for (int col = n - 1; col >= 0; --col) {
    for (int row = 1; row < n; ++row) {
        if (crossings[row][col].size() != 2)
            continue;

        int a = crossings[row][col][0];
        int b = crossings[row][col][1];
        if (cycle_id[a] == cycle_id[b]) {
            reflect[row][col] = !reflect[row][col];
            swap_positions_in_rend(a, b);
            recompute_cycles(rend);
        }
    }
}
```

每次操作都会增加置换环数，因此最多执行 $n-1$ 次。基础构造和射线模拟各处理 $O(n^2)$ 个网格状态；环更新总计也是 $O(n^2)$，整体复杂度为 $O(n^2)$，满足 $n\le2000$。

当 `rend` 变成恒等排列后，标签 $j$ 从第 $j$ 行离开，也就意味着每条射线命中了能量相同的目标。最后只输出内部行 `1..n-1` 的反射器矩阵。

## 方法总结

- 核心技巧：先构造任意合法的射线路由，把错误终点表示为置换；再利用两条路径的交点作为可控 transposition，逐环修正为恒等排列。
- 识别信号：网格中的局部开关会交换两条线路的后缀，而不改变其它路径；这种结构适合从几何问题转成置换与环分解。
- 复用要点：不能任意交换两个标签，必须先证明相应路径存在可切换交点；从右向左处理可避免新反射器破坏已记录的后续路径关系。每次只在同一环内交换，才能保证环数单调增加并终止。
