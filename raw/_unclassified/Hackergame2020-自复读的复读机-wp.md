# Hackergame2020 自复读的复读机 WP

## 题目简述

服务端通过标准输入接收一行 Python 3 代码并执行。第一问要求程序输出自身源码的逐字符逆序，第二问要求输出自身源码的 SHA-256 十六进制摘要。输出必须与判定目标逐字节一致，不能多一个换行。

这是 Quine 的变体，核心是程序自指构造和精确输出，暂归 `_unclassified`。

## 解题过程

### 先构造普通 Quine

Python 的 `%r` 会给字符串生成可再次解析的带引号表示。把模板自身保存在变量 `s` 中，再将 `s` 代回模板，就能重建完整源码：

```python
exec(s:='print("exec(s:=%r)"%s)')
```

服务端从 stdin 执行代码，没有对应的源码文件，所以依赖 `open(__file__)` 的方案不可用；必须让代码在运行时自行重建文本。

### 第一问：输出自身逆序

在普通 Quine 重建出完整源码后使用切片 `[::-1]`，并设置 `end=""` 禁止 `print` 添加换行：

```python
exec(s:='print(("exec(s:=%r)"%s)[::-1],end="")')
```

设整行代码为 $q$，变量 `s` 保存的是引号内部模板；`"exec(s:=%r)" % s` 恰好等于 $q$，所以程序输出 $q[::-1]$。

### 第二问：输出自身 SHA-256

同样先还原完整源码，将其编码为字节并计算摘要：

```python
exec(s:='print(__import__("hashlib").sha256(("exec(s:=%r)"%s).encode()).hexdigest(),end="")')
```

`hexdigest()` 给出题目要求的小写十六进制字符串。这里也必须保留 `end=""`；服务端输入的源代码末尾不含换行，默认 `print()` 增加的 `\n` 会使输出与期望不相等。

两行代码分别提交，对应获得两个与用户绑定的 flag。

## 方法总结

Quine 的关键不是读取源文件，而是让“模板”和“模板的可打印表示”互相嵌套。完成普通 Quine 后，逆序、哈希等变体只是在最终输出前增加纯函数变换。此类题要特别检查比较单位：题目比较的是精确字符串或字节时，空格、引号类型、编码和末尾换行都属于答案的一部分。
