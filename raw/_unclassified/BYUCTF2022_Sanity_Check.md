# BYUCTF 2022 - Sanity Check

## 题目简述

这是比赛的签到题。附件是 Discord 频道截图，顶部管理员消息用假设语气直接包含完整 flag；无需对图片做隐写或 OCR 之外的处理。

## 解题过程

放大截图顶部，可读到：

```text
If only the sanity check flag were
byuctf{l3t_th3_g4m3s_b3g1n!}.....
```

其中花括号内已经符合赛事 flag 格式，直接提交：

```text
byuctf{l3t_th3_g4m3s_b3g1n!}
```

原图只是承载这段文字的聊天截图，没有额外视觉机制，因此归档正文转写关键信息，不再保留一张只能重复展示文本的图片。

## 方法总结

签到题用于确认选手能访问公告或比赛资料。先检查明显文本和标准 flag 格式，不要在缺乏异常迹象时过度分析图片位平面、元数据或压缩结构。
