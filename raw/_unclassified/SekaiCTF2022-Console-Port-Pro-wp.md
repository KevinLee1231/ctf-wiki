# Console Port Pro

## 题目简述

Pro Mode 与 Console Port 使用同一套 curses 炸弹逻辑，但倒计时从 3108 tick 缩短到 120 tick，按每轮约 100 ms 计算只有约 12 秒。前面板仍会从六种模块中随机选五种，且一次错误就立即爆炸，因此必须编写自动终端客户端。

官方求解方案分为两层：用真正的终端仿真器解释 curses 输出，再读取固定坐标上的字符与颜色属性，执行六种模块的规则。

## 解题过程

### 建立可查询的终端画布

curses 发送的是光标移动、擦除、颜色和重绘等 ANSI/VT 控制序列，不能从 TCP 字节流中直接搜索屏幕文本。官方程序使用 `xterm-headless` 创建 81×41 的终端缓冲区，把每批网络数据写入仿真器后再查询 cell：

```javascript
const term = new Terminal({
  cols: 81,
  rows: 41,
});

await term.writeAsync(data);
const cell = term.buffer.active
  .getLine(row)
  .getCell(column);
```

[xterm.js](https://xtermjs.org/)在这里不是显示组件，而是负责正确执行控制序列并保留字符、前景色和光标状态。题目会启用 SGR 扩展鼠标模式；左键按下与抬起分别发送：

```javascript
function down(x, y) {
  return `\x1b[<0;${x + 1};${y + 1}M`;
}

function up(x, y) {
  return `\x1b[<0;${x + 1};${y + 1}m`;
}
```

坐标要加一是因为协议使用 1-based 坐标。格式可在 [XTerm Control Sequences](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html#h2-Extended-coordinates) 中查到；正文中的序列已经包含解题所需信息。

### 解析炸弹状态

六个前面板槽位左上角固定为：

```text
(4,3)   (4,28)   (4,53)
(20,3)  (20,28)  (20,53)
```

读取每个位置的 `[Countdown]`、`[Keypad]` 等标题即可建立“模块类型到槽位”的映射。先点击上箭头，依次经过顶面、背面和底面，解析顶面与底面的序列号、电池、`CAR` 和 `FRK`；左右面与背面没有组件。

返回前面板后，所有控件位置都可以表示为“槽位左上角加模块内偏移”。颜色模块不能只读字符，例如 Wires 的各行都是 `━`，需要同时读取 cell 的前景色。

### 自动执行模块规则

每收到一批数据都先更新终端画布与完成标记，再只驱动一个未完成模块：

```text
收集 top/bottom 状态
while 最终报告尚未出现:
    刷新模块标题、倒计时和完成标记
    选择一个未完成模块
    从固定坐标读取文字、符号、颜色
    按 Console Port 的规则计算目标
    发送一次按下/抬起或完整点击
```

各模块的自动化要点如下：

- Keypad：读四个 Unicode 符号，定位唯一符号行并按行内顺序点击。
- Who’s on First：把显示词映射到参考按钮，再按该按钮的优先词表选出当前存在的第一个词，共做三轮。
- Memory：保存前四阶段按下的位置和标签，按阶段表计算下一按钮。
- Wires：从六个候选行过滤实际存在的 `━`，结合前景色、数量和序列号奇偶性选择切线。
- Button：先决定点击还是按住；按住后持续读灯条颜色和倒计时，出现目标数字时只发送抬起事件。必须沿用源码中的 `DENOTATE` 拼写差异。
- Password：每列循环六次记录字母集合，从 35 词词表筛出唯一答案，再把五列转到目标字母并提交。

异步客户端不能在发送点击后立即假设状态已改变。应等待下一次 curses 重绘，在模块标题右侧读到绿色 `O` 或阶段指示变化后再推进；否则一次网络回调可能重复点击。

五个模块全部完成后，终端最终报告显示：

```text
SEKAI{ANSI?xterm?VT100?idk`\_(''/)_/`}
```

## 方法总结

本题将“屏幕自动化”变成了终端协议自动化。可靠解法不应猜测 ANSI 字节流，而要先构建可随机访问的终端状态机，再把固定布局解析、SGR 鼠标事件和模块规则分层实现。外部终端文档只用于确认协议；坐标、状态字段、判定表和交互序列均已由题目源码与官方求解器交叉验证。
