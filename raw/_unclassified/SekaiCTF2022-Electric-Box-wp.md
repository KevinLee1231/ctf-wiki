# Electric Box

## 题目简述

一个初始半径为 $R$ 的球需要从长为 $L$、宽为 $W$ 的矩形管道左端滚到右端。管道中有 $M$ 个互不相交的圆形障碍，球还可以依次套上若干层厚度为 $t_i$ 的外壳。任务是求在仍能通过管道的前提下最多能套多少层；若初始球都无法通过，则输出 `-1`。

原题 PDF 共 5 页，已逐页核对题面、约束、图示和样例。官方解法将几何可达性转化为连通性判定，再对球半径二分。

## 解题过程

固定球半径 $r$ 后，球心不能进入障碍和上下墙附近的禁区。与其搜索球心的连续路径，不如判断这些禁区能否从上墙连成一条到下墙的屏障。

建立一个含 $M+2$ 个点的无向图：

- 每个圆形障碍对应一个点；
- 另外两个点分别表示上墙和下墙；
- 若两个障碍的禁区相接，则连接对应点；
- 若某个障碍的禁区与上墙或下墙相接，则连接墙点；
- 若球本身已经塞满管道宽度，则直接连接两面墙。

两个障碍 $i,j$ 形成连续屏障的条件为：

$$
(x_i-x_j)^2+(y_i-y_j)^2
\leq
(r_i+r_j+2r)^2.
$$

这里的 $2r$ 来自两个障碍分别向外扩张一个球半径。考虑球心还必须与墙保持距离 $r$，障碍与墙的连接条件为：

$$
y_i+r_i+2r\geq W
$$

或

$$
r_i+2r\geq y_i.
$$

若 $W\leq 2r$，球也无法在上下墙之间放入。完成建图后，从上墙做 DFS；能到达下墙说明屏障已经截断所有从左到右的路径，当前半径不可行。反之，在管道左右方向没有封闭端点的前提下，球仍可绕过障碍。

可行性对 $r$ 单调：半径越大，禁区只会扩大。因此在 $[0,\lfloor W/2\rfloor]$ 上二分最大可行半径 `limit`。随后把外壳厚度升序排列，从最薄的开始贪心累加：

```cpp
sort(thickness.begin(), thickness.end());

int count = 0;
int radius = R;
for (int value : thickness) {
    if (radius + value > limit) {
        break;
    }
    radius += value;
    ++count;
}
```

若 `limit < R`，输出 `-1`。否则上述贪心最优，因为选择同样数量的外壳时，最薄的若干层产生的总半径最小。

一次判定需要枚举所有障碍对，复杂度为 $O(M^2)$；总复杂度为 $O(M^2\log W+N\log N)$。

## 方法总结

这是一类典型的配置空间问题：移动圆盘等价于把障碍膨胀后移动一个点。矩形通道的左右可达性又可以用“上下边界是否被障碍链连通”来判定。完成这一离散化后，单调二分与最小厚度优先的贪心都很直接。
