# netcat

## 题目简述

这是一道网络连接工具教程，不包含需要利用的协议或漏洞。题面给出主机和 TCP 端口，目标只是用 netcat 建立原始连接并读取服务发送的数据，因此没有合适的安全方向可归类，暂存于 _unclassified。

## 解题过程

按题面给出的地址执行：

~~~bash
nc HOST 1337
~~~

连接建立后服务直接输出：

~~~text
maple{netcat_stands_for_network_kitty}
~~~

如果本地 nc 版本不支持相同参数，可以使用 ncat HOST 1337；本题不需要发送额外内容，也不涉及端口扫描。

## 方法总结

netcat 适合快速与纯 TCP 服务交互。基本形式是 nc 主机 端口；连接失败时先区分 DNS、网络和端口可达性问题，不要把连通性教程误归为 Web、Pwn 或 Pentest。只有后续决定性障碍属于某一安全机制时，才应按该机制分类。
