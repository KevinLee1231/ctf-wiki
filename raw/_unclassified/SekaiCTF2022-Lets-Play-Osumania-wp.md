# Let's Play osu!mania

## 题目简述

题目给出一张四轨 osu!mania 谱面。每行由左右边框和四个轨道字符组成，空格表示没有物件，`-` 表示物件端点，`#` 表示长按物件的中段。任务不是计算按键时机，而是统计谱面中一共有多少个物件。

原题 PDF 共 3 页，输入格式、字符含义与样例均已逐页对照；仓库同时提供了五种语言的官方求解器。

## 解题过程

单个长按物件在同一轨道上形如：

```text
-
#
#
-
```

若逐行向下扫描，每个物件恰好有一个 `-` 的下一格不是 `#`：普通短按物件只有一个端点，长按物件则在末端满足这个条件。因此不用显式匹配整段，只要在四个轨道上统计满足以下条件的格子：

```text
当前字符是 '-'，且下一行同一轨道的字符不是 '#'
```

在谱面首尾各补一行空格后，边界也能用同一逻辑处理。官方 Python 解法还检查了上一格属于合法字符集合；由于输入只可能出现空格、`-` 和 `#`，该条件不会改变结果。

```python
n = int(input())
chart = [[" "] * 4]
chart.extend(list(input()[1:-1]) for _ in range(n))
chart.append([" "] * 4)

answer = 0
for lane in range(4):
    for row in range(1, n + 1):
        if (
            chart[row][lane] == "-"
            and chart[row + 1][lane] != "#"
        ):
            answer += 1

print(answer)
```

时间复杂度为 $O(4N)=O(N)$，额外空间可以通过只保留相邻两行降到 $O(1)$。

## 方法总结

本题的关键是为一个多格对象寻找唯一标志，而不是尝试恢复完整谱面结构。长按物件可以跨越任意多行，但“末端 `-` 的下一格不是 `#`”只出现一次，因此一次线性扫描即可完成计数。
