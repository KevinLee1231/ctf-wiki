# Purple Sheep And The Apple Rush

## 题目简述

有一棵包含 $N$ 个城镇的树，$2\le N\le 4000$。度数为 $1$ 的城镇是废弃城镇，其中藏有 $L_i$ 个苹果；其他城镇出售通行证，购买一次花费 $1$ 个苹果，通行证面值为 $L_i$。持有面值为 $v$ 的通行证时，每经过一条边花费 $v$，途中可以在其他非叶节点购买新通行证并丢弃旧证。

从每个起点 $u$ 出发，必须最终到达且只收取一个叶节点的宝藏。输出最小净支出：

$$
\text{购买通行证的费用}+\text{道路费用}-\text{终点宝藏}.
$$

若起点本身是叶节点，则只能立即取得该处宝藏，答案为 $-L_u$。

## 解题过程

先观察最优路线中更换通行证的顺序。若已经持有面值 $x$ 的通行证，又在某节点购买面值 $y\ge x$ 的通行证，新证不仅额外花费 $1$，以后每条边也不会更便宜，因此这次购买必然可以删除。故真正有用的通行证面值严格递减。

令 `dp[u]` 表示从节点 $u$ 开始、当前没有通行证时的最小净支出。叶节点的边界为：

$$
dp[u]=-L_u.
$$

对非叶节点 $u$，先在 $u$ 购买面值 $L_u$ 的通行证，再移动到某个节点 $v$，在那里转入已经求出的最优方案。若树上距离为 $\operatorname{dist}(u,v)$，转移为：

$$
dp[u] =
\min_v\left(1+L_u\operatorname{dist}(u,v)+dp[v]\right).
$$

这里的 `v` 有两类：

- 任意叶节点。到达后可以直接拿宝藏，所以叶节点的 `dp` 从一开始就已知，即使其 $L_v$ 不小于 $L_u$ 也可作为终点。
- 已经求出 `dp[v]` 的非叶节点。按 $L$ 从小到大处理非叶节点后，这些节点对应更便宜的后续通行证，符合“面值严格递减”的性质。

官方实现对每个待处理节点做一次 DFS，求它到所有节点的距离，然后枚举 $v$ 更新答案：

```cpp
for (int u = 1; u <= n; ++u) {
    if (degree[u] == 1) dp[u] = -label[u];
    else dp[u] = INF;
}

sort(nodes.begin(), nodes.end(),
     [&](int x, int y) { return label[x] < label[y]; });

for (int u : nodes) {
    if (degree[u] == 1) continue;

    dfs_distance(u, 0, 0);  // 得到 dist[v]
    for (int v = 1; v <= n; ++v) {
        dp[u] = min(
            dp[u],
            1LL + 1LL * dist[v] * label[u] + dp[v]
        );
    }
}
```

尚未处理的非叶节点仍为 `INF`，不会产生无效转移。每个节点做一次 $O(N)$ 的树遍历和一次 $O(N)$ 枚举，总时间复杂度为 $O(N^2)$，额外空间复杂度为 $O(N)$。

## 方法总结

这题的核心不是普通树上最短路，而是先证明“最优方案中的通行证面值严格递减”，从而给状态建立一个按 $L_i$ 排序的无环依赖关系。树只负责提供两点间距离；排序后的动态规划才是消除任意换证序列的关键。
