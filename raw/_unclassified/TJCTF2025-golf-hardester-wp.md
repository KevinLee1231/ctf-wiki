# golf-hardester

## 题目简述

服务依次给出五组“必须匹配”和“不得匹配”的字符串，要求提交不超过指定长度的正则表达式。后端使用第三方 Python `regex` 模块并开启 `regex.V1`，以 `re.search` 检验公开样本和运行时生成的隐藏样本。五关分别考察前缀、递归回文与位置约束、五进制整除 3、二进制整除 7，以及所有不同字符出现次数相同。

## 解题过程

各关不能靠只拟合公开样本的字符枚举，因为后三关还会随机生成扩展测试。仓库中的 `master.txt` 给出了满足长度限制的预期模式：

```regex
^a
^(?=((.)(?1)\2|.?)$).(.)(.)(.).\3.(.).\5\4\6.{13}$
^((2[14]*[03]|[14])(2|[03][14]*[03])*([03][14]*2|[14])|2[14]*2|[03])*$
^(0|1(((0|1(01*00)*01*011)(((0|11)|10(01*00)*01*01)1)*((0|11)|10(01*00)*01*01)|1(01*00)*01*01)0)*((0|1(01*00)*01*011)(((0|11)|10(01*00)*01*01)1)*10|1)(01*00)*1)*$
^(.)((.)(?<=^(?=(\1(?4)*?\3|\3(?4)*?\1|(?!\1|\3).)*$).*)|\1)*$
```

这些表达式的含义分别是：

1. `^a` 只要求字符串以 `a` 开头；
2. 递归子模式 `(?1)` 先保证整体回文，后半段的反向引用再约束长度为 25 的 Sator-square 风格布局；
3. 把五进制数字逐位送入“模 3 余数”有限状态机，正则是状态消除后的形式；
4. 同理构造二进制数模 7 的 DFA，再将接受状态转为正则；
5. `regex` 模块特有的递归和可变长回顾用于逐种字符配对，确保每个不同字符的计数相同。

逐行提交以上模式，服务会打印：

```text
tjctf{davidebyzero_is_my_hero_6a452cbdc75f}
```

本地把五个 `master.txt` 的首行依次输入 `golf.py`，包括随机扩展样本在内的所有检查均已通过。

## 方法总结

- 核心技巧：先从样本识别真实语言性质，再用递归正则或有限自动机生成短表达式。
- 识别信号：隐藏测试按数学性质随机生成，说明不能用样本黑名单投机；`regex.V1` 则明确允许递归、子例程和高级回顾。
- 复用要点：表示“某进制整数可被常数整除”时，可先建模余数 DFA，再做状态消除；复杂模式写完必须同时跑公开与生成测试。
