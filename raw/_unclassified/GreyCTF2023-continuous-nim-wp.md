# GreyCTF 2023 ContinuousNim

## 题目简述

游戏有 30 到 50 堆三位小数石子。服务先给定每步最多移除的 $R$，玩家选择最少移除量 $L$；双方每回合从一堆移除 $[L,R]$ 内的数量，所有堆都小于 $L$ 时最后行动者获胜。把数值放大 1000 后，它就是有限区间减法 Nim。

## 解题过程

将所有堆、$L$、$R$ 乘 1000 并四舍五入为整数，消除浮点误差。对允许移除任意 $L\le t\le R$ 的单堆，大小为 $n$ 时的 Grundy 值为

$G(n)=\left\lfloor\dfrac{n\bmod(L+R)}{L}\right\rfloor$。

玩家可以在服务给出的 $R$ 以内选择 $L$。依次尝试 `L = 1, 2, ...`，计算所有堆 Grundy 值的异或，选取初始异或非零的第一个 $L$，确保先手存在必胜步：

```python
xor_sum = 0
for pile in piles:
    xor_sum ^= (pile % (L + R)) // L
```

每个玩家回合枚举堆号和合法移除量，临时更新该堆的 Grundy 值；找到使全局异或变为 0 的动作便提交。机器人行动后同步本地堆状态，再次恢复到异或 0。重复到所有堆为 0 或不足 $L$，得到：

```text
grey{tH3_n1mbLE_n4M_n0mNom_MY_nUmneMn0M}
```

## 方法总结

“连续”只是输入表现，三位小数和舍入规则把状态离散成了整数。先按精度缩放，再识别区间减法游戏的周期 Grundy 函数，便可套用 Nim 异或策略。玩家能选择 $L$ 还提供了主动挑选非零初态的机会。
