# golf-harder

## 题目简述

本题延续正则高尔夫，共五关，仍由 Python `regex` V1 引擎执行。测试对象依次是一元三角数、素数长度、一元除法、三进制偶数和一元取模。隐藏测试会随机生成更大输入，因此必须用递归、反向引用、前瞻、占有量词和模糊匹配等引擎特性表达数学关系。

## 解题过程

仓库内通过全部测试的五条表达式为：

```text
(\1.|^.)+$
^(?!(..+)(\1{s})+$)..
^(?=.*=(x*))(\1(?2)x|.)=
^(1[02]*1|[02])*$
^(?=.*%(x*))\1*+(x*+).*=\2$
```

第五关的 `master.txt` 还保留了两个同长度思路，均可用可变长后行断言表达余数：

```text
%(x*)=(?<=^\1*(x*?).*?)\2$
%(x*)=(?<=^(x*)\1*.*?)\2$
```

关键观察如下：

1. 三角数 $1+2+\cdots+n$ 可让每轮捕获的前缀长度递增一位，反向引用负责记住上一轮规模。
2. 素数测试沿用“一元串若能被长度大于 1 的块整除则为合数”的经典负前瞻；`regex` 的 `{s}` 模糊约束允许块内容变化而保持长度。
3. 除法先在前瞻中捕获等号后的商长度，再递归地让被除数按除数规模消费。
4. 三进制整数的奇偶性等于各位数字奇偶性的异或；正则 `^(1[02]*1|[02])*$` 把 `1` 成对消去，因此只接受偶数。
5. 取模先捕获除数，再用占有量词消费尽可能多的完整除数块，剩余长度与等号后的结果通过反向引用绑定。

逐行提交后得到：

```text
tjctf{davidebyzero_is_my_hero_f7f43a2d}
```

## 方法总结

- 这组表达式依赖 `regex` 模块特性，移植到 Python `re`、RE2 或浏览器正则时不会等价工作。
- 一元数字把整除、商和余数都转化为“重复多少个等长块”；前瞻可预先捕获右侧答案，再约束左侧消费过程。
- 高尔夫题的长度限制是算法的一部分。应在证明一般关系后再压缩语法，不能牺牲隐藏随机测试上的正确性。
