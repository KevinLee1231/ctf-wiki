# Nokotan's Antler Tines

## 题目简述

题目给出两排共 $2n-1$ 个位置：上排有 $n$ 个数，下排有 $n-1$ 个数，整体是 $1\ldots2n-1$ 的排列。一次操作选择第 $i$ 个三角形，并循环移动：

```text
top[i] <- bottom[i]
bottom[i] <- top[i + 1]
top[i + 1] <- old top[i]
```

目标把上排排成 $1,\ldots,n$，下排排成 $n+1,\ldots,2n-1$，操作数不得超过 $(n+1)^2$。本文已逐页对照官方 3 页 PDF，补齐了输入范围、操作定义、输出格式和示例信息。

该题是纯构造算法题，决定性障碍不属于现有安全方向，因此归入 `_unclassified`。

## 解题过程

### 1. 利用三点轮换从右向左固定

一次操作是三元循环，已经固定在更右侧的位置不应再被触碰。官方解法从 $i=n-1$ 向左处理，依次把：

```text
top[i]    = i
bottom[i-1] = n-1+i
```

放到目标位置。代码内部先把所有值减一，因此目标上排值是 $i$，目标下排值是 $i+n-1$。

对当前目标值，先在线性数组中查找它位于上排还是下排。根据它和另一个目标值的相对位置，做至多常数次预处理旋转，避免两者互相阻塞。

### 2. 沿相邻三角形搬运

若下排目标值当前位于上排，就先旋转一次把它送到相邻下排。随后不断在当前位置执行旋转，使它向右移动：

```cpp
while (bottom_pos < i) {
    rotate(bottom_pos);
    ++bottom_pos;
}
```

上排目标值使用同样思路：

```cpp
while (top_pos < i) {
    rotate(top_pos);
    ++top_pos;
}
```

因为循环只使用索引小于等于当前 $i$ 的三角形，所以此前已经固定的右端不会被破坏。

### 3. 最后三个位置与可达性

处理到只剩第一个三角形后，反复旋转 0，直到 `top[0] == 0`：

```cpp
while (a[0] != 0) {
    rotate(0);
}
```

此时若 `top[1] != 1`，输出 `NO`；否则所有位置已经确定，输出操作序列。

原因是每次操作都是 3-cycle，属于偶置换。全局排列奇偶性保持不变；贪心固定右侧后，最后三个元素只有三种循环状态可达。把第一个元素转到正确位置后，第二个仍不正确就说明目标排列与初始排列奇偶性不同。

### 4. 复杂度

官方代码每次通过线性扫描寻找元素，并逐格向右搬运，因此：

$$
T(n)=O(n^2),\qquad S(n)=O(n).
$$

每个元素只会被搬运有限次，构造出的操作数满足题目给出的二次上界。

## 方法总结

这类局部轮换构造题适合“从不会再受影响的一端开始固定”。三元循环的奇偶性是不变量，既解释了为什么某些实例无解，也把最后的判定压缩到一个三角形。

实现时最容易出错的是上下排索引差一：第 $i$ 个操作作用于 `top[i]`、`bottom[i]`、`top[i+1]`，而下排目标 `bottom[i-1]` 与上排目标 `top[i]` 属于同一轮固定阶段。
