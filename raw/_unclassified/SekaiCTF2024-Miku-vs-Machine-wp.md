# Miku vs. Machine

## 题目简述

有 $m$ 场连续演出和 $n$ 名歌手，且 $2\le n\le m$。所有演出长度必须相同，每名歌手获得的总舞台时间也必须相同；每场演出最多只能在两名歌手之间切换一次。需要自行选择演出长度 $l$，并输出每场中两段时间及对应歌手。

题面 PDF 共三页，示意图只展示一种合法切分，没有额外约束；完整题意可由上述条件、输入范围和输出格式表达，因此不提取图片。

## 解题过程

### 选择 $l=n$

令每场长度为：

$$
l=n.
$$

整个演唱会总时长为 $mn$。平均分给 $n$ 名歌手后，每名歌手恰好需要：

$$
\frac{mn}{n}=m
$$

单位舞台时间。

把完整时间轴 $[0,mn)$ 按歌手切成 $n$ 个长度为 $m$ 的连续区间，再按演出切成 $m$ 个长度为 $n$ 的区间。由于 $m\ge n$，任意一个长度为 $n$ 的演出区间内部最多穿过一个歌手区间边界，所以每场至多涉及两名歌手，自动满足限制。

### 线性输出各场切分

维护当前歌手编号 `at`，以及其长度为 $m$ 的区间边界。第 $i$ 场对应时间段：

$$
[in,(i+1)n).
$$

若下一条歌手边界落在本场内部，则按该边界拆成两段；否则整场交给当前歌手。官方实现为：

```cpp
cout << n << '\n';
long long end = 0;
int at = 1;

for (long long i = 0; i < m; ++i) {
    long long left = i * n;
    long long right = (i + 1) * n;

    if (end + m < right) {
        cout << end + m - left << ' ' << at << ' '
             << right - end - m << ' ' << at + 1 << '\n';
        end += m;
        ++at;
    } else {
        cout << right - left << ' ' << at << ' '
             << 0 << ' ' << at << '\n';
    }
}
```

当歌手边界恰好等于演出边界时，代码可能在下一场输出长度为 $0$ 的第一段；题目允许段长为 $0$，所以仍然合法。算法每场只做常数次运算，复杂度为 $O(m)$。

## 方法总结

- 核心技巧：把二维“每场如何分配”改写为一条连续时间轴上的两种等长分段，并选择 $l=n$ 让歌手总时长自然为整数。
- 识别信号：构造题允许自由选择统一长度，同时给出 $m\ge n$；这通常暗示可选择某个输入参数作为块长，借区间长度关系限制交叉次数。
- 复用要点：先证明任意演出区间最多跨过一个歌手边界，再写输出逻辑；零长度段是否允许会影响边界等号的处理，本题允许 $0$，因此可省去额外分支。
