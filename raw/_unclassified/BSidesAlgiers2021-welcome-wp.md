# Welcome

## 题目简述

这是 BSides Algiers 2021 Quals 的签到题。题面要求加入赛事 Discord，并提示“向 `/bin/cat` 询问”；目标只是找到机器人支持的取 flag 指令，不涉及漏洞利用、编码、取证或其他安全机制。

由于它是无法稳定映射到正式安全方向的纯签到交互题，暂存于 `_unclassified`，不人为创建 `misc` 类别。

## 解题过程

进入赛事 Discord 后，在任意文本频道向机器人发送：

```text
.flag
```

机器人返回签到 flag：

```text
shellmates{w3lc0me_t0_BS1d3s_4lg1er$_2021}
```

题面中的 `/bin/cat` 是机器人角色提示，不是要求在本地或远程 shell 中执行 `/bin/cat`。官方题解明确给出的触发命令是 `.flag`。

## 方法总结

签到题通常只验证参赛者是否阅读公告、加入交流平台并发现机器人的基础命令。遇到类似描述时，应优先检查频道置顶消息、机器人帮助和题面中的命令提示，避免把装饰性的 Unix 名称误判成需要利用的服务。

本题没有可迁移的安全漏洞机制，因此保留最短可复现步骤并归入 `_unclassified`，比勉强塞入 Web、Pwn 或渗透测试目录更准确。
