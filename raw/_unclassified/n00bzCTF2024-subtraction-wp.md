# Subtraction

## 题目简述

服务生成 696969 个偶数，每轮接收一个整数 $c$，并把所有元素变成 $|c-a_i|$。需要在 20 轮内让整个数组收敛到同一个值。

## 解题过程

每轮选择当前取值范围的中点，可以把最大跨度至少减半。由于初始值均为偶数且位于 $[0,696969]$，可从上界中点开始，之后不断向上取整除以 2：

```python
import math

c = 696969 // 2 + 1
for _ in range(20):
    print(c)
    c = math.ceil(c / 2)
```

其思想是让区间两端到 $c$ 的距离尽可能接近；绝对值折叠后，新集合的直径约为原来一半。因为：

$$\lceil\log_2 696969\rceil=20,$$

所以能在轮数限制内把所有值压到同一点，得到：

```text
n00bz{1_sh0uld_t34ch_my_br0th3r_logs}
```

## 方法总结

本题不是逐元素求解，而是控制整个集合的直径。每次在范围中点做绝对值折叠会指数级缩小状态空间，20 轮正好对应初始范围的二进制位数。
